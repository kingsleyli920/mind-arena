### N1 ★★★★★【必须改】按键派生的随机流，取代全局单一随机序列

**机制**：任何一次随机判定，都不从一条全局序列里"抽"，而是用一个确定性的键 hash 出它自己的流：

```
draw = H(match_seed, year, season, faction_id, event_kind, event_seq)
```

**出处**：`GAMEPLAY-MOD-ECOSYSTEM.md` §2.7 / M18。
社区对《三国志 11》的逆向笔记还原出全游戏只有两个随机原语，共用同一个 LCG，
且 `random_value` 是**全局变量**——整局所有势力、所有事件共用一条序列。
派生结论：序列预先确定；每次判定推进一格，不管谁发起；"评定"这类不耗行动力的指令**也会**推进指针，
于是玩家用连续评定来"洗"随机数。
⚠ 该逆向为社区资料，非光荣官方信息，本文引用的是文件内容本身，未独立复现反编译。

**为什么首轮漏了**：首轮的四份调研全部停在"规则层"，没有一份触及**实现层**。
`GAMEPLAY-DESIGN.md` §9.4 写了一张漂亮的"随机性放置表"（哪些环节允许随机），
但**从未规定随机数如何生成**。这是一个纯工程层的规格缺口，规则层的调研看不见它。

**对本项目的价值**：这条是 **WEGO 能不能名副其实的前提条件**，不是优化项。

- 全局单流 = **裁决顺序在暗中分配运气**。谁先被求解器遍历到，谁就吃掉序列里的那个数。这个优势与决策质量完全无关。
- 对"同时密封下令 + 同时裁决"尤其致命：求解器内部总要有一个遍历次序，那个次序会静悄悄决定谁走运。
- 重构一次循环顺序就会改变对局结果，**回放对不上，复现无从谈起**。
- 它还顺手封掉模型侧的重试漏洞：随机数必须在**裁决时**按键派生，不能在**请求时**抽取，否则一次网络抖动导致的重试就是免费重摇骰子。
- "评定洗随机数"是一个精确的警告：**任何免费的、看似只读的动作，只要碰了随机流，就会变成策略通道**。所以观测与探查动作必须严格无副作用。LLM 完全有能力发现这种通道——那正是它在做的事。

**落地**：写进 `lib/game/engine/` 的规格，M0 阶段就要定死，不能等。对照 C5（✓✓✓）、C6（✓✓ 可复现）。

### N2 ★★★★★【必须改】终局用绝对阈值分档 + 名额 + 保底档必须进攻 + 按历史最高档记

**机制**（四条性质缺一不可）：

| 性质 | 内容 | 消灭的退化 |
| --- | --- | --- |
| Q1 | **绝对阈值，不是排名**。"控制 ≥3 州"是门槛，不是"比第二名多" | 围殴第一名（打倒他不会增加你的州数） |
| Q2 | **多档、可多赢**。一局可以同时有多个甲档 | 围殴（目标不冲突就没有联合的理由） |
| Q3 | **名额可协商分配**（通过一条可枚举的条约条款） | 零和化（把"消灭对手"换成"分蛋糕"） |
| Q4 | **有保底档，且保底档要求进攻**（打通关隘链，不是"未失领土"） | 全员苟活 + 提前放弃 |
| Q5 | **按本局曾达到过的最高档记，不看结算瞬时** | 最后 4 季全员龟缩保分 |

**出处**：`GAMEPLAY-SLG-MOBILE.md` §3.1 / §3.5，来自《三国志·战略版》的霸业/割据/历战名额（S1 规则 + 2025 名额池）与《率土之滨》赛季评定的"历史最高等级"判据。
⚠ 率土 2023-06 官方赛季评定页两轮抓取均返回乱码，具体档位表**不采信**；本文只用"历史最高"这一条结构。

**为什么首轮漏了**：首轮的 `GAMEPLAY-OTHER-SANGUO.md` §三覆盖了率土之滨与战略版，但看的是**玩法层**（土地分级、同盟、赛季制），
没有专门去看**目标函数与计分表**。而目标函数恰恰是这条赛道十年运营打磨得最狠的一层。
首轮方案的综合分（`0.45×PI + 0.15×威望 + 0.15×存续度 + 0.25×私有目标`）
在结构上是**万国觉醒 KVK 的荣誉积分制**——`GAMEPLAY-SLG-MOBILE.md` §3.4 指出，
那正是同一条赛道里玩家侧公认对抗生态最弱的一款。

**对本项目的价值**：这是审查【C2 致命】的**根治**方案，比审查自己给的改法（改权重 + 被灭方乘 0.5）更彻底。

关键的差别是一句话：

> 首轮："丢地扣分" → 最优策略是**不冒险**。
> 这条赛道："丢地不扣分，但不打就没有分" → 最优策略是**在能赢的地方打**。
> 惩罚是**机会成本**，不是**直接扣分**。

审查实算的边际交换率（袁绍席位丢地代价是拿地收益的 7.3 倍，曹操席位 26 倍）
在这套判据下变成 0 / 正无穷——丢地根本不进分，只是让你够不到门槛。

**落地**：替换 `GAMEPLAY-DESIGN.md` §9.1 综合分与 §9.2 霸业档位。具体形态见本文 §五的一页纸规则集。

**必须同时做的一次验算**【必须改】：按 194 实际数据验算阈值，**要求开局时无人达档**。
审查 §3.3 实算出袁绍开局即二等霸业、刘备/吕布/刘表开局即三等。
`GAMEPLAY-SLG-MOBILE.md` §6.5(c) 补了一条本项目特有的警告：
**率土like 的开局是随机分配的，本项目的开局是固定的 194 剧本，没有"多开几局平均掉开局差异"这个兜底。**
阈值定错，每一局都会错。

### N3 ★★★★★【必须改】身份分流：归隐（主动退出）与流亡（失地不出局）

**机制**：一个席位在一局中可以处于三种角色，每种有自己的目标函数：

```
                     可扩张   有产出   参与分档   可被消灭
  群雄（常态）          是      是       是         是
  流亡（被打光）        否      否       丁档       否（已无地可失）
  归隐（主动退出）      否      是(高)   丁档       否（不可被攻击）
```

**出处**：`GAMEPLAY-SLG-MOBILE.md` §6.4。
- 归隐 ← 《率土之滨》2024 年度版本"桃源军"：转入需清空全部领地、**本赛季不可逆**、不可连地、但能做群雄做不了的事（与人共占同一地块、把土地升 1 级）。
- 流亡 ← 《率土之滨》S2 起的"流浪军"：清除城市/要塞/领地/同盟，**保留设施与技术等级**（因此保有战斗力）；领地不产出；靠"掠夺"（要求连地）与"豪夺"（3 政令，无连地要求）维生；流浪军之间不可互攻、可互相借地。
  ⚠ 流浪军规则为多方攻略二手口径，官方页面本轮未完整取到。

**为什么首轮漏了**：首轮把"苟活"和"出局"都当成**需要被消灭的失败模式**，
所以整个设计里只有"群雄"一种状态，所有非正常状态都被迫挤进同一套综合分里表达。
首轮从未考虑过第三条路：**给它们一个正式身份**。

**对本项目的价值**：两条，方向相反，都很大。

**（一）归隐把苟活从隐蔽策略变成可观测信号。**
对一个**用来比较模型的竞技场**而言，这是关键的一步：

> "让退化行为变得可观测"和"消灭退化行为"是同等重要的目标，某些时候前者更重要——**因为它把噪声变成了信号**。

`withdraw` 被调用 = 该模型在第 k 季公开放弃了博弈。这是一个干净的、可统计的行为指标，
比从综合分里反推"它是不是在苟活"强得多。

**（二）流亡打击苟活的心理根源。**
`GAMEPLAY-SLG-MOBILE.md` §6.4.2 的论证值得原样保留：

> 一个理性的模型，在"不打 = 稳定丁档"与"打 = 有概率甲档、有概率出局（无分且不再被调用）"之间，
> 如果出局的代价是**彻底归零且失去所有后续决策**，它会倾向不打。**这不是模型笨，这是收益结构造成的。**

外加一条竞技场特有的、比手游更强的理由：
**一个模型被打光后如果直接出局，我们就失去了它在逆境下的全部决策样本；而逆境决策恰好是最有区分度的样本。**

**落地**：`withdraw` 一个动作 + 一个状态标志 + 结算特判，成本极低，**M1 就做**。
完整流亡状态（raid / plunder / resettle 三个动作）成本中等，**M1 只做"失地不判出局、转为无产出的流亡标记"这一半**，掠夺动作推到 M2。

### N4 ★★★★★【必须改】muster 集结：多郡抽调 + 集结窗口 + 可含盟友

**机制**：

```
action: muster（集结）
  at:        集结地（己方郡国 或 己方前进基地）
  from:      [郡国, 兵力档] × 2–5 个来源，可含盟友（需 stance=ally）
  commander: 主将
  deadline:  k+1 或 k+2 季
  cost: 1 SP（发起方）+ 0.5 SP（每个非己方来源，由该方支付）
  裁决: 各来源按行程陆续抵达；deadline 当季合并为一支军团；未抵达的部分回原郡
        集结期间集结地可被攻击；被攻破则集结整体失败
```

**出处**：`GAMEPLAY-SLG-MOBILE.md` §4.5，来自《三国志·战略版》的"太守 + 集结"：
每个郡城可任命一名太守，盟友把部队派到该城，由太守统一指挥出战。
配套的攻城规则是"最后一发"（城池耐久最后一击是谁的就归谁）与"守军打掉后 1 小时不破则恢复"。

**为什么首轮漏了**：首轮的 `campaign` 把 `strength` 四档取自**起点据点的戍兵**，
这是一个从光荣本传继承下来的、看起来天经地义的假设——
`GAMEPLAY-WESTERN-ANALOG.md` §10.2 明确指出这是本项目**自己的设计选择**：
西方大战略普遍**不把部队规模绑定在出发地驻军上**（部队是地图上独立存在的单位，集结成本是行军时间与行动预算），
所以西方赛道给不出对照物。**只有率土like 这条赛道给出了"多方把兵送进一个点、一人统一指挥"的现成形态。**

**对本项目的价值**：这是审查【C1 致命】**成因一**（军团规模上限 = 单郡戍兵，袁绍一次只能投入自己国力的 12%）的直接解药，
而且比审查自己的建议（给 `campaign` 加一个 `muster: CommanderyId[] ≤3` 参数）**明显更好**，原因是：

> 做成独立动作，集结就变成一个**暴露意图、可被反应、可被打断**的博弈动作；
> 做成 `campaign` 的隐藏参数，它只是一次静默的加法。

逐条对约束：C1 ✓（只说从哪抽、在哪汇合、谁带，不说路径与阵型）；
C4 ✓（来源集合受限于"距集结地 ≤N 的己方 + 盟友郡国"，通常 3–8 选 2–5，组合数在 O(10²) 内）；
C5 ✓✓（**纯推理博弈：我要不要为了打你而把后方掏空？你看见了会不会去打我的后方？** 零随机）；
C6 ✓（破除死锁 → 郡国开始易主 → 不再触发"连续 8 季无变动"的僵局）。

它还一次修好三件事：兵力集中、"同盟没有具体合作内容"、"盟友关系没有可验证行为"
（**集结出兵是可观测的忠诚证明**）。

### N5 ★★★★★【必须改】多数决区域控制：控制(州) = 州内直辖郡国数最多

**机制**：

```
控制(州) = 该州内直辖郡国数最多的一方（并列则无人控制）
邻接推进: 只有控制了州 S，才能对与 S 相邻的州内的郡国发起 campaign
        （己方已有郡国的州视为已具备落脚点，不受此限）
```

**出处**：`GAMEPLAY-SLG-MOBILE.md` §4.8，抽象自《文明与征服》的板块 / 据点结构。
⚠ "680 板块 / 每板块 5 据点"出自两处二手攻略，口径一致但均非官方；本文只用"多数决控制"这个**结构**，不依赖那两个数字。

**为什么首轮漏了**：首轮的终局判据用的是"控制 ≥N 个州的**过半**郡国"，
这已经很接近多数决了，但首轮**只把它用在终局判定上**，没有意识到同一个谓词可以同时承担三个职能。

**对本项目的价值**：它从**判据侧**拆掉攻城死锁，与 N4（供给侧）互补——
**muster 让你打得动，多数决让你不必全打完。**

四样收益：

| # | 收益 | 对应 |
| --- | --- | --- |
| 1 | 推进不要求全歼。拿下一州过半即可继续向外，不必逐郡拔除 | 审查【C1】判据侧 |
| 2 | 易主可逆。对手多占一个郡就能夺回州控制权，守方永远有便宜的反制 | 削弱滚雪球 |
| 3 | 战略焦点是一个整数。"冀州我 6 : 你 5，再拿一个就翻"——所有席位都算得出来 | C2（每州一行约 15 token）、C5 |
| 4 | 完全确定性，一次计数即可裁决 | C5 |

**关键的工程收益**：把终局分档、邻接推进、观测摘要三处**统一到同一个 `控制(州)` 谓词**上，是纯收益。
本项目的地理层级恰好现成——`commanderies.json` 的 105 郡国天然分属十三州，规则可以一字不改地落。

### N6 ★★★★★【建议】隐名模式：把姓名与数值藏起来，A/B 分差量化"模型有多依赖记忆"

**机制**：两个模式跑同一批模型。
- **模式 A（史实）**：武将姓名、属性全公开。测的是"记忆 + 推理"的混合。
- **模式 B（隐名）**：武将只给编号与**可观察线索**（籍贯、出身、历次任职表现、他人评价），姓名与数值隐藏。测的是纯推理。
- **A 与 B 的分差本身就是一项评测指标。**

**出处**：`GAMEPLAY-CN-INDIE.md` §7.3，《隐名三国》（Three Kingdoms: Alias，Plotrick，韩国团队，2026-07-14 上架 Steam，351 篇评测 / 80.9% 好评）。
⚠ 明确不是华语圈作品，列入是因为机制与"用游戏测推理能力"直接相关。

**为什么首轮漏了**：首轮**有**去三国化对照组（`GAMEPLAY-DESIGN.md` §8.8），但它只是一个 `id → 显示名` 的映射层——**只改名字**。
审查 G7 已经指出这个方案漏掉了卒年表：
"一个读过《三国志》的模型知道自己的谋主会在哪一年死、对手的君主会在哪一年死，这是纯粹的记忆优势，而 §8.8 的整个目的就是把它测出来并消掉。"
**隐名三国给出的是完整版**：不只改名字，还藏数值，只留可观察线索。

**对本项目的价值**：这是本轮对**项目定位**（而不只是玩法）贡献最大的一条。

本项目最大的风险之一：所有主流 LLM 都知道诸葛亮智力高、吕布武力高、荀彧是曹操的谋主。这意味着
① 一大部分"决策质量"其实是记忆检索；
② 模型之间的分差可能主要来自"谁记得更准"；
③ 这与"测试和比较不同大语言模型"的定位直接冲突。

**落地**：M0 就要留接口（首轮已经写了"M0 就要留接口"，方向对，只是接口的规格要扩）。
真正跑 B 模式推到 M4，但**接口必须一开始就按"藏数值"设计，而不是按"改名字"设计**——两者的 observation schema 不一样。

### N7 ★★★★☆【建议】提案通道：候选动作由引擎生成，模型只做选择题

**机制**：引擎按确定性规则预筛 5–15 条"具申"，**不带评分、不带排序**，模型从中选择采纳。

**出处**：三处独立出现，这本身就是证据。
- `GAMEPLAY-KOEI-WIDE.md` §7.2：《信长之野望·大志》的**评定**——一年 4 次（1/4/7/10 月），向配下武将征询意见，**最多采纳 3 名武将的意见**，采纳即获得对应类型的"施策力"，再用施策力买效果**多为永久**的"方策"。大名的「志」决定哪些方策可用。
- 同文 §5：《真·三国无双 Empires》的武将提案。
- `GAMEPLAY-WESTERN-ANALOG.md` §4.2：《信长之野望·新生》的**具申**（家臣主动提案）。

**为什么首轮漏了**：首轮的动作协议是"引擎枚举 `legalActions[]`，模型返回索引"——
方向对，但它枚举的是**全部合法动作**（审查实测 62–195 条，第一级），
而不是**若干条有意义的候选**。这两者差一个数量级。
首轮把"枚举"理解成完备性问题，大志把它理解成**候选生成**问题。

**对本项目的价值**：
- C4 ✓✓：**从根上消除非法动作**——模型永远在做选择题。
- C2 ✓✓：`legalActions` 是审查复算里最大的一段（开局 6,324 token、中期 8,160 token，占总量 6 成）。预筛到 5–15 条，这一段从 3,000+ 降到几百。
- C5 ✓：`GAMEPLAY-WESTERN-ANALOG.md` §10.3 P0-2 强调**"不带评分排序"**——一旦带了排序，就是引擎在替模型做决策，委任余量被吃掉。

**一条配套的、独立价值很高的机制**：大志的**「再考」**——不满意可以重掷一次候选集，但**再考后得到的施策力偏小**。
`GAMEPLAY-KOEI-WIDE.md` §7.2 把它译成"**重新推理预算**"：
模型可以声明对当前候选集不满意、要求重新生成，但要付代价。
**知道什么时候自己该重想，是推理能力的一部分**，而且这是一个几乎没有其他游戏提供的可测量元认知决策。★★★★★，实现成本近零。

### N8 ★★★★☆【建议】直辖半径：把观测分层变成规则的一部分，而不是外挂的裁剪

**机制**（《信长之野望·创造》，2013）：
- 定义势力"直辖半径"（从本据地出发的图距离）
- **半径内的郡国** → 观测里给完整字段
- **半径外的郡国** → 必须委任给军团，观测里只给一行军团摘要（兵力总额 / 粮草 / 方针 / 当前目标 / 忠诚警戒）
- **迁都可以改变半径覆盖**，是一个真正的战略决策

**出处**：`GAMEPLAY-KOEI-WIDE.md` §7.1 / §9.3。
同一思路在《信长之野望·新生》以"知行"（郡/城两层授予 + 军团长统治范围限制）再次出现（同文 §7.3）。

**为什么首轮漏了**：首轮的分层观测是**按 token 预算裁的**（`GAMEPLAY-DESIGN.md` §8.5 有一张降级顺序表：先裁 known officers，再裁……）。
这是一个 harness 层的技术手段，模型无从理解也无从规划。首轮没有想过让**规则本身**产生分层。

**对本项目的价值**：这是一个质变，不是量变。

> **token 压缩成为规则的一部分，观测大小随领土增长而收敛，而不是发散。**
> 而且**模型能理解为什么看不清**，而不是感觉被系统藏了信息。

评测上的意义更大：外挂裁剪造成的信息缺失**无法归因**（模型没做好，是它笨还是我们裁掉了它需要的东西？）；
规则内委任造成的信息缺失**可以被模型规划**（它可以选择迁都、可以选择缩小战线）。
这直接关系到审查【B1 致命】能不能被干净地解决。

配套 ★★★★★：《信长之野望·大志》PK 版的**可勾选授权清单**（商业/农业/取引/开发/募兵/配属 + 评定，可分别勾选）。
`GAMEPLAY-KOEI-WIDE.md` §9.8 的判断值得原样引用：
**"会不会正确地放权，是推理能力的一部分。"** 建议在评测指标里单列"授权配置的合理性"。

### N9 ★★★★★【必须改】盟约硬性到期：只给永久联合加价，不给临时联合加价

**机制**：

```
stance = ally 的关系带一个 expiry（缔结时约定，上限 N 季，建议 N = 8）
到期自动回落 neutral，不需要任何一方动作，也不触发背盟惩罚
续约：双方各付 1 SP 重新缔结，延迟一季生效、对全席位可见
hostile 不设到期（敌对是默认状态，不需要维持成本）
```

**出处**：`GAMEPLAY-SLG-MOBILE.md` §4.9，抽象自《无尽的拉格朗日》的小队——跨组织成团、共享视野、可互相增援，但**赛季结束自动解散**。

**为什么首轮漏了**：首轮的盟约有 `untilCouncil` 到期回合（§7.2），但**续约是免费的**，
且首轮的反围殴思路整个压在"众怒"这一个旋钮上（§3.7 原话："反滚雪球的唯一旋钮"）。
首轮从未想过**结盟本身可以有维持成本**。

**对本项目的价值**：它说了一件与直觉相反的事——

> **要防止长期围殴，不该禁止结盟，该给结盟设到期日。**

禁止结盟会把外交这一整层博弈删掉（而外交正是最想测的能力之一）。到期日保留全部博弈内容，只改变价格曲线：

| | 无到期日（首轮） | 有到期日 |
| --- | --- | --- |
| 临时联合（打一仗） | 便宜 | **同样便宜** |
| 永久联合（长期压制领先者） | **同样便宜** | 每 8 季重新付一次 SP，且每次都要重新暴露意图 |

三条派生性质：
1. **背刺不再需要 `abrogate`**——到期不续约就是和平分手，代价为零；在有效期内翻脸才付背盟代价。这把"毁约"从一个免费动作（审查 F5 判定的漏洞）变成一个**有时机选择的决策**。
2. 5 打 1 的联合每 8 季要重谈 4 条边，领先者有了**可预期的分化窗口**。
3. 观测成本为零：stance 矩阵那一行加一个整数。

**实现量：一个字段 + 一次每季递减。** 性价比是全文最高的几条之一。

### N10 ★★★★★【必须改】结构性连通 = 产出，取代 `scheme:断粮`

**机制**：

```
每季裁决末尾，对每个席位计算一次连通性:
  从治所出发，沿「己方控制的郡国 + 己方前进基地 + 有 transit 条款的盟友郡国」走
  可达的郡国  → 正常产出
  不可达的郡国 → 产出归零（领地仍属己方，守军仍在，只是不产出也不上缴）
  关隘所在的郡国若易主，会一次性切断其后方的整条走廊
观测里给一行: supplyCut: [郡国 A, 郡国 B]
```

**出处**：`GAMEPLAY-SLG-MOBILE.md` §6.6，来自《万国觉醒》的联盟旗帜—要塞连通性。
同一思路在 `GAMEPLAY-MOD-ECOSYSTEM.md` M3（三国志 11 的 `TransportCity` 输送城市字段）与
`GAMEPLAY-CN-INDIE.md` §9.1-5（《中华三国志》的粮道、《傲世三国》的辎重）独立出现三次。

**为什么首轮漏了**：首轮**有**补给系统（§5.3 行军与补给，"到最近己方仓的全己方路径；断则 1+⌊统率/25⌋ 旬后溃散"），
但它只作用在**军团**上，不作用在**领土产出**上。而"切断补给"被做成了一个 2 SP 的 `scheme:断粮` 动作——
审查 F4 判定：一个 2 SP 的动作不该能删掉一支军团。

**对本项目的价值**：一次改动同时解决三个问题。

1. 审查 **F4** 的定价问题（删掉那个动作）。
2. 审查 **G4** 指出的"`strategic-nodes.json` 的 61 个关隘一直没有承重"——改成连通性规则后，**关隘成为连通图上的割点，天然承重**。
3. 把"切断补给线"从一个**掷骰式的 scheme** 变成一个**确定性的、可推理的图论问题**——正是 C5 要的那种"更强的推理稳定转化为更好的结果"。

**无随机数，无新动作，一次连通分量计算，观测增加不到 30 token。**

**一条来自先行者的实证**（`GAMEPLAY-MOD-ECOSYSTEM.md` §7.3）：
"赛博斗蛐蛐：9 大模型决战三国志"的作者记载，Claude 战略文档写得最好（27 次战略修订）、外交最守信，
但**反复因补给短缺导致攻势崩溃**——**补给是该实验里分出模型高下的主要维度**。
⚠ 该文中的模型名与版本号未独立核实，未提供公开仓库链接。
但它给出一条直接的警告：**如果补给的因果链在观测里不可见，它就只是噪声**。补给状态必须显式、量化、带趋势。

### N11 ★★★★★【建议】纪元推进 = 全服目标 OR 时限（双触发）

**机制**：整局分若干纪元，每个纪元有**名字 + 一句话目标 + 截止季**。
达成目标提前推进，未达成则超时强制推进。纪元推进改变地图状态（关隘开放、核心区解锁）。
观测里放一个 `currentEpoch: { name, objective, deadline }` 字段。

**出处**：`GAMEPLAY-SLG-MOBILE.md` §1.3.4 / §3.3，《鸿图之下》的 20 阶段（"黄天当立""啸聚山林""汉室遗珍""兵戈之祸""厉兵秣马""天下归一"）。
⚠ 该作官方赛季时长未公布；运营现状本轮两次均未取到权威结论，本文不下结论。

**为什么首轮漏了**：首轮的时钟是纯计时的（旬/季/年三层），**没有任何"阶段目标"层**。
首轮把"局面推进"完全交给势力之间的相互作用，而没有一个外生的、共享的时钟压迫。

**对本项目的价值**：
- 直接对审查 §4.4"苟活是稳态"：**集体不作为不能冻结时钟**。苟活方的边界会自动变成前线。
- 观测成本 30–50 token，**却把"模型不知道往哪打"这个问题整体消掉**——玩家/模型在任意时刻问"我现在该干什么"，答案是一句话，不需要读整张数值表。

**注意与 N5 的分工**（`GAMEPLAY-SLG-MOBILE.md` §6.3 讲得最清楚，必须两条都做）：

> **纪元超时（T3）解决"不打也会被推到前线"——这是动机问题。**
> **多数决（T7）解决"想打就一定打得动"——这是能力问题。**
> 审查 §3.1 与 §3.2 恰好一条是能力问题、一条是动机问题。
> **只修一条会退化成另一种苟活**：只给动机不给能力，模型被迫发动打不赢的进攻并学会规避；只给能力不给动机，模型保留能力而不使用。

### N12 ★★★★★【建议】剧本随机度体检（T-Span），以及"种子的影响随棋力上升而上升"

**机制**：跑模型之前，先用**确定性 baseline 策略**（六席同策略）在 200 个剧本种子上各跑 N 局，
测 Trimmed Span（各种子下先手胜率的最大最小之差，去掉最极端 5%）。

```
≤ 0.15    → 通过，可以开始跑模型
0.15–0.30 → 有条件通过：必须加大剧本数，且报告中不得出现单剧本结论
> 0.30    → 不通过。先改机制，不要跑模型
成本：零模型调用
```

**出处**：`GAMEPLAY-WESTERN-ANALOG.md` §8.5，
James Goodman, Diego Perez-Liebana, Simon Lucas, *Seeding for Success: Skill and Stochasticity in Tabletop Games*,
IEEE Transactions on Games, Vol. 17, No. 3, pp. 777–786, 2025（[arXiv:2503.02686](https://arxiv.org/abs/2503.02686)）。
参照系：Puerto Rico 的 T-Span 是 0.08，Poker 是 0.99。本项目应瞄准 Puerto Rico 那一端。

**为什么首轮漏了**：首轮的 `GAMEPLAY-AI-FRIENDLY.md` 覆盖了 CivRealm / SAGA / DSGBench / SPIN-Bench 等一批 LLM 基准，
但**没有覆盖桌游 AI 的评测方法论文献**。而"这个游戏到底测的是模型还是测的是开局"这个问题，
恰恰是桌游 AI 圈量化得最好的。

**对本项目的价值**：两条，第二条冲击首轮的一个假设。

**（一）它是一个零成本的、跑在烧钱之前的闸门。**
审查 §5.5 实算一轮 M1 评测（24 局）在旗舰档要 $3,570，全量版 $9,730。
在这个量级上，**先花零元确认"这个游戏测的是模型不是开局"，是纯理性的**。

**（二)【推翻一个常见理解】种子的影响随棋力上升而上升，不是下降。**
论文的发现：随着玩家棋力提高，随机种子的影响会**增大**；解释是更强的智能体更善于把好种子的优势兑现，
而弱智能体会把好牌打烂，反而掩盖了种子的影响。

> **推论：不能靠"等模型变强"来解决方差问题，必须靠机制与实验设计。**
> 这让首轮 §9.4 的"随机性放置表"从一条**偏好**升级成一条**硬要求**。

**（三）顺带纠正一个可能的成本幻觉：镜像配对的收益远小于直觉。**
论文 Table I：多数游戏做镜像对（同种子交换位置各打一次）相对独立种子，95% 置信区间只收窄 0.1–0.4 个百分点；
只有 Poker 这种"结果在发牌时就基本定了"的游戏才有数量级改善。
**所以不要指望席位轮换 + 镜像配对能把评测成本降下来。** 成本得靠机制省。

### N13 ★★★★☆【建议】缺口数取代兵力比

**机制**：

```
breaches = 基础缺口数(据点等级) + 器械投入产生的缺口
  属县 / 无墙据点 4    ← 立刻可突击
  郡治（有墙）     0
  关隘            0，且器械效率减半
器械投入（一个 O(1) 的档位选择，进动作集，占 SP）：
  不投 +0 / 冲车临车 +1（需 N 旬准备）/ 土山地道 +2（需 2N 旬，且地形允许）/ 火攻 +1（仅对木栅）
每旬判定（确定性）：
  守方能有效防守的缺口数 = ⌊守军单位数 / k⌋
  breaches > 可防守缺口数 → 破城；否则双方交换折损，守方每旬修复至多 1 个缺口
```

**出处**：`GAMEPLAY-WESTERN-ANALOG.md` §10.2，Oriental Empires（2017）手册 pp.20–21。

**为什么首轮漏了**：首轮的攻城直接沿用光荣本传的兵力比思路（`A/D ≥ 2.2`），
而 Oriental Empires 是**唯一一款西方人做的古代中国 4X**——首轮四份文档里没有它。

**对本项目的价值**：攻方的核心决策从"凑多少兵"变成"**投多少器械、等几旬**"——
这是一个时间与资源的取舍，不是一个乘法。动作集只 +1 条（器械档位，3–4 档），完全确定性，缺口数公开，攻守双方都能算出还需要几旬。

**必须写清它没解决什么**（`GAMEPLAY-WESTERN-ANALOG.md` 自己诚实地标了这一点）：
审查【C1】有两个成因，缺口数**只解了成因二**（破城门槛），
**成因一（军团规模上限 = 单郡戍兵）原封不动**。
换成缺口数之后仍会出现"器械备齐了、但派不出足够守住新占地的兵"的僵局。

> **这正是本轮两份文档互补的一个典型例子**：西方赛道解不了成因一（因为西方游戏根本没有这个绑定），
> 率土like 赛道用 `muster` 解了成因一。**两条必须一起上。**

### N14 ★★★★☆【建议】把首轮的"配战法"换成战法连锁

**机制**：战法不是"伤害 +15%"，而是**有触发前提与后效的动作**（击退 / 混乱 / 分断 / 侧击）。
会战由确定性引擎按顺序展开，一个战法的后效可能满足另一名武将战法的前提，自动连锁，**链越长收益越高**。

**出处**：`GAMEPLAY-KOEI-WIDE.md` §3，《三国志战记》Dynasty Tactics（光荣，PS2，2002/2003）的战法连锁。

**为什么首轮漏了**：首轮采纳的是**九代**的自动战斗（编队、指定目标、配战法，打起来不介入）。
九代的战法本质是数值加成。《三国志战记》不是本传，首轮的 `GAMEPLAY-RTK-SERIES.md` 只覆盖了本传 8/9/10/11/13/14。

**对本项目的价值**：用 `GAMEPLAY-MINIMALISM.md` 的语言说，这是把一条**加法规则（R3）**换成一条**乘法规则（S1 交互）**。

> 模型在出征前配置战法时，必须推理"这几个人的战法能不能串起来"。
> **这是纯规划，没有随机性可躲，正是 C5 要的区分度来源。**

**判定为【建议】而非【必须改】**：它需要一整套战法前提/后效表，M1 做不完。
但**它决定了 §4 武将系统的数据形状**（战法要有 `precondition` 与 `effect` 两个字段，而不是一个 `bonus` 数），
所以**数据 schema 现在就要留位**。

## 二、对首轮 7 条致命问题的新解法

**读法**：每条先复述审查的建议，再写本轮能否给出**更好**的解法。
本轮给不出更好解法的，明写"沿用审查建议"——**不为了显得有产出而硬凑**。

---

### C1【致命】攻城死锁：没有集兵手段 + `A/D ≥ 2.2` = 地图冻结

**审查的建议**（§3.6 一）：`campaign` 加 `muster: CommanderyId[] ≤3` 参数；围城粮耗 1.0 → 0.7；破城门槛降到 A/D ≈ 1.6。

**本轮给出了明显更好的解法。** 审查的三条改法全部作用在**同一个环节**（把兵力比这个乘法调松），
本轮从**四个不同环节**同时拆：

| 环节 | 机制 | 出处 | 判定 |
| --- | --- | --- | --- |
| **供给侧** | `muster` 独立动作（多郡抽调 + 集结窗口 + 可含盟友 + 集结地可见可被打断） | 三战 太守/集结（SLG-MOBILE §4.5） | **【必须改】** |
| **判据侧** | 多数决区域控制：`控制(州) = 州内直辖郡国最多`，推进不以攻下每城为前提 | 文明与征服（SLG-MOBILE §4.8） | **【必须改】** |
| **结算侧** | 缺口数取代兵力比 | Oriental Empires（WESTERN §10.2） | 【建议】（要重写 §5.5，M1 可先用审查的降门槛版） |
| **时限侧** | 围城有硬到期日 + 双向消耗（守方也耗粮） | 霸王的大陆 30 日时限（MINIMALISM §2.10-6） | **【必须改】**（首轮已有 6 旬窗口，但守方消耗未建模） |
| **投送侧** | `outpost` 前进基地 + `clause:transit` 借道，按"绕过邻接约束 3 倍价"定 SP | 率土 要塞 / 借地出征（SLG-MOBILE §4.4） | 【建议】M2 |

**为什么这比审查的改法好**，三条理由：

1. **审查的 `muster` 参数是隐藏的加法；独立动作是暴露的博弈。**
   集结地可见 → 对手有一季时间反应 → "我要不要为了打你而把后方掏空？你看见了会不会去打我的后方？"
   这是**纯推理、零随机**的博弈内容，而参数版没有。
2. **审查只解了"打得动"，没解"不必全打完"。** 多数决把"推进"与"全歼"解耦，
   同时让易主变得**可逆**（对手多占一个郡就能夺回州控制权），削弱滚雪球。
3. **同一个 `控制(州)` 谓词三处复用**（终局分档、邻接推进、观测摘要），是纯工程收益。

**一条必须记录的互补关系**：`GAMEPLAY-WESTERN-ANALOG.md` §10.2 明确承认，
西方赛道解不了 C1 的成因一（军团规模绑定出发郡戍兵），因为西方游戏根本没有这个绑定。
**而 `muster` 恰好来自率土like。本轮的两份文档在这一条上互补，缺任何一份都补不全。**

### C2【致命】综合分把"苟活"定为最优解

**审查的建议**（§3.6 二）：
```
综合分 = 0.70 × PI + 0.10 × 威望/100 + 0.20 × 私有目标达成率
被灭或被从属者：综合分 × 0.5（取代「存续度」）
```

**本轮给出了根本上更好的解法，而且是整轮调研里最值钱的一条方法论。**

`GAMEPLAY-SLG-MOBILE.md` §6.1 的判断：

> **首轮的"众怒"是一个修正性旋钮——它试图在事后惩罚领先者。审查 §4.3 证明了任何单一修正性旋钮都可以被绕过。
> 率土like 十年没有任何一个"众怒"式的旋钮，它靠的是让"围殴"和"苟活"在收益结构上就不划算。**

审查的改法仍然是**调权重**——它把 0.15 的存续度加项改成 0.5 的乘性罚项，方向对，但仍在同一个连续加权和的框架里。
本轮建议**换框架**：

| 层 | 改法 | 出处 | 判定 |
| --- | --- | --- | --- |
| **计分框架** | 绝对阈值分档 + 名额（不是加权和，不是排名） | 三战 霸业名额 | **【必须改】** |
| **保底档** | 丙档判据是"**打通 ≥2 个关隘 且 直辖郡国数 ≥ 开局数**"，不是"未失领土" | 三战 Q4 | **【必须改】** |
| **记分时点** | **按本局曾达到过的最高档记**，不看结算瞬时 | 率土 赛季评定 | **【必须改】**（零成本，收益大） |
| **产出来源** | 产出全在地上；不打就没有增长，内政不能补 | 全赛道 T2 | **【必须改】** |
| **扩张上限** | 挂在**累计攻取郡国数**上（不是威望——威望在首轮里是守成方永不掉的量） | 率土 领地上限（改造版） | 【建议】 |
| **时钟压迫** | 纪元推进 = 全服目标 OR 时限，集体不作为不能冻结时钟 | 鸿图 20 阶段 | **【必须改】** |
| **身份分流** | `withdraw` 归隐：把苟活变成公开的、不可逆的自我出局，**并变成可观测指标** | 率土 桃源军 | **【必须改】**（低成本） |
| **恐惧根源** | 流亡状态：失地不判出局 | 率土 流浪军 | 【建议】M1 做一半 |
| **资产侧** | 不作为也失血（治绩 − 虚耗 / 离乱时间表） | FoG:E + Attila | 【建议】M2 |
| **私有目标** | 逐个解锁 + 按完成个数计分；**删除全部纯守成条目** | Old World Ambitions | **【必须改】**（M1 直接设 0 亦可） |

**核心判断，写死**：

> **删掉"存续度"这一项。这条赛道十年没有任何一款给"活着"记分。
> 存续的价值应当完全体现为机会成本：活着才有机会拿档，丢了地就够不到门槛。**

### D1 / D2 / D3【严重】多方博弈退化 —— 这一节要推翻首轮的一整块

**审查的建议**（§4.5）：请附门槛改用直辖 PI、附庸只按 20% 计入、同一宗主最多 2 个附庸、
`cede` 单季 1 郡上限、众怒体量项去掉上限改 `100×(PI−0.15)/0.35`、行为项衰减加永久残留下限、奉诏折扣收到 60%、从属折扣收到 50%。

**本轮的判断：审查的改法是在修一个不该存在的东西。**

`GAMEPLAY-SLG-MOBILE.md` §6.2 给出了这条赛道的六条**结构性**反围殴机制（R1–R6），
其中**没有一条是"惩罚领先者"的旋钮**：

| # | 机制 | 为什么有效 |
| --- | --- | --- |
| R1 | 绝对阈值，非排名 | 打倒第一名不会增加你的州数。**围殴的直接收益为零** |
| R2 | 多档可多赢 + 名额可协商分配 | 目标不冲突时没有联合的理由；冲突时"分蛋糕"比"消灭对手"便宜 |
| R3 | **连地约束** | 远处的势力**物理上够不着**领先者 |
| R4 | 保底档需要进攻 | 弱势方有一条自己够得着的路，但那条路仍要求进攻 |
| R5 | 有限时间视野 | 报复的收益被截断 |
| R6 | **组织有到期日** | 只给永久联合加价，不给临时联合加价 |

**对 D3（众怒失效）的建议**【推翻】：

> **建议整体删掉"众怒"，改由 R1 + R3 + R6 三条结构性机制承担反滚雪球职能。**
>
> 理由：审查 §4.3 已实算证明"尊汉 + 奉诏 + 收附庸"这条路线让众怒**永远停在 60、永远不触发僭越**。
> 审查的修法（调三个系数）能堵住这一条路径，但堵不住下一条——
> **这是一个可被搜索的参数空间，而对面坐着的正是一批擅长搜索规则漏洞的模型。**
> `GAMEPLAY-SLG-MOBILE.md` §6.5(b) 给出了赛道级的经验证据：
> 率土的 380 人同盟上限被玩家用"多盟矩阵"绕过，官方的应对**不是修补上限，是用赛季重置定期清空 + 推出更小的组织单位分流**。
> 结论：**任何形式的"规模上限"都会被绕过，除非绕过它的通道本身也被封死。**

**R3 的重新定位【建议，零成本】**：
首轮把连地约束当成 C4（动作可枚举）和 C2（观测裁剪）的工具。本轮指出它**还是反围殴的主力**：

> **在一个只能打邻居的世界里，"所有人联合起来打第一名"在物理上就是不可能的——除非第一名恰好是所有人的邻居。**

这是一条免费收益，实现成本为零（现有代码已经用 `neighbors` 做了限制）。**建议把这条价值写进设计文档，避免以后有人为了别的理由放松连地约束。**

**对 D1（kingmaker）**：
- 绝对阈值 + 多档可多赢消掉了"比第二名多"这一类；
- `cede` 单季 1 郡上限（沿用审查建议）；
- **从属 / 请附整块在 M1 砍掉**（见 §四）。它是审查 D2/D4 两条问题的共同来源，且不是必需系统。
- 若 M2 恢复：**附庸 PI 不计入终局分档判据**（率土大盟经验——这类通道要么封死，要么让终局判据不认它）。

**【不确定】一条本轮没能定论的替代路线**：
`GAMEPLAY-WESTERN-ANALOG.md` §9.3 提出用 Twilight Struggle 的 **DEFCON**（共享的厄运钟 + 明确归责）
取代众怒——一个整数，所有人共享，谁推动了它是公开可归责的。
`GAMEPLAY-CN-INDIE.md` §7.4 提出用**联军系统**（超阈值时其余势力解锁"联合"动作）。
两者与"删掉众怒、只留结构性机制"是三条不同的路。
**本文倾向第一种（删掉），因为它状态最少、且有十年赛道证据；但另两条都没有被证伪。**
反面教材是明确的：Shogun 2 的 Realm Divide（无条件触发的全场围殴）是教科书级的失败案例（WESTERN §3.4）——
围殴必须**可降温、行为加权、且降温要付机会成本**。

### B1【致命】token 预算低估 1.7–3 倍

**审查的建议**（§2.3）：邻接全表移入系统提示并 KV 缓存、standings 给全 30 家分级、
己方武将不能裁、legalActions 收敛到 90 条 → 中期总量 7,631，把预算行改成"软目标 7,500 / 硬上限 10,000"。

**本轮给出了更彻底的解法，但代价是结构改动。**

`GAMEPLAY-WESTERN-ANALOG.md` §7.4 的**四道闸门**，每道砍掉一个数量级：

```
闸门 1（广度）：行政容量        → 进入动作集的郡从 105 降到 15–30
闸门 2（粒度）：决策对象换层    → 第一级条目从 O(郡数) 降到 O(战区数 + 3)
闸门 3（呈现）：提案通道        → 郡级的事仍然发生，但只以"下属提了什么"的形式出现（5–15 条）
闸门 4（频率）：资格轮替        → 单个决策点的模型调用数从 6 降到 2
```

**目标（建议写进验收标准）**：

| 量 | 首轮实测 | 审查改后 | 本轮目标 |
| --- | --- | --- | --- |
| 第一级动作条目数 | 62–195 | ≤90 | **≤12–20** |
| **六席之间条目数之差** | **3.1 倍** | 未提 | **≤1.5 倍** |
| 观测 token | 9,910–13,761 | 7,631 | ≤6,000（郡级明细 ≤1,200） |
| 单个决策点的模型调用数 | 6 | 2（批量查询） | 2 |

**"六席条目数之差 ≤1.5 倍"这一条是本轮新加的，且判定为【必须改】。**
审查实测六席开局第一级条目数是 62 / 138 / 155 / 172 / 186 / 195——差 3.1 倍。

> **这意味着六个模型面对的根本不是同一道题。这是评测口径问题，不只是成本问题。**

闸门 1 + 闸门 2 天然压缩这个差距，因为战区数与阶层数**不随版图线性增长**。

**加上一条质变改造【建议】**：把分层从 harness 层搬到规则层（N8 直辖半径）。
配合一条必须守住的分界（WESTERN §7.5）：

> **聚合决策，不要聚合后果。郡不再是决策对象，但郡必须仍然是后果对象，而且因果链要短到模型能自己推出来。**

具体做法：观测里对每个战区给出"上一季这条方针实际产生了什么"的**三行回执**
（户口变化、民心变化、粮秣变化 + 贡献最大/最小的两个郡的名字）。
比给出 30 个郡的完整明细便宜两个数量级，但保住了因果可读性。

**判定**：闸门 3（提案通道）【建议，M1 就做，纯 harness 改动，零新状态】；
闸门 1、2【建议，M2】；闸门 4（资格轮替）【不确定，必须先做实验 E-3】。

### E1【致命】M1 验收标准与预算差 20 倍

**审查的建议**（§5.6）：唤醒硬预算 36 次、工具查询改批量提交（4 次往返压到 2 次）、M1 砍到 16 季、
验收标准改成"单局 < 3M token，墙钟 < 90 分钟"。

**本轮的补充有两条，但都不完整。**

**（一）资格轮替（COIN）能把单个决策点的调用数从 6 降到 2**，
且副产品是时钟不再需要"要不要唤醒"的判断——牌面的次序就是答案（这同时打在 F2 上）。
**但 `GAMEPLAY-WESTERN-ANALOG.md` §6.5 明确拒绝替这个取舍下结论**：
它是一个"多次小决策 vs 少次大决策"的结构选择，两边都有合理先验，只能实测（实验 E-3）。
**本文沿用这个立场：【不确定】。M1 不做资格轮替，但 E-3 要排进计划。**

**（二）本轮给出了一条降低"验收成本"而非"对局成本"的路，价值被低估。**

`GAMEPLAY-MINIMALISM.md` 手法 8 引用海德堡研究的 Rep. 列（每项机制要多少局才能以 >75% 把握确认强者更强）：

| 结算性质 | 每组消融的最小局数 | 三组消融 + 对照的总预算 |
| --- | --- | --- |
| **确定性结算** | **5–10 局** | **20–40 局** |
| 掺了结算随机 | 70+ 局 | 280+ 局 |

> **这条把首轮"确定性结算"的论证闭环了**：确定性结算不只是"测得准"，
> 它让**整套验收方法本身变得负担得起**。
> 一个 60 季的对局若要跑 280 局才能验收一条机制，这套方法论就废了；跑 20–40 局，它就是每次改动都能用的常规工具。

**具体落地【建议】**：把 restricted play 消融固化成 CI 里的 `depth-ablation` 任务：
禁用 `scheme` 全类 / 禁用谈判通道 / SP 固定不随规模增长，三组各跑 5–10 局，
**每组的胜率下降幅度就是那条维度的深度贡献**。某一维禁用后胜率几乎不变 → 那条维度对深度的贡献是 0，删掉，省实现成本、省 token。

**外加一条排在最前面的【必须改】**：**E-1（T-Span 体检）必须跑在任何模型对局之前。**
零模型调用，直接回答"这个游戏测的是模型还是测的是开局"。
在一轮评测 $3,570 的量级上，这是纯理性的。

## 三、需要推翻的首轮判断

### 3.1 "九代范式最适合" —— **仍然成立，但两个组成部分要换**

**首轮原话**（骨架结论）："九代式自动战斗：编队、指定目标、配战法，打起来不介入"。

**本轮的证据支持这个骨架，且支持得比首轮更强：**
`GAMEPLAY-MOD-ECOSYSTEM.md` §6.2 的十二条"AI 显得蠢"里，
A2（添油：排队送人头）、A7（不会用攻城器械与地形）、A8（配兵/编队算法拙劣）三条都是**逐部队接口**的必然产物。
§6.4 的结论是结构性的："AI 和玩家共用同一套微操接口 → 规则引擎在这个粒度上只能用贪心启发式 → 贪心必然在全局上露怯"。
**这是对"打起来不介入"最有力的独立佐证。**

**但两个组成部分要换：**

| 首轮 | 换成 | 出处 | 理由 |
| --- | --- | --- | --- |
| **编队**（模型指定谁带哪支军团） | **编成偏好**（模型声明"重步为主、骑兵置侧翼、优先带擅守将"，求解器做全局最优匹配） | MOD §M4 | 比九代**更进一步**：求解器最优 = 无破绽 = 推理差异不被执行噪声掩盖。且省 token |
| **配战法**（数值加成） | **战法连锁**（有触发前提与后效，可自动串联，链越长收益越高） | 三国志战记（KOEI-WIDE §3） | 数值加成是加法规则（R3），连锁是乘法规则（S1）。**前者不产生深度，后者产生纯规划深度** |

**判定**：编成偏好【建议，M1 可做，省 token】；战法连锁【建议，M2，但数据 schema 现在就要留 `precondition`/`effect` 两个字段】。

### 3.2 "霸王的大陆的一城一令是更好的骨架吗" —— **先更正前提，然后：是，这一条推翻首轮**

**必须先更正一个流传很广的错误说法。**
`GAMEPLAY-MINIMALISM.md` §2.2 明确指出：

> "一城一月一令"**不准确**。准确的说法是：**全国一个月共 3–12 次操作机会，每次操作是一个 (城, 命令) 二元组。**
> 你可以把 12 次全砸在一座城上，也可以摊到 12 座城。

所以问题应该改问：**全局硬上确界的动作预算，是不是比首轮的 `SP = 5 + ⌊√n⌋ + 爵位 + 结转` 更好的骨架？**

**答：是。这一条【推翻】首轮 §2.2。** 三份本轮文档独立给出同一结论
（`GAMEPLAY-KOEI-WIDE.md` §9.1、`GAMEPLAY-MINIMALISM.md` 手法 1、`GAMEPLAY-SLG-MOBILE.md` §5.3）。

**理由三条：**

1. **首轮的 SP 没有硬上限**（实际可达 18），所以观测预算随版图**发散**。而 C4 要求动作集有界。
2. **硬上限同时是反滚雪球机制**：从 12 座城扩到 30 座城，命令书一枚不涨——**领土的边际收益递减到 0，每城人均决策带宽从 1.0 掉到 0.4，领先者被迫放弃大部分领土的发展。**
3. Old World 的 Orders 是**软上限**（随帝国规模平滑增长），只满足反滚雪球；**硬上限同时满足 C4 与反滚雪球。**

**具体改法**（`GAMEPLAY-MINIMALISM.md` 手法 1，本文完全采纳）：

| 首轮 | 改成 |
| --- | --- |
| `SP = 5 + ⌊√n⌋ + 爵位(0–2) + 结转(≤4)`，可达 18 | **`SP = min(5 + ⌊√n⌋, 12)`，结转 ≤2，爵位加成移出 SP** |
| 每条命令 SP 价 0–3 | **一律 1 SP，只保留 `campaign` = 2 一个例外** |
| 无"每郡上限" | **同一郡国一季最多 2 条命令** |
| — | **维护性动作（任命太守、调动武将、提升守备）移出预算**（霸王的大陆与 8 Empires 各自独立验证过这条） |

**"一律 1 SP"这一条单独说，因为它也是一条【推翻】。**
`GAMEPLAY-MINIMALISM.md` §9.3(二) 的论证：

> **价格表本身就是一条规则，而且是一条极容易出错的规则。**
> 定价表编码的是设计者对"什么强"的判断。判断错一格，模型就找到一条最优通路，深度塌一层。

审查独立发现的三条（F4 `scheme:断粮` 2 SP 删掉一支军团、F5 `abrogate`/`respond` 标价 0 SP、F1 `requestWakeAt` 无预算）
**是同一个病的三个实例**。霸王的大陆的做法是**把这条规则整个删掉**——所有命令一律 1 枚。
这样**深度只能来自"做什么"，不能来自"钻价格表"**。

**必须诚实记录硬上限的代价**（`GAMEPLAY-MINIMALISM.md` §2.11）：

> 命令书封顶 12，后期发展停滞，玩法收敛到"攒兵—攻城—攒兵"。
> **硬上限的代价是后期决策空间也一起缩了。本项目需要在后期换维度，而不是只缩预算。**

本项目的"换维度"通道：纪元推进（N11）改变地图状态、外交与名额协商（N2 的 Q3）、终局分档的门槛竞赛。
**这一条是设计风险，M1 之后必须回头验证。**

### 3.7 "578 名武将 + 五维 + 24 特技" —— **不是推翻，是判据升级**

`GAMEPLAY-MINIMALISM.md` 手法 4 给出的判据最锋利：

> **如果 578 名武将可以排成一条"谁更强"的序，那这 578 个数据点的深度贡献 ≈ log(578)。**
> 如果每名武将有一个离散**适性标签**，让"带谁"取决于"打哪"，深度贡献是一个**匹配问题**的规模。

首轮的五维 + 24 特技基本是可排序的（数值高的全面更好）。
**建议改成：数值保留用于计算，但所有能力开关改成阈值 + 离散适性标签**（手法 3 + 手法 4）。
出处：霸王的大陆的智力门槛（85/93/95/98/99 五档解锁计略）、忠诚门槛（≥90 不可离间、<40 可劝降、≤25 容易）、
兵种×地形机动力矩阵、**等级×部队构成表（L1 步5弩4骑1 → L8 步0弩4骑6，8 级武将一个步兵都没有）**。

阈值化的第二个好处直接打在评测上：

> **阈值把浮点变成布尔。** 模型不必算 `0.87 × 1.2 × (1 − 0.15)`，只需判断"过没过 93"。
> 这大幅降低了**算术错误污染推理质量测量**的风险——
> lmgame-Bench 的核心发现是：不加脚手架时几乎所有模型都聚在随机水平附近，因为感知/算术的噪声淹没了推理信号。

## 四、极简性的重新审视

### 4.1 首轮方案是不是过于复杂了？—— 是

用 `GAMEPLAY-MINIMALISM.md` §9.2 的七条反向条件（R1–R7）过一遍首轮方案，**已经中招三处**（该文 §9.3 自己点了名）：

| 条件 | 首轮的中招处 |
| --- | --- |
| **R1**（新规则提供支配策略） | SP 差别定价（审查 F4/F5/F1 是三个实例）；综合分把苟活定为最优（审查 C2） |
| **R2 + R3**（dud + 加法不是乘法） | §2.4 用 `C(98,5) ≈ 6.7×10⁷` 论证深度。**98 条里 `fortify` 8 + `levy` 8 + `scout` 9 = 25 条是逐郡展开的同类动作，彼此零交互**，对深度的贡献接近 log(8) 而不是 C(8,k) |
| **R7**（规则总量超过上下文预算） | 审查 B1 判定 token 低估 1.7–3 倍，本质上就是 R7 的一次触发。多出来的规则不只是无效，**它还会挤掉有效规则的注意力** |

**首轮 §2.4 的深度论证要换掉【必须改】。**
建议的替代论证（`GAMEPLAY-MINIMALISM.md` §9.3）：
不要用组合数论证深度，用**交互对计数**——数一数模板集里有多少对模板的**联合效果 ≠ 各自效果之和**。
如果这个数低于模板数（即平均每个模板只与 2 个模板交互），深度就不够，**要加的不是模板数，是模板之间的耦合**。

### 4.4 这 43 条够不够深？—— 用交互对计数自查

| --- | --- | --- |
| R14 集结 × R28 连通 | 集结路径要经过连通的己方走廊；借道盟友能不能信 | S1 交互 |

**16 组非平凡交互 / 43 条规则。** 平均每条规则参与 ≥2 组交互 —— 通过 §0.3 的裁刀。

| **S7** | 正交差异化 | 适性标签 × 地形 × 目标（R30×R21×R13）；郡的三个数不可互换 | **强** |

**S4 的处理是有意为之，必须说清楚**：
审查 §3.5 指出"确定性结算 + 状态隐藏 = 确定性的骰子"。
MINIMALISM §八 给出的学理依据是同一件事：
**状态不可见多数情况下只产生方差不产生深度**（因为未知量往往无法通过推理收敛，只能猜）；
**意图不可见才产生深度**（因为意图可以通过历史行为、当前局势、语言承诺来推理）。
所以 MERS 的选择是：**状态雾压到最低（十三档 + 点估计），意图雾拉到最满（密封 + 同时裁决）。**
