# 武将属性体系：设计方法论与可复现推导规则

撰写日期：2026-08-31
适用范围：Mind Arena 194 年剧本及后续剧本的武将数据生成
定位约束：本项目是**多个大语言模型同场对局的竞技场**，不是给人玩的三国游戏。
下文每一条设计决策都必须能回答"这对区分模型能力有什么用"。

---

## 零、结论摘要

| 问题 | 结论 |
| --- | --- |
| 几维 | **5 维能力（统率 / 武勇 / 谋略 / 政务 / 名望）+ 1 维倾向（义理）**。义理不是"强弱"，是行为约束 |
| 为什么不是 3 维 | 3 维会让"派谁去"退化成两次排序，绝大多数任命有唯一最优解，不构成权衡 |
| 为什么不是 8 维 | 多出来的维度在任何一次决策里都不 binding。光荣自己在《三国志9》砍掉魅力，就是"玩法不用到的维度是死维"的实证 |
| 数值来源 | **从公有领域史料的可计数特征推导**，不是打分。见第四节的证据编码表与五步管线 |
| 量纲 | 0–100 整数，能力维有效区间 6–99；分位映射到指定目标分布，长尾在高端 |
| 顶级人物 | 全池单维 ≥90 控制在 15–20 人次，≥95 不超过 5 人次；三维 ≥85 的"全才"≤2 人 |
| 特技 | 要，但**全局不超过 24 条、每人 0–2 条、绝不新增动作模板**，只收放已有模板的合法参数域 |
| 战法 | **不做**。战斗自动结算。战法是把模型拖进微操的最短路径 |
| 成长 | 极弱。战功年增上限 +1/年、终身 +6；史实卒年为默认死亡时间 |
| 数值是否能被手改 | **不能**。可改的只有两样：带出处的证据行，和规则权重。每个数字必须携带 `derivation` |

## 一、为什么不能照抄五维

三份现有文档（`docs/THREE_KINGDOMS_RESEARCH.md`、`docs/RESEARCH-2026-08-31.md`）都写了
"沿用光荣五维"，`lib/game/strategy.ts:11-28` 把 18 个君主的五维用 1–5 的整数写死在常量里。
这条路在本项目里有三个具体的坏处：

1. **法律边界**：三国题材不受版权保护，光荣的**具体数值表**受保护。抄"曹操统率 96"这种
   具体取值，和抄地图、头像、字体是同一类问题。`RESEARCH-2026-08-31.md` 第三节 E 已经把
   数值表列进"明确不能碰"。
2. **基准可信度**：这是一个用来给模型排名的竞技场。若属性来自设计者的主观印象，任何一次
   排名结果都可以被质疑成"数值偏袒了某种打法"。数值必须能被第三方按同一套规则复算出来。
3. **玩法错配**：光荣的五维是为它自己的玩法定的。武力在《三国志》系列里主要撑起一骑讨与
   战法伤害——本项目两样都不做。照抄五维会带进一个在本项目里**不影响任何结算**的维度，
   对模型来说那就是纯噪声。

所以真正要解决的问题不是"哪五个数"，而是：**如何从史料出发，可复现地推导出一套属性数值**。

## 二、横向调研：各作品的维度设计与取舍

### 2.1 光荣五维的官方定义

《三国志8 REMAKE》官方手册给出的定义（`RESEARCH-2026-08-31.md` 第四节已收录，此处补作用面分析）：

| 属性 | 官方作用面 | 作用面的性质 |
| --- | --- | --- |
| 統率 | 部队攻击、防御、行动顺序、补修效果 | 战役层 |
| 武力 | 战法效果、一骑讨强度、治安 | **战术层为主**（战法、一骑讨都是战斗内的） |
| 智力 | 战法效果、计略成功率、舌战、技术效果量 | 战役层 + 战术层 |
| 政治 | 开垦、商业、劝告效果 | 内政层 |
| 魅力 | 登用、同盟成功率 | 人事 / 外交层 |

关键观察：**武力的作用面几乎全在战术层**。一个没有一骑讨、没有逐队战法的游戏，
直接搬武力过来，它就只剩"治安"这一个弱挂钩。

### 2.2 五维之外，各代都加了什么

| 代 | 能力维 | 五维之外的层 | 这一层解决什么问题 |
| --- | --- | --- | --- |
| **9** | **統率 / 武力 / 知力 / 政治 —— 只有 4 维，没有魅力** | 兵法（歩兵/騎馬/弓騎/弩兵等系统，靠熟练值成长）、阵形（鱼鳞、鹤翼、锋矢…影响兵法发动率） | 9 代是全自动战斗（下令后部队自行推进），没有登用玩法与舌战，魅力无处挂钩，所以直接删掉。**这是"死维就该删"最硬的官方先例** |
| **10** | 五维 | 特技（约 45 种，可从他人处习得）、相性（0–149 的环状值，分主相性与个相性）、义理、性格（冷静/刚胆/直情/小心）、名声、一骑讨、舌战 | 10 代是"单武将扮演"，需要人际关系与个人成长的钩子 |
| **11** | 五维 | 特技（每人固定一条，上百种）、兵种适性（戟/弩/骑/兵器/水军，S/A/B/C 四档）、单挑、舌战 | 连续大地图 + 部队在图上直接交战，需要"这支部队擅长什么兵种"的表达 |
| **13** | 五维 | 特性（多条）、战法、绊（用亲书结交，设为"同伴"后获得同伴效果）、威名（宣示生存方式的称号，解锁不同活动范围） | 13 代回到"个人视角"，威名与绊是把人物关系变成玩法资源 |
| **14** | 五维 | 个性（多条）、**主义（覇道/王道/我道/割拠/名利/礼教 六种）**、政策、阵形、战法 | 主义把"人物立场"接到国家层：君主主义决定政策槽位构成，与君主同主义的武将其政策成本 −3（最低 1）。这是**属性驱动国家层战略**的最好范例 |

（9/10/11/13/14 的细节来自官方页面与攻略站，见文末来源。11 代特技总条数、14 代个性总条数
未逐条核实，此处只说"上百种/多条"，不给具体数字。）

值得抽出来的机制思路有三条：

- **9 代的删维**：玩法不用到的维度必须删，不是"留着也没坏处"。
- **11 代的兵种适性**：它其实是"把 4 个额外维度压缩成 4 个字母"的做法，比再开 4 个 0–100 的维度
  省得多，可读性还更好。本项目可以借这个思路，但把它折进特技，见 6.3。
- **14 代的主义**：属性不只影响"做得好不好"，还影响"能做什么"。这对 LLM 竞技场特别有价值——
  它把差异做在**可选动作集**上，而不是做在隐藏系数上，模型能直接看见。

### 2.3 《全面战争：三国》

CA 的五维完全另起炉灶，且与五行绑定（土/金/水/木/火，互相生克配色）：

| 属性 | 官方作用（据 Total War Wiki 与官方 Academy 资料） |
| --- | --- |
| Authority 威望 | 统御他人的能力。势力首领的 Authority 提升**其他人物的满意度**，并给随军部队士气加成 |
| Cunning 谋略 | 支持深入敌境的长期作战与围城，率领远程部队更高效 |
| Expertise 才略 | 工造与产业。降低建造成本，战场上闪避与防御更好 |
| Resolve 韧性 | 耐久。任太守时提升郡的人口增长 |
| Instinct 本能 | 作为军事指挥官的素质。降低征兵成本，近战更强 |

它真正的创新不在五维本身，而在**人物关系网**：满意度（satisfaction）、友谊与敌对、家族与
姻亲、人物职级（五种角色定位）、以及开局的两难抉择。人物会因为满意度低而叛离，太守身份
能提高他人满意度。也就是说：**属性之外还有一层"人际状态"，且这层状态是可被玩家操作的资源**。

本项目能借的：把"忠诚/叛离"做成一个**可被模型主动经营的资源**，而不是一个后台掷骰。
不能借的：TW3K 的具体属性名、五行相克配色、以及重型即时战斗层。

### 2.4 为什么是五维——真实的约束是什么

流传的说法是"五维平衡"，但从上面的横向对比看，真正的约束只有一条：

> **能力维的数量上限 = 游戏里互不重叠的"可任命岗位"数量。**

9 代砍到 4 维，因为它没有登用与外交玩法。10/13 代有大量人际玩法，于是在五维之外又加相性、
义理、绊、威名。11 代要表达部队专精，于是加兵种适性。**没有一代是先定维数再找作用面的。**

推论出三条判据，本项目直接采用：

- **判据 A（作用面）**：每一维至少绑定一个模型**能看见、且会改变其选择**的决策。只喂后台
  公式的维度不算。
- **判据 B（正交性）**：任意两维在全池武将上的皮尔逊相关系数 |r| < 0.6。超过就合并或重新
  定义证据来源。
- **判据 C（消融）**：把该维置为常数后重跑 N 场固定脚本策略的自对局，若最优任命方案的变化
  比例 < 10%，该维应删除。

判据 B 的实操要点：**正交性首先靠"证据来源不重叠"来保证，其次才靠统计检验**。
统率只从统兵记载取证，武勇只从个人格斗记载取证，两个特征集不相交，相关系数自然就压下来了。
如果先混着取证再事后调分，那是在粉饰共线性。

### 2.5 对 LLM 决策：维度是信息还是负担

三个成本，量级完全不同：

**token 成本（小）**：一维 ≈ 每名武将 3–4 个 token。240 人的全量花名册，每多一维约 +800 token。
按分层观察（7.1）只给"我方 + 已知敌将"，实际每回合多出的不到 200 token。可以忽略。

**注意力成本（大）**：模型在长列表上倾向于**按单一显著数字排序**，多维会被压成一维使用。
维数越多，被忽略的维越多。这不是 token 问题，是模型行为问题，且要靠实测发现。

**决策复杂度成本（中）**：k 维、m 个岗位的任命是一个指派问题。真正让决策变难的不是 k，
而是**是否存在非传递的权衡**。若五维高度相关（"厉害的人各方面都厉害"），k=5 的指派问题
实际难度和 k=1 一样。所以判据 B 不是洁癖，是决定这套属性有没有意义的关键。

配套两个必须做的实测：

- **换名对照测试**：把两名武将的属性块对调，名字不动，看模型的任命是否跟着数字走。
  跟着名字走 = 模型在用记忆里的光荣数值，而不是读观察。这会直接污染基准。
- **维度使用率探针**：给出两个候选（一个统率高、一个特技匹配当前任务），统计模型选择分布。
  某一维长期不被引用，说明它对模型是负担而不是信息，回到判据 C 复核。

## 三、本项目的维度决策

### 3.1 先确定岗位，再确定维度

本项目战略层实际存在的可任命岗位（依据 `THREE_KINGDOMS_RESEARCH.md` 的核心循环与
`scenario-194.json` 的势力/郡国结构）：

| 岗位 | 模型每旬要做的决策 | 需要区分武将的什么 |
| --- | --- | --- |
| 主帅 | 谁带主力军团、带多少兵 | 能带多大的军、行军与围城中会不会散 |
| 先锋 / 别部 | 谁去打野战、抢关、掠地、平叛 | 冲击力与破垒能力 |
| 军师 | 谁执行断粮、伏兵、火攻、离间；情报可信到什么程度 | 计略成败与识破 |
| 太守 | 谁治哪个郡 | 粮钱产出、屯田、民心、征兵上限 |
| 使者 / 招抚 | 谁去出使、招降、征辟在野 | 声望能打开哪些动作 |

五个岗位、五个互不重叠的能力需求。**五维不是抄来的结论，是从岗位表数出来的。**
与光荣重合是收敛的结果，但定义与作用面按本项目重写。

### 3.2 五维定义与作用面

数值范围 0–100。括号内是**该维在全区间上的效应幅度**——见 3.6 的幅度上限规则。

#### 统率 command

- 部队规模上限：`兵力上限 = 4000 + 统率 × 300`（统率 20 → 1 万；统率 95 → 3.25 万）
- 行军减员：`每旬非战斗减员率 = 基础 × (1.35 − 统率/145)`（幅度 ±35%）
- 守御：据点防御系数 `× (0.82 + 统率/280)`
- 断粮崩溃阈值：断粮后可维持的旬数 `= 1 + floor(统率/25)`
- 遭遇战基础战力系数

#### 武勇 valor

- 野战首合冲击：`冲击系数 = 0.85 + 武勇/330`
- 攻城拔垒：强攻时的己方折损 `× (1.3 − 武勇/160)`
- 突围：被围时脱出成功率
- 平叛与镇压：叛乱事件的压制效率
- **不做一骑讨**。武勇是部队层的系数，不是个人对决的胜负判定

#### 谋略 stratagem

- 计略成功率：`P = 基础 + (己方谋略 − 对方主将谋略)/220`，上下限 [0.05, 0.9]
- 识破：抵抗对方计略
- **情报质量**：己方观察中敌军兵力/位置的估计误差带宽 `= 基础带宽 × (1.5 − 谋略/140)`
  ——这是"信息不完全下的决策"这条测试目标的主要旋钮，见 7.2
- 伏兵、火攻、断粮道的效果量

#### 政务 admin

- 郡产出：`粮/钱产出 = 基础 × (0.78 + 政务/230)`
- 屯田开发速度、户口恢复速度
- 征兵上限：`可征兵额 = 户口 × 基础率 × (0.8 + 政务/260)`
- 城防修筑速度

#### 名望 renown

- 登用在野武将、招降 NPC 与中立势力的成功率
- 流民归附、灾后民心恢复
- **开启外交动作档次**：某些外交模板（如"倡合纵""奉诏讨逆"）只有派出名望 ≥ 阈值的使者才在
  合法动作集中出现——这是学 14 代主义的做法，把差异做在可见的动作集上
- 僭越/称帝一类政治动作的成本

### 3.3 一条不可逾越的红线：属性绝不裁决另一个模型的选择

名望**不能**提高"对方模型接受同盟"的概率。任何"我魅力高所以你必须答应"的机制，都是在用
数值覆盖对手的推理，会直接破坏"更强的推理稳定转化为更好结果"这条基准前提。

名望只作用于**引擎裁决的对象**：NPC 势力、在野人物、流民、民心、以及外交动作的成本与可用性。
模型之间的谈判永远由模型自己判断。

### 3.4 义理：把叛变从掷骰改成确定性资源

义理（0–100）不是能力，是行为倾向。它只进一条公式：

```
忠诚 = clamp(
    50
  + (义理 − 50) × 0.6          // 本性
  + 待遇分                      // 官职、封赏、驻地是否本乡，模型可操作
  + 战绩分                      // 势力近 12 旬的胜负、是否连败弃地
  + 君臣纽带分                  // 同乡 / 姻亲 / 故吏 / 举主，见 4.3 的 T 类特征
  − 猜忌分                      // 君主特技「猜忌」、同僚被诛
  , 0, 100)
```

规则：**忠诚 < 30 且持续 3 旬 → 该武将必然出走或叛变，且这个状态在观察里对其主公完全可见。**

为什么不掷骰：随机叛变会用运气淹没推理（违反"必须能分出高下"）。做成确定性阈值 + 完全可见，
它就变成一道资源管理题——模型要在"把好将放在前线"和"忠诚正在掉"之间权衡。这道题正好考
长期规划与风险判断。

194 年剧本里这条规则天然有戏：袁术麾下同时挂着孙策、周瑜与孙坚旧部（程普、黄盖、韩当、朱治），
按 `scenario-194.json` 的判定孙策本年尚未独立。孙策一系对袁术的君臣纽带分为负，忠诚天然低位——
接管袁术的模型第一道题就是"这支不属于我的精锐要怎么用、什么时候必须放弃"。这不是设计师编的
剧情，是史料落到规则上的自然结果。

### 3.5 不设的维度，以及理由

| 候选维度 | 不设的理由 |
| --- | --- |
| 魅力（独立于名望） | 与名望作用面重叠 90%。合并为名望 |
| 智力（独立于谋略与政务） | 光荣的"智力"同时管计略与技术，本项目按岗位拆成谋略/政务，智力就没有剩余作用面 |
| 兵种适性（4–5 个值） | 折进特技（水战/骑锋/弩阵/山地）。四个字母档也是四份 token，且大多数武将全是 B，信息量低 |
| 性格（分类值） | 不作为独立字段。有行为后果的部分折进特技（如「恃勇」「猜忌」），没有后果的部分不入数据 |
| 相性（0–149 环状值） | 光荣式相性是隐藏的合拍度。本项目用**可查证的关系**（同乡/姻亲/故吏/举主）替代，这些是硬史料，且能在观察里明写 |
| 潜力 / 成长率 | 本项目成长是次要的。留成长率等于请模型去做养成，偏离测试目标 |
| 寿命 / 体力 | 用史实卒年，见第八节 |

### 3.6 两条数值幅度规则

**幅度上限**：任何单一属性在其全区间（6→99）上，对任何一个系数的影响不得超过 **±35%**。
理由：若一维能造成 3 倍差距，牌面就直接决定胜负，模型的决策被淹没，基准失效。

**属性解释力目标**：用固定脚本策略（所有席位同一套规则 AI）跑 N ≥ 200 局，
统计"势力初始属性总优势"对胜负的解释方差，目标区间 **25%–40%**。
低于 25%：属性形同虚设，势力牌面没区别；高于 40%：开局就定胜负，模型比不出高下。
这是一个可以在 CI 里跑的硬指标，见第十节。

## 四、可复现的数值推导方法

### 4.1 原则

> **不给人打分，只统计文本里可计数的特征，再用一套公开、固定的变换把特征映射成数值。**

任何一个数字，都必须能回答"它是从哪几条史料的哪几个特征算出来的"。因此：

- 唯一可以人工编辑的产物是两样：**带出处的证据行**（`officer-evidence.jsonl`）与**规则权重**
  （`tools/build-officers.mjs` 顶部的常量表）。
- 成品 `officers-194.json` 由脚本生成，**任何人不得直接改动其中的数字**。改数字的唯一合法方式
  是补一条证据或改一次权重，然后全池重算。
- 每个数字携带 `derivation` 字段，列出贡献它的特征代码与原文引文。

### 4.2 语料与授权

| 语料 | 授权 | 用途 |
| --- | --- | --- |
| 陈寿《三国志》+ 裴松之注 | 公有领域（ctext.org 有全文） | 主语料 |
| 范晔《后汉书》（含司马彪《续汉书》诸志） | 公有领域 | 汉末人物、郡国建置、官职 |

**不是**把结果往那边靠。

### 4.3 证据编码表（codebook）

每条证据是一行 JSONL：`{ person, code, count, cite, source, layer, note }`。
`layer` ∈ `hist` | `peizhu` | `yanyi`。`cite` 必须是原文片段，不是转述。

编码原则：**判定标准必须写到"两个人独立编码会得到同一结果"的程度**。
上线前抽 30 人做双人独立编码，Cohen's kappa 目标 ≥ 0.8，不达标就改判定标准。

### 4.4 五步管线

```
① 抽取   ctext 原文 → 分人切段 → 半自动打特征标 → 人工复核 → officer-evidence.jsonl
② 原始分 raw_s = Σ (权重 × 分层权重 × min(计数, 上限))
③ 收缩   z_s = raw_s / R_s        R_s = 全池 raw_s 的 p95（由数据算出，不手设）
         ẑ_s = (n_s · z_s + k · z_tier) / (n_s + k)      k = 3，n_s = 该维证据条数
④ 映射   按 ẑ_s 在全池的分位，查 5.1 的目标分布表，线性内插取整
⑤ 封顶   final_s = min(mapped_s, tier_ceiling)
```

第 ④ 步是这套方法能站住的关键：**分位映射之后，权重的绝对值不再影响结果，只有权重的相对
大小影响排序。** 于是"献策应验该给 8 还是 9 分"这种争不出结果的问题，退化成"献策应验是不是
比献策被采纳信号更强"——这个是可以讨论清楚的。

### 4.5 传记体量分层，与按书别归一化

传记体量决定**先验中心**与**数值上限**。理由很直接：史料只给了一个人 80 字，就没有依据说
他是天下第一名将。

| tier | 判定 | 先验 z_tier | 数值上限 |
| --- | --- | --- | --- |
| T1 | 本传字数在其所属书内 ≥ p90 | 0.62 | 100 |
| T2 | 本传字数 p70–p90 | 0.55 | 92 |
| T3 | 本传字数 p40–p70，或详附传 | 0.48 | 84 |
| T4 | 简附传 / 散见累计 ≥ 100 字 | 0.42 | 74 |
| T5 | 仅一两处点名 | 0.36 | 66 |

**必须按书别分别取分位**：《蜀书》因蜀不置史官而普遍简略，直接用全语料字数排名会系统性
压低蜀汉人物。所以分位在《魏书》《蜀书》《吴书》《后汉书》四个池内**各自**计算。
裴注字数按 0.5 折算后并入本传字数。

这是一条容易被忽略但影响全局的规则：不做书别归一，整套数据会有一个结构性偏差，
而这个偏差正好落在"刘备席位"上。

### 4.6 收缩估计：为什么记载少不等于废物

第 ③ 步的 `ẑ = (n·z + k·z_tier)/(n+k)` 是标准的经验贝叶斯收缩。效果是：

- 证据多的人（n 大），结果几乎完全由证据决定
- 证据少的人（n 小），结果被拉回该 tier 的先验中心，而不是掉到 0
- k = 3 意味着"三条证据"才与先验等权，这个值应在敏感性分析里一并扫描

同时输出 `confidence`：n ≥ 6 为 `high`，3–5 为 `med`，≤2 为 `low`。
`low` 的属性在观察里可以以区间形式呈现（见 7.2），这既诚实又正好成为玩法。

### 4.7 敏感性分析与不稳定标记

对全部权重做 ±30% 的均匀随机扰动，重跑管线 200 次。对每人每维：

- 中位数作为发布值
- p10–p90 带宽 > 6 分 → 标 `unstable: true`，并在数据里同时给出区间
- 若某人某维在扰动下跨越 tier 上限，说明该人证据结构异常，进人工复核队列

这一步同时给了两样东西：数据的可信区间，和 7.2 里"敌将属性以区间呈现"的天然素材。

### 4.8 史实 / 演义 / 游戏原创，三层分明

| 层 | 处理 |
| --- | --- |
| **史实**（正史正文 + 裴注） | 进主分。默认唯一生效层 |
| **演义**（明嘉靖本《三国志通俗演义》） | 用**同一套编码表**跑演义文本，得到 `yanyiRaw`，映射后与史实值之差截断到 **±8**，写入 `yanyiDelta`。剧本配置 `layer: "hist" | "hist+yanyi"` 决定是否叠加。永不静默混合 |

### 4.11 一个走完全程的例子：高顺

高顺是个好例子——**史料极薄，但共识评价不低**，正好检验管线在稀疏证据下的行为。

可用证据（全部出自《三国志·吕布传》及裴注引《英雄记》，故 layer 多为 `peizhu`，权重 0.7）：

| 代码 | 依据 | 计数 | 原始贡献 |
| --- | --- | --- | --- |
| M2+M3 | 破刘备、破夏侯惇，二役皆胜 | 2 | (2×2.5 + 2×2) × 0.7 = 6.3 |
| M5 | 中郎将 | 1 | 2 × 1.0 = 2 |

| Y1 | 城陷被执，不降被杀 | 1 | +30 → 义理高位 |

`raw_command ≈ 14.6`，`n_command = 4`。tier：无本传，附见 + 裴注累计约 150 字 → **T4**，
`z_tier = 0.42`，上限 74。

最终统率取决于 `R_command`（全池 p95 的原始分），只有跑完全池才能定。可以先说清楚的是：
收缩把他从"证据稀疏"拉回 T4 先验附近，tier 上限 74 挡住了他冲进第一梯队，
而 M6/M8/S2 三条会把他抬到 T4 池的上沿。**这个结果多半会低于商业游戏给他的数字——
这正是"以计数为准"应有的样子。**

（不在此处给出具体数值，因为它必须由全池计算得出。凭手算给一个数，就回到了凭印象打分。）

## 五、数值区间与分布

### 5.1 目标分布表

按全池分位查表，线性内插。五维形状不同，理由在右栏。

| 分位 | 统率 | 武勇 | 谋略 | 政务 | 名望 |
| --- | --- | --- | --- | --- | --- |
| p100 | 97 | 99 | 98 | 96 | 97 |
| p99 | 92 | 93 | 92 | 90 | 90 |
| p95 | 84 | 85 | 83 | 82 | 82 |
| p90 | 78 | 79 | 76 | 76 | 77 |
| p75 | 68 | 68 | 64 | 66 | 67 |
| p50 | 55 | 52 | 50 | 52 | 55 |
| p25 | 43 | 34 | 38 | 40 | 45 |
| p10 | 34 | 22 | 30 | 32 | 38 |
| p05 | 29 | 15 | 26 | 27 | 34 |
| p00 | 14 | 6 | 12 | 8 | 20 |

形状差异的理由：

- **武勇跨度最大、地板最低**：文官的个人格斗记载确实是零，不该人为托底
- **名望地板最高**：能进史书本身就是一种名望，池内没有"名望为 0"的人
- **谋略中位偏低**：大多数有传人物没有献策记载，中位不该虚高
- **统率最均匀**：统兵是汉末最常见的经历

### 5.2 池子规模

| 层 | 人数 | 说明 |
| --- | --- | --- |
| A 级（关键武将） | 约 60 | 全量属性 + 特技，常驻观察 |
| B 级（有传可考） | 约 120 | 全量属性，按需进观察 |
| C 级（散见记载） | 约 60 | 全量属性，主要作为太守与补充兵将 |
| **合计** | **约 240** | 首版目标。可随剧本扩展 |

240 是从 105 郡国 / 31 势力倒推的：主要席位每家 8–20 人，中小势力 2–6 人，在野 30–40 人。
比《三国志》系列典型的 700–1000 人少，比现有实现的 18 人多一个数量级。
少的理由是 token 与注意力：模型能真正区别对待的人物数量有上限，堆到 800 人只会让它按名字挑。

### 5.3 顶端稀缺度约束（audit 断言）

| 断言 | 目标 |
| --- | --- |
| 单维 ≥ 95 的人次 | ≤ 5 |
| 单维 ≥ 90 的人次 | 15–20 |
| 单维 ≥ 85 的人次 | 45–60 |
| 两维 ≥ 90 的人 | ≤ 5 |
| 三维 ≥ 85 的人 | ≤ 2 |
| 五维之和 ≥ 360 的人 | ≤ 3 |
| 五维之和 | 均值 250–265，标准差 45–60 |

顶端必须稀缺，否则"我手上这一个 90 该放在哪条战线"这道题不成立——而这道题正是属性
存在的全部理由。

违反断言时的处理顺序：先查证据是否重复计数 → 再查权重是否失衡 → 最后才考虑调目标分布表。
**不许对个人做例外处理。**

### 5.4 长尾方向

分布必须在**高端长尾、低端厚实**：少数极强、大量中庸。这不是审美，是可玩性要求——
若属性接近正态且方差小，所有势力的牌面趋同，第 3.6 节的"解释方差 25–40%"就落到 0，
不同势力就没有区别，也就测不出"如何用手上的牌"。

## 六、特技层

### 6.1 要不要

**要。** 五个 0–100 的数字只能表达"强弱"，表达不了"擅长什么场合"。没有特技，
高统率的人在任何地形、任何季节、任何任务上都是同一个最优解，任命就退化成排序。

但特技也是动作空间爆炸的头号风险源。所以先立三条规矩。

### 6.2 三条不炸动作空间的规矩

**规矩一：特技绝不新增动作模板。**

动作模板集是**固定的全集**（首版目标 ≤ 24 个模板）。特技只做两件事：
改系数，或**放开/收紧某个模板在某个参数上的合法域**。
于是 validator 输出的合法动作集永远有限、永远可枚举。

举例：「说客」不是新增一个"说客动作"，而是让 `envoy` 模板的 `proposal` 字段
多出 `倡合纵` 这个取值。模板数不变，枚举照样能做。

**规矩二：不做战法。**

战法是逐队、逐回合的战斗内选择。一旦引入，模型每场仗要做几十次微观决策，
直接违反"决策必须是高层战略"。战斗由引擎按属性、兵力、地形、补给确定性结算，
模型的决策点在**出兵前**：派谁、带多少、走哪条路、什么姿态。

**规矩三：姿态（将令）代替战法。**

`march` 模板带一个 `posture` 字段，取值固定 6 个：

| 姿态 | 效果 | 代价 |
| --- | --- | --- |
| 强攻 | 攻击 +20% | 折损 +30% |
| 持重 | 折损 −25% | 推进速度 −30% |
| 急行 | 速度 +40% | 遭遇战首合 −20%，粮耗 +30% |
| 掠食 | 就地征粮，粮耗 −60% | 该郡民心 −15，名望 −2 |
| 固守 | 防御 +30% | 不推进 |
| 佯动 | 敌方情报误差 +50% | 无实际推进 |

特技通过"某姿态对该主将是否可用 / 代价是否减免"来发挥作用（如「疾行」使急行的
遭遇战惩罚减半）。姿态是 `march` 上的一个字段，不是六个新动作。

**动作枚举规模的硬预算**：单势力单旬的合法动作枚举文本 **≤ 3000 token**。
超了就收紧参数域——出兵目标只列相邻且可达据点、兵力只给 4 档（三成/五成/七成/全军）
而不是连续值、可选主将只列在该据点的。这个预算是协议层的硬约束，属性与特技设计不得突破。

### 6.4 派生规则的纪律

特技与属性走**同一套证据**、同一套纪律：派生条件全部写成对证据编码的布尔表达式，
由 `tools/build-officers.mjs` 自动判定，**不许手工挂特技**。
数据里每条特技携带触发它的证据代码。

若某条特技全池只有 0–1 人触发，说明条件设窄了；若超过 25 人触发，说明设宽了。
两种情况都回去改条件表达式，不改个人。

## 七、属性怎么进入观察

### 7.1 分层与序列化

三档可见性：

| 档 | 内容 | 粒度 |
| --- | --- | --- |
| 己方 | 全部麾下武将 | 精确值 + 特技 + 忠诚 + 驻地 |
| 已接触敌方 | 交过战或有外交往来的势力的 A 级武将 | **区间值**，无特技，无忠诚 |
| 其余 | 不可见 | 仅在战报中事后出现 |

紧凑序列化（约 20 token/人）：

```
荀彧|41/14/88/93/86|义88|举贤,抚民|忠95|陈留|在任
张辽|72/86/61/38/55|义62|骁锐,骑锋|忠48|下邳|在任
```

敌方：

```
夏侯惇|统65-78/武70-84/谋?/政?/望?|谯|主将
```

**属性效果说明表只在系统提示里给一次**，不随每回合观察重复。每回合观察里只出现数字。
这是 token 预算上最划算的一刀。

### 7.2 情报误差：把谋略接到"信息不完全"上

敌将属性的区间宽度由三样东西决定：

```
带宽 = 基础带宽 × (1.5 − 我方主将谋略/140) × 情报等级系数 × (1 + 该值的 unstable 惩罚)
```

四层含义都能对上：谋略高的势力看得更清；情报投入有回报；我们自己也不确定的数值
（4.7 标了 `unstable` 的）本来就该给区间；模型必须在信息不全时做判断——这正是要测的能力之一。

### 7.3 派生角色分不要藏

引擎会给每名武将附一组确定性的角色适配分（主帅/先锋/守将/太守/使者），并**明写在观察里**。

理由：这些分数是属性的确定性函数，任何模型都能自己算出来。藏起来只会让基准在测心算，
不是在测战略。真正要测的是**在稀缺下怎么分配**——只有两个能打的人，四条战线，派谁去哪儿。
这道题不会因为给了适配分而变简单。

## 八、成长、死亡与入池

本项目"武将成长是次要的"，所以这一节只给最小规则：

| 项 | 规则 |
| --- | --- |
| 战功成长 | 每维每年最多 +1，终身累计 +6。触发条件为该维绑定的岗位上取得明确战果 |
| 年龄折扣 | 剧本开始时未满 20 岁者，当前值 = 基准 × 0.85，每年回升，20 岁归位。**默认关闭**（可复现性优先），可在 Persona 模式开启 |

## 九、194 年的牌面：七道不同的考题

属性存在的意义是"让不同势力的初始牌面不同"。用项目现有数据看，194 年岁末的牌面差异
已经足够极端——下表的郡数与人口来自 `scenario-194.json` × `commanderies.json`
（人口是《续汉书·郡国志》140 年数字，只作相对量级参照）：

| 势力 | 郡 | 口 | 属性侧的牌面 | 这一席在测什么 |
| --- | --- | --- | --- | --- |
| 曹操 | **1** | 66 万 | 全图最深的人才班底（荀彧、荀攸、程昱、夏侯惇、夏侯渊、曹仁、于禁、乐进、典韦…），几乎没有地 | **人才过剩、土地极度稀缺**：怎么把人换成地，且要在被吕布压制的一年内翻盘 |
| 袁绍 | 13 | 830 万 | 国力第一，谋士群名望高但谋略分散（沮授、田丰、审配、逢纪、许攸、郭图），君主谋略受锚点压制 ≤70 | **资源过剩、决策带宽稀缺**：家底最厚，最容易赢也最容易被拖垮 |
| 刘表 | 7 | 627 万 | 政务与名望好、统率弱（蒯越、蒯良、蔡瑁、黄祖、文聘） | **守成型牌面**：四面皆可成敌，考"什么时候必须放弃中立" |
| 刘璋 | 9 | 497 万 | 地利 + 政务，统率与谋略薄 | **地形优势能撑多久**：出川困难，考长期规划与何时下注 |
| 刘备 | 6 | 304 万 | 两三张顶级牌（关羽、张飞）+ 极薄的政务与财政 | **少而精怎么用**：一个 90 只能在一条战线上 |
| 吕布 | 6 | 296 万 | 武勇极端、政务近底、麾下义理参差（张辽、高顺 vs 侯成、宋宪、魏续） | **把一把锤子变成一个国家**：还要防内部崩解 |
| 袁术 | 2 | 253 万 | 手里攥着不属于自己的孙氏精锐（孙策、周瑜、程普、黄盖、韩当） | **忠诚是可耗尽资源**：3.4 的忠诚阈值在这里最有戏 |

七道题，七种能力：资源转化、决策带宽、外交时机、长期投资、稀缺分配、内部治理、人事风险。
**这就是"考验模型如何用手上的牌"的具体含义**，也是属性体系必须服务的唯一目标。

补一条赛制上的结论：**牌面不平衡不该靠改数值来修，该靠赛制修。**
Benchmark 模式采用席位轮转（每个模型把每个席位各打一遍），势力强弱就从噪声变成了控制变量。
一旦接受这条，我们就不必为了"平衡"去动史料推出来的数字——这对本项目至关重要。

## 十一、明确的边界

**可借鉴的机制思路**

- 《三国志9》：玩法用不到的维度就删（砍掉魅力）
- 《三国志11》：把多个专精压缩成少数标签（兵种适性 S/A/B/C），而不是新开维度
