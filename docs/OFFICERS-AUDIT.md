## 一、总体结论

这份名录的质量在同类数据里属于上乘，几个通常最容易出错的地方都做对了：

- **时点敏感人物基本无误。** 孙策系于袁术、诸葛亮与司马懿留空、关羽张飞随刘备在徐州、张辽属吕布、徐晃属杨奉、陈群为刘备属吏、马超十九岁在凉州从父、陆逊十二岁在庐江围城中、周瑜二十岁在舒县尚未渡江——这些都对。
- **演义与正史分得干净。** 28 个虚构人物全部 `fictional=true` + `certainty=romance`，出处只记回目；貂蝉、周仓、关索、潘凤、武安国、俞涉、杨松、邢道荣、木鹿大王、兀突骨、祝融夫人、吴国太、南华老仙、紫虚上人等一个不漏。关平正确标为亲子（《关羽传》"羽子平"）而非演义的养子说；孙夫人条注明"尚香之名出后世戏曲小说"；大小桥条注明"史止称桥公两女"；华雄条注明斩之者为孙坚而非关羽；士仁条注明"演义作傅士仁"。
- **机械校验全部通过。** 无重复 id、无同一人两录、`affiliation194` 全部能在 scenario-194 找到、`commandery` 全部能在 commanderies 找到、`roles` 全部在 roleVocabulary 内、`fictional` 与 `certainty=romance` 一一对应、无"卒于 194 前却仍有归属"或"生卒年倒置"。
- **人数远超 300**：578 人，其中 194 年有归属者 307 人。

问题集中在一处：`affiliation194` 被当成了两种东西用。meta 定义它是"此人在为谁做事"，但实际有一批人是按**地理位置代管**填的——人在某势力的地盘上，就填了那个势力，哪怕他此时未仕、事迹无考，甚至正在跟那个势力打仗。下面第二节修掉了其中"填成了敌人"和"自述未仕却仍有归属"的部分，第三节把剩下的成规模列出来供决策。

## 三、存疑待查（未改，供决策）

### 3.1 系统性问题：`affiliation194` 的"地理代管"用法

meta 定义 `affiliation194` 是"此人在为谁做事"，但下列各组人的 historicalNote 明写"本年事迹无考"，归属是按其**后来**的活动区域或**后来**的从属关系倒填的。这不是史实错误，是字段语义问题，但对 LLM 竞技场影响不小：模型 observe 到的初始阵容会凭空多出一批史无明据的可用武将，而且分布不均。

| 组 | 人物 | 问题 |
|---|---|---|
| 关中十部 → hansui / mateng | 程银、侯选、李堪、梁兴、张横、马玩、成宜、杨秋 | "关中十部"之目成于建安十六年（211）渭南之役，194 年这批人与韩遂马腾是否有从属关系，史无一字 |
| 汉阳士人 → mateng | 姜叙、尹奉、赵昂、王异 | 这四人是建安十八年举义讨马超的核心，194 年在乡里，与马腾无涉 |
| 南中大姓 → nanzhongyi | 孟获、雍闿、爨习、高定、孟琰、朱褒 | 全部注"本年事迹无考"，事迹最早都在建兴元年（223）以后，相隔近三十年 |
| 氐羌部帅 → qianghu | 阿贵、强端、千万 | 同上，事迹在建安中后期 |
| 同处一地 → baibo | 王邑 | 本条注已自陈"此人非白波之属，因同处河东姑并列" |

**建议**（三选一，不要混用）：
1. 保持 `affiliation194` 严格等于"在为谁做事"，上述人一律 null，游戏里按登场年份逐步解锁；
2. 增设 `sphere194` 字段专记"人在谁的地盘上"，与 `affiliation194` 分离；
3. 增设 `affiliationCertainty: attested | inferred | placeholder`，让消费方自己决定要不要用。

考虑到这个项目要用统一协议给多个模型发同样的状态摘要，我倾向第 3 案：信息不丢，且模型能读到"这条归属是推测的"。

## 四、建议补充的人物

按对 194 剧本的重要性排序。前 8 人建议优先补，其中 3 人已经被别的条目提到过却本身不在表里——这种"注里有人、表里无人"是最该先补的。

### 第一优先（本年有事，且已被其他条目提及）

1. **马日磾** — 太傅、录尚书事，奉使关东。兴平元年在寿春被袁术夺节留置，忧愤呕血而死。这是本年朝廷与袁术关系的关键事件，人却不在表里。
2. **李乾** — 乘氏李氏部曲帅，本年为吕布所杀。**李典条已写"从父李乾本年为吕布所杀"**，其人却不在表。可连带补其子**李整**（领其众）。
3. **赵昱** — 陶谦别驾、广陵太守，本年为笮融所杀。**笮融条已写"本年杀广陵太守赵昱"**，其人却不在表。

### 第二优先（本年在场且有史料）

4. **田畴** — 刘虞使者，本年率宗族入徐无山中，后为曹操向导定乌桓。幽州线在鲜于辅、阎柔移出公孙瓒之后更需要他。
5. **刘和** — 刘虞之子，本年在袁绍处，是幽州复仇一线的名分所在。
6. **孙静** — 孙坚弟，本年在富春合宗族乡曲五六百人自守，是孙策渡江后定会稽之役的主谋。
7. **祖茂** — 孙坚亲近将，见《孙破虏传》（非演义人物）。现表孙氏旧部收了程普、黄盖、韩当、朱治、吕范，独缺此人。
8. **李通** — 本年在朗陵、江夏之间聚众，后为曹操南面屏障。

### 第三优先（补齐既有分类的缺口）

### 收录口径的一处不对称

魏晋末人物收得很全（钟会、邓艾、杜预、卫瓘、贾充、王濬、羊祜、石苞、王肃、傅嘏、夏侯玄、何晏、管辂），蜀汉末也齐（谯周、郤正、罗宪、霍弋、樊建、董厥、张翼、张嶷），**唯独吴国后期成片缺失**：孙峻、孙綝、滕胤、吕据、留赞、朱异、施绩、钟离牧、陆凯、张悌、濮阳兴、韦昭、华覈、吾粲一个都没有。

这不是史料问题，是收录口径没定：如果名录定位是"全时段人物库"，这批要补；如果定位是"194 剧本 + 后续可登场者"，那么反过来说，魏晋末那批（钟会 225 生、杜预 222 生、卫瓘 220 生）在一个 maxTurns 有限的对局里也永远登不了场，收得偏多。**建议先定 scope，再决定补哪边。**

## 六、可脚本化的校验清单

下列检查这次都是一次性跑的，建议固化成 `tools/` 下的校验脚本，改数据时回归：

1. `meta.count === officers.length`
2. id 唯一、匹配 `^[a-z0-9_]+$`
3. `affiliation194` ∈ scenario-194 的 factions[].id ∪ {null}
4. `commandery` ∈ commanderies[].name ∪ {null}
5. `roles[]` ⊆ meta.roleVocabulary
6. `fictional === (certainty === 'romance')`
7. `origin` 的州名前缀 === `commanderies[commandery].zhou`；且 `commandery` 出现在 `origin` 里（塞外条目除外）
8. `birthYear <= deathYear`；`deathYear - birthYear <= 100`
9. `deathYear < 194` 或 `birthYear > 194` 者，`affiliation194` 必须为 null
10. historicalNote 里"本年 N 岁"与 `194 - birthYear + 1` 一致
11. historicalNote 含"未生 / 未仕 / 在乡里 / 事迹无考"时，`affiliation194` 应为 null（或标 `affiliationCertainty=inferred`）
12. 同名不同人（马忠、张温）需要白名单，避免被查重误报

第 9、10、11 条正是这次抓出实质问题的三条，最值得固化。
