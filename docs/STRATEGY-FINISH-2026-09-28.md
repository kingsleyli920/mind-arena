## 1. 后期对局能够自然统一

玩家对局仍然没有季数上限，胜利判据仍为控制 11 州或成为最后一个有效势力。
测试的 256 季预算只会停止测试循环，不会给未统一的对局强行判胜。

本轮修复：

- 增加相邻己方郡调兵。每季合计最多调出来源兵力的一半，保留目的地容量，不能同季接力转运。
- 修正武将所属判断：收编、归降后的武将能由新主调任，原主不能把已驻敌城的将领调回。
- 围攻预测在折损后判断封锁，并使用实际规模耗粮规则；明确增援与不发生外部干预的假设。
- 玩家机器人会组织后方调兵、前线配将及跨季围攻，避免同源多路出兵、反复调将和无效集结。
- 自动补兵先检查军饷，避免内地自动增兵后全军反复欠饷。
- 新增后期归降条件：控制 7 州、疆域至少为相邻目标的两倍时，可劝降超过 8 郡的地区势力。
  仍需概率判定并遵守拒降冷却；归降后接管兵将与国库，取消旧势力当季剩余命令。

单纯调整机器人、收入或统兵上限的试验仍会形成地区对峙，因此没有保留试验中的
收入和统兵数值调整。后期归降是这次促成收敛的明确规则变化，向所有控制者开放。

## 2. 两种低价 AI 连续四季实测

先用免费机器人把 `strategy-session-2` 推进到内部 turn=24，再将袁绍交给
`z-ai/glm-5.3-flash`、刘璋交给 `openai/gpt-5-nano`，其余势力保持免费机器人。
不改兵力、金钱或所有权。通过正常 `advanceSeason → modelDecide → OpenRouter → resolve`
路径推进 turn=24–27，共 8 个模型决策、11 次上游尝试。未以机器人替代失败模型。

结果：8/8 决策成功返回结构化结果，67 条命令通过准入，3 条因郡令或行动点约束被丢弃。
两席后三季的 6 次真实请求均核对到了前季计划；丢令反馈也进入后续观测。

| 席位与模型 | 实际跨季行为 | 四季后的疆域 | 返回费用 |
| --- | --- | --- | ---: |
| 袁绍 · GLM Flash | 解渔阳之围；次季攻下代郡；随后夺居庸关、攻下济阴；末季应对多线围城 | 22→24 郡，2→2 州 | $0.007065595 |
| 刘璋 · GPT-5 nano | 夺褒斜道；续攻拿下安定、右扶风；后续调兵与争夺关隘 | 16→17 郡，1→2 州 | $0.006153450 |

战报验证了计划与实际行动有关联。最终领土净变化包含敌军反攻，不等于模型指令的总攻取数；
接管前已在途的部队也会继续执行，不能将所有战果归给模型。

### 成本与延迟

- 本轮返回费用合计 **$0.013219045**。这是成功响应报告的费用，不是账单精确总额。
- GLM 首次决策耗时 256.3 秒，含一次重试，首轮疑似超时；日志没有保留该次失败原因，
  也无法确认该次尝试是否另行收费。
  原始报告 `unknownCost=0` 仅表示每个最终响应都有费用字段，不能据此认定失败尝试零费用。
- 实测硬限制为 8 个决策、每个最多 2 次尝试、每次最多 8,000 输出 token（含推理）、
  90,000 输入字节。按模型目录价格预留 $0.14491，预留上限 $0.20；未锁定提供方，
  因此费用预留不是账单金额保证。
- 本次 CLI 每次尝试超时 180 秒。页面仍为每次 90 秒，不能把 CLI 成功等同于 GLM
  在页面中始终稳定。GLM 后三次分别为 49.1、34.8、66.4 秒；nano 四次为 8.7–11.4 秒。
- nano 会在同一季重复选择同源同目标的不同出兵档，还提及不存在的“夜袭”机制；
  有时直接重复上一季计划。系统只执行合法候选，解释文本仍可能不准确。

结论：跨季记忆、模型控制、规则执行和反馈链路已验证；四季样本不构成模型强弱排名，
也没有验证全 AI 长局的成本、延迟与胜率。

## 3. 工程收尾与真实页面验收

- TypeScript target 升为 ES2022，修复 BigInt 编译目标错误。
- 通过 Wrangler 从构建配置生成 Workers 运行时类型；D1 绑定声明与实际可选配置一致。
- 对地图数据和模型目录响应补充明确类型；两处地图共用 `TerritoryGrid`。
- `npm run typecheck` 零错误；`npm test` **189/189** 通过；lint 零错误、零警告；构建成功。
  构建仍有依赖弃用提示、较大 chunk 与 vinext 路由静态分类提示，不阻止构建。
- `npm run obs:budget` 通过：384 席·季的观测均不超过 10,000 估算 token，峰值 9,567。
  这不含规则摘要，不能视为一次请求的总输入费用；实际模型账单以返回 usage 为准。
- 新增 10 项回归覆盖调兵守恒/容量/禁止接力、围城预测、隐藏情报、将领归属、军费补兵、
  归降门槛和归降后命令取消等边界。
- 真实浏览器从 `/play` 开启纯观战，全部规则机器人，自然推进到页面第 25 季，
  袁绍控制 11 州并显示“戡定天下，本局结束”。自动观战停止，推进按钮禁用。
- 刷新页面，点击“继续”后仍为第 25 季结束状态，自动观战和推进按钮均禁用。
  页面显示 0 个模型席位、已用 0/32 次决策；控制台错误为 0。未注入游戏状态。
