## 一、Oriental Empires（2017）—— 唯一一款西方人做的古代中国 4X

### 1.1 它是谁做的，为什么值得单独开一章

- 开发：R.T. "Bob" Smith 与 John Carline；发行：Iceberg Interactive
- 抢先体验 2016-09-20，正式版 2017-09-14
- Metacritic **74**（16 家媒体）；PC Gamer 72/100
- 9 个可玩华夏势力（商、周、韩、蜀、秦、楚、吴、闽越、巴）+ 蛮、游牧、叛军
- 跨度约三千年，青铜时代到火器出现前
- 多人最多 **15 人**

（以上均据 [Wikipedia: Oriental Empires](https://en.wikipedia.org/wiki/Oriental_Empires)。）

关键的一条：**R.T. Smith 此前参与过 Total War 系列**（同上）。
这解释了 OE 最反常的两个设计——策略地图上直接跑的自动战斗、以及 WEGO 回合——
它们是"全面战争的作者反过来把战术层砍掉之后剩下的东西"。

**这对本项目的意义**：OE 是唯一一个既做古代中国、又独立收敛到 WEGO + 自动战斗的商业作品。
它的取舍是本项目骨架的**独立验证**，不是灵感来源。

### 1.2 WEGO：它和本项目的骨架撞上了

官方手册《Battles》一节的原话（意译，非逐字引用）：下令后部队不立即移动，
按下结束回合键之后**全部同时移动**；这样保留了古代战争里的不确定性与突然性，
让玩家能围观重要会战、而不必被无关小冲突的细节拖住
（[官方手册 PDF](https://steamcdn-a.akamaihd.net/steam/apps/357310/manuals/OE-Manual.pdf)，p.19）。

设计师笔记里说得更直白：这套做法让玩家处在**古代将领的真实位置**——
他能决定何时何地开战、投入哪些部队、采用什么战法，
但战斗一旦打响就基本失去控制权；顺带"让游戏非常适合多人对战"（同上，p.26）。

**逐条对照本项目：**

| OE 的做法 | 本项目 | 差异 |
| --- | --- | --- |
| 一回合 = 一季 | 旬 / 季两层钟 | 本项目更细，但决策点在季 |
| 命令同时提交、同时裁决 | 同 | 一致 |
| 战斗全自动，出战前设阵形与战术板 | 九代式：编队 + 目标 + 姿态 | 一致 |
| 战斗是**实时演算的，逐次投射/劈砍单独判定** | 确定性公式 | **本项目更强**：OE 的实时演算不可复现，本项目要的是可复盘 |
| 看不看战斗结果都一样 | 同 | 一致 |

手册明写"whether you chose to watch the battle or not, the outcome will be the same"（p.19）。
这一句是本项目 `GAMEPLAY-AI-FRIENDLY.md` §1.2C 那条判断的商业实证：
**只要"亲自打"不能赢更多，两层就等价，自动结算才不是次优选项。**

**适配度：★★★★★（骨架级确认，不需要新增设计）**

### 1.3 双阶级动乱：士族与黔首是两条独立的账

OE 把人口分成 **Nobles（贵族）** 与 **Peasants（黔首）**，两者各有一套动乱值，**互不相通**：

| | 贵族动乱 | 黔首动乱 |
| --- | --- | --- |
| 主要来源 | **Authority 不足**（见 §1.4）、君主战败或身死 | 摊派公共工程与垦荒（等同强征徭役）、人口过密、粮荒、天灾 |
| 中度后果 | 阻挠税收、拒绝服役 | 税收减少、无法征募民兵、境内出盗匪 |
| 高度后果 | **举兵自立，析出一个新势力**，与你自动开战 | 同样举兵，且**仇视一切贵族、与所有势力同时开战** |
| 传染 | 叛军逼近你的其他城时按动乱值判定是否响应；**军队中贵族单位过半也可能倒戈** | 同左，民兵过半的部队可能倒戈 |
| 镇压 | **贵族单位无法压制贵族动乱** | **黔首单位无法压制黔首动乱** |
| 通用解 | 常备军（训练兵 / 禁军）两者通吃，但维护费高；德望高的官员坐镇；文教建筑；诏令 | 同左 |

（据官方手册 pp.13–19。）

三条设计要点，本项目直接可用：

**（一）"能镇压 A 的兵不能镇压 B"是一条极优雅的约束。**
它把"你到底靠谁统治"变成一道结构题，而不是一个数值题。
汉末的对应物是现成的【史实】：**部曲（豪族私兵）压不住豪族，郡兵压不住流民**，
唯有中央直属的常备军（对标虎豹骑一类）两者通吃但费钱。

**（二）黔首叛军与所有势力同时开战，因此邻国的民变会烧到你身上。**
这是一个**跨势力的公共外部性**：它给"联合平叛"提供了非空头的动机，
而这正是首轮方案 §7.5 缺的东西——除了围殴领先者之外的第二种结盟理由。
黄巾、白波、黑山在史料上就是跨州郡流动的【史实】，不需要硬造。

**（三）"摊派工程会升高黔首动乱"把内政投入变成了有代价的赌注。**
首轮方案 §6.4 的七项工程目前只有钱粮与前置条件成本，**没有民心成本**。
按 OE 的口径，兴修水利、筑关、造船这类大工程应当每季扣民心，
否则"有钱就一直修"是无脑最优。

**适配度：★★★★★（对 C5 有直接贡献：它把内政从"堆数值"变成"选择得罪谁"）**

### 1.4 Authority：一条把版图规模直接变成内政压力的线

手册定义（p.18，意译）：Authority 衡量一位君主**能够有效治理的国家规模**。
若势力控制的城镇数超过其 Authority 值，**贵族动乱会大幅上升**，因为他们感到这个国家已经失控。

- 主要靠"思想"分支的技术推进提升，也受事件与诏令影响
- **一部分 Authority 附着在君主本人身上**，随会战胜败增减，**君主一死这部分全部消失**
- 君主死亡本身给继任者一个临时 Authority 惩罚；**无明确继承人时惩罚更大；连一个可继位的人物都没有时最大**
- 附庸的城镇**不计入宗主的 Authority 上限**，但附庸的人口计入宗主的胜利条件

最后一条是整套系统的枢纽：**它把"直辖"与"羁縻"做成了一道真正的战略取舍**。
直辖拿到全部产出但吃 Authority；附庸不吃 Authority、人口照算胜利分，但你指挥不动它的内政。

**这条直接可解 `GAMEPLAY-REVIEW.md` 的【C2 苟活占优】吗？不能，但它是解法的一半。**
（另一半见 §5.3 的 Decadence 与 §9.10 的落地方案。）

对本项目的映射【史实】：Authority 的汉末对应物不是虚构的，就是**印绶与察举**——
你能任命多少太守、这些太守是朝廷认的还是你私署的，本身有硬上限。
私署越多，士人越离心。这一层史料支持充分，不用编。

**适配度：★★★★★（见 §9.10；这是本文给首轮方案的第一条重点建议）**

### 1.5 Edicts：把"短痛长利"做成时机题

设计师笔记（p.27，意译）：诏令**同时带成本与收益，而成本往往只在短期**，
这让"什么时候颁"成为一个有意思的决策，尤其是那些会引发短期动乱的诏令；
并且**所有诏令都以真实的历史诏令与律令为原型**。

已确认的具体例子：**井田制（Well Field System）**——进一步向农业产出课税，
**抬高贵族满意度、同时抬高黔首不满**
（手册 p.15 建议"尽早颁布"；贵族/黔首方向由 Fandom 维基条目描述，
该维基本次无法直连，此条按二手来源记，标为**未从一手核实**）。

**为什么这个形状对 LLM 竞技场有价值**：
它是一个**纯时机题**——收益和成本都是已知的、公开的、确定的，唯一的变量是"什么时候"。
这类题目对随机性免疫（C5 友好），动作集极小（C4 友好，一条诏令一个条目），
但要求模型对未来若干季的局势做预判。**这是能把强推理和弱推理分开的最廉价题型之一。**

首轮方案 §6.5 的"国策 4 系 × 3 级"是一个纯增益结构，**没有一项有短期代价**。
按 OE 的口径，每一级国策都应当带一个明确的短期负项（民心、威望、或某项产出），
否则它退化成"攒够钱就点，没有决策"。

**适配度：★★★★★（改造成本极低：给现有国策表加一列"短期代价"即可）**

### 1.6 Recognize Emperor / Son of Heaven —— 迄今见到的最好的"奉天子"建模

这是本文认为**最值得抄的单条机制**，全文如此。

手册（pp.23–24）的规则原文要点：

**「承认皇帝（Recognize Emperor）」是一项外交行为，只有一个效果：**
承认方的人口，计入被承认方的「天子（Son of Heaven）」胜利进度。

约束条件是精心设计的：

1. **承认了别人，你自己就不能再走天子路线获胜。**
2. **一旦给出，不可撤回；但可以转授给另一方。**
3. **附庸永远承认其宗主为皇帝。**（所以拿附庸 = 顺带拿承认）
4. 「天子」胜利需要说服**大多数人口**承认你；手册说这需要"军事威慑与贿赂的混合"。
5. 「征服」胜利同样按人口算，且**附庸的人口计入宗主**。

**为什么它比华语三国游戏的任何"名分"实现都好：**

| | 华语三国游戏的常见做法 | OE 的做法 |
| --- | --- | --- |
| 名分是什么 | 一个自己的属性值（威望 / 声望 / 名声），别人无法直接给你 | **一个别人手里的、可转让的筹码** |
| 谁决定 | 引擎按规则算 | **其余每一方各自决定，且是公开的** |
| 可否反悔 | 通常可以 | **不可撤回，只能转授** |
| 博弈结构 | 无 | **可交易、可勒索、可交换的三方博弈** |

第 2 条（不可撤回、只能转授）是全套设计的关键：
它让"承认"成为一枚**一次性、高价值、可交易的棋子**。
你能把它卖给出价最高的人，但只能卖一次；而买方从此欠你一份人情，因为你随时可以转授。

**这在汉末语境下有精确的史实对应**【史实】：
建安元年（196）曹操迎献帝都许之后，其余诸侯面临的正是这道题——
承认许都朝廷的诏命（袁绍在很长时间里事实上承认了，接受了大将军之外的名号安排），
还是另立（袁绍曾谋立幽州牧刘虞为帝、袁术径自称帝）。
承认与否是**一次公开的、代价高昂的、难以反悔的政治站队**，不是一个内政数值。

**落地草案（给首轮方案 §3.5「名分」的替换件）：**

```jsonc
// 每方持有恰好一枚「奉」筹码，开局默认指向"汉室（NPC）"
"allegiance": {
  "holder": "yuanshao",        // 谁在做这个承认
  "target": "han_court",       // 承认谁为正统；可指向任一势力或汉室
  "sinceCouncil": 0,
  "transferable": true,        // 可转授
  "revocable": false           // 不可收回为"无"
}
```

- 承认某方 → 你的**户口数**计入该方的「奉天子」进度条（公开）
- 承认了别人 → **你自己本局不能再走「奉天子」胜利路线**（其余胜利路线不受影响）
- 转授需要付**威望**代价（史实感：反复无常者士人不附），且**全局可见**，进背信日志
- 从属（vassal）自动承认宗主，与 OE 一致
- 汉室朝廷作为 NPC 持有初始承认；**"迎奉天子"= 让汉室这枚筹码指向你**，这是一次可枚举的动作

这一条同时**部分缓解 REVIEW 的【C2 苟活占优】**：
「奉天子」进度是一条纯粹靠外交与威慑推进的胜利轨，
一个只修城劝农的势力永远拿不到别人的承认——**苟活在这条轨上得零分**。

**适配度：★★★★★（本文第一推荐）**

### 1.7 一个反常规设计：技术进度大家基本同步

设计师笔记（p.27，意译）：技术系统"有点不寻常"，
不仅在于分成四个独立分支，还在于**所有人的推进速度大致相同**。
理由有两条：一是符合历史实际，二是避免"研究实验室"式的时代错置；
四分支则**避免了各国发展水平出现巨大失衡**，同时便于把文化与哲学思想装进来。

**对本项目的价值不在"技术"，在这条思路**：
在一个 15 年 / 60 季的短窗口里，**科技差不该成为胜负的主要来源**。
首轮方案 §6.5 的国策已经砍到 4×3，方向是对的；
本文建议再加一条 OE 式的约束：**国策的推进速度对所有势力设一个共同的时代下限**，
差距只体现在"点了哪几条"，不体现在"点了几条"。
理由直接是 C5：**如果强模型可以靠国策差累积复利优势，那么开局领先者的优势会被放大，
而不是被它的决策质量放大。**

**适配度：★★★★（需要改造：把国策从"可加速"改成"选择题"）**

## 二、Paradox 引擎如何表达汉末

### 2.1 先说结论，免得读者按错误的期待往下读

**Paradox 的三国 mod，价值几乎全在"数据规模"上，机制价值很低。**

理由是结构性的：mod 不能改引擎。CK2/CK3 的引擎核心是**封建人身依附关系的模拟**——
封臣契约、继承法、爵位层级、家族血脉。汉末的政治结构不是封建制，是**官僚制加豪族**：
郡守是任命的不是世袭的，州牧是朝廷授的不是分封的，士族的力量来自察举与门生故吏网络而不是采邑。
把汉末塞进 CK 引擎，本质上是把太守当伯爵、把州牧当公爵、把「奉天子」当教宗授冠。
**能玩，但那不是汉末的政治机制，是欧洲中世纪的机制换了皮。**

所以本章的重心不在 mod，而在 **Paradox 本体里那些恰好为中国政治发明的机制**——
EU4 的天命、EU4 的行政容量、CK3 的官僚政体。这三样比任何 mod 都值钱。

### 2.2 CK2《Romance of the Three Kingdoms》

规模（据 [ModDB 条目](https://www.moddb.com/mods/romance-of-the-three-kingdoms) 的描述，
**本次调研 ModDB 直连返回 403，以下数字来自检索摘要，未从一手页面逐项核实**）：

- 5000+ 人物、**500 个省**、14 种宗教、16 种文化
- 自建的单挑、战斗、爵位、继承、流民、帝国等系统
- 多个剧本：黄巾之乱、讨董联军、群雄割据、河北争锋、赤壁、三国鼎立

**对本项目唯一有参照价值的一条：500 个省。**
本项目的 `commanderies.json` 是 **105 郡国**，`lib/game/data` 里另有 1180 县的数据。
这个 mod 选择了介于两者之间的粒度。但它是给人玩的 CK2，玩家可以花几百小时慢慢点；
本项目的观测预算是 6000 token，**105 已经是上限区间**（见 REVIEW §2.2 的【B1】token 超预算）。
所以这条数据的结论是反向的：**不要往 500 走，1180 县首版必须继续推迟。**

**适配度：★（不迁移任何机制，只作为粒度参照）**

### 2.4 EU4 的天命（Emperor of China / Mandate of Heaven）—— 本章的重点

这是 Paradox 为中国**专门发明**的一套政体机制【游戏原创】，比任何三国 mod 都值得研究。
以下数值均据 [EU4 Wiki: Emperor of China](https://eu4.paradoxwikis.com/Emperor_of_China)，
**仅用于说明机制形状与量级，不建议照抄任何一个数字**。

**天命（Mandate）是一个 0–100 的数值资源，阈值在 50。**

年度增减（示意）：

| 来源 | 效果 |
| --- | --- |
| 安定度 | 每点 +0.4 |
| **朝贡国** | 每 100 发展度 **+0.15** |
| 繁荣的州 | 每个 +0.04 |
| 完全荒废的州 | 每 100 发展度 **−12.0** |
| 贷款 | 每 5 笔 −0.6 |
| 丢失北京 / 南京 / 广州 | **每城每月 −0.05** |

天命的效果是**双向的、非线性的**：

- 天命 0：产出 −50%、人力 −50%、受到的火力/冲击伤害 +50%、附庸独立欲望 +30%、动乱 +5
- 天命 100：动乱 −2.5、议会忠诚 +10%、月度厌战 −0.05

**丢掉天命的惩罚是一个 20 年的诅咒**：产出 −50%、人力 −50%、纪律 −10%、
附庸独立欲望 +50%……**且 20 年内不能重夺**。

**四条可迁移的机制思路：**

**（一）天命是一个"别人在贡献"的数值。**
朝贡国按发展度给天命增长——**天下越承认你，你越像天子**。
这与 §1.6 的「承认皇帝」是同一条思路的连续版：
OE 是离散的一次性筹码，EU4 是连续的贡献流。
本项目可以两者兼取：**「奉」筹码是离散的站队，「朝贡/归附」的郡国户口是连续的进度条**。

**（二）关键城池是天命的锚，丢了就每月流血。**
本项目的现成对应物是 **洛阳、长安、许（许都）** 【史实】，
以及 `strategic-nodes.json` 里的关隘。这比"控制 N 个州的过半郡国"（首轮 §9.2）
好在**它不会开局就锁死档位**（见 REVIEW 的【C3】：袁绍、刘备、吕布、刘表开局即达霸业档）。

**（三）帝国诏令：花「贤能度」换 10 年的一个全局增益。**
Meritocracy（贤能度，0–100，年基线 −2，聘用能臣按每技能等级每年 +0.25）
花 20 点开一条诏令，持续 10 年。
**这是一个"低频、高杠杆、可枚举、有明确资源代价"的动作** —— C1/C3/C4 全部友好。

**（四）天朝改革：−70 天命 + −1 安定的一次性重击，换永久结构改变。**
需要天命 ≥80 才能启动。这个形状叫**"必须先攒到峰值才能花掉"**，
它逼出一种非常具体的规划：什么时候停止扩张、专心把天命拉到 80。
对 LLM 而言这是一道优质的长程规划题（对照 `GAMEPLAY-AI-FRIENDLY.md` §1.2F 的尤里卡讨论）。

**适配度：★★★★★（天命作为数值资源）/ ★★★★（帝国诏令）/ ★★★★（改革的攒-花结构）**

### 2.5 EU4 的行政容量（Governing Capacity）—— "管不过来"的硬数字版

据 [EU4 Wiki: States and territories](https://eu4.paradoxwikis.com/States_and_territories) 与社群总结：

- **完整州（state）的每 1 点发展度 = 1 点行政容量成本**
- 贸易公司 −50%（即 0.5）；领地（territory）−75%（即 0.25）；首都州只占 1%
- 法院 −25%、市政厅 −50%、州府 −15% 且在所在省额外 −10 点、并对全州再 −20%
- **超出容量则受递增惩罚**

**形状总结：`容量成本 = Σ(每郡的规模 × 治理方式系数)`，治理方式是可选的，超限有惩罚。**

这是本文见过的**最可枚举、最可序列化**的行政上限写法：

- 它是一个可以一行算出来的标量（C2 友好）
- "把某郡从领地升为州"是一个可枚举的二元动作（C4 友好）
- 它天然产生"直辖 / 羁縻 / 遥领"的三档取舍，正是汉末的真问题【史实】

**与 §1.4 的 OE Authority 的区别值得讲清楚**：

| | OE Authority | EU4 Governing Capacity |
| --- | --- | --- |
| 成本口径 | **城镇数**（每城 1） | **发展度加权**（大郡贵、小郡便宜） |
| 超限后果 | 贵族动乱大涨（**内政风险**） | 递增数值惩罚（**确定性衰减**） |
| 规避手段 | 附庸化 | 降级为领地 / 建法院 |
| 对本项目 | 后果更有戏剧性，且与豪族叛乱耦合 | 计算更清爽，模型能心算 |

**本文的建议是两者混用**：成本按户口加权（EU4 式），后果走豪族离心（OE 式）。
落地见 §9.10。

**适配度：★★★★★**

### 2.6 CK3《Roads to Power》的官僚政体（Administrative）—— 郡守任免的现成模型

2024 年的 Roads to Power 资料片给 CK3 加了一套**以拜占庭为原型的中央官僚政体**
（据 [CK3 Wiki: Administrative](https://ck3.paradoxwikis.com/Administrative)）。
它是 Paradox 全系列里**最接近汉末郡县制**的一套规则：

**结构：**

- 帝国划分为公爵级的 **Province / Theme（军区）**，**这些地不能被拥有**，
  只由帝国**任命**一位 **Governor（Strategos）**治理
- 治理权的分配靠一种专属货币 **Influence（influence，权势）**
- **Noble Family（世家）** 拥有独立于任何官职的 **Estate（庄园）**——
  **即使被免官，家族的经济基础还在**
- 世家评级 ≥40 且位列前五 → **Powerful Family（强宗）**，解锁"废黜/篡夺总督"政治阴谋
- 强宗控制全境 ≥25% → **Dominant Family（豪右）**，阴谋成功率更高
- 评级修正示意：议政 +15/人、同宗族每支 +10、每级 influence +5

**Influence 的花法（示意数值）：**

| 用途 | 成本 |
| --- | --- |
| 指定继承人 | 150 |
| **强令总督去职** | **150** |
| 收回封臣手里的直属兵 | 150（防御战 −25%，指向战争目标 −50%） |
| 更改世家属性 | 250 |

**与封建制的关键差异（这几条对本项目全部适用）：**

| | 官僚政体 | 封建制 |
| --- | --- | --- |
| 独立战争 | **中央官僚制的封臣不能打独立战争** | 可以 |
| 建国 | 不能建公爵以上的爵位，不能组解散派系 | 可以 |
| 直属兵 | **君主可以在封臣之间调动** | 封臣自持 |
| 指令 | **有地封臣随时可以接受指令** | 受限 |

**为什么这套比任何三国 mod 有价值：**

它把"任免"做成了**一个有明确价格的动作**（150 权势），
而不是华语三国游戏里那种"点一下就换太守"的零成本操作。
一旦任免有价格，**"谁来当这个郡的太守"就成为一道真正的资源分配题**：
你要么花权势换一个能干的自己人，要么留着一个不称职但便宜的世家子。

**同时，"世家的庄园独立于官职"这一条极其重要**：
它意味着**免官不等于削弱对方**，只是把对方从体制内推到体制外。
这正是汉末的真实结构【史实】——袁氏四世三公的力量来自门生故吏与汝南南阳的乡里根基，
不来自任何一个具体官位；曹操罢免一个郡守，不会让那个家族消失。

**落地草案（给首轮方案 §4.2「岗位」的加强件）：**

```jsonc
"appoint": {
  "cost": { "prestige": 4 },        // 任免不是免费的
  "targetSlot": "taishou:陈留",
  "officer": "xunyu",
  // 若被免者出身本郡豪族：该郡「豪族离心」+8，且该家族的私兵不再计入你的可用兵
  "sideEffects": ["clanAlienation"]
}
```

**适配度：★★★★★（任免有价）/ ★★★★★（世家根基独立于官职）**

## 三、Total War 系列（三国之外）

《全面战争：三国》已在 `GAMEPLAY-OTHER-SANGUO.md` §2 覆盖，本章只谈其余作品。

### 3.1 省份 = 若干郡 + 一个郡治：Rome II / Attila 的两级据点

结构（据 [Total War Academy: Rome II Province Overview](https://academy.totalwar.com/rome-2-province-overview/)
与 TWCenter 社群整理）：

- 一个 **Province（省）** 含 **2–4 个 Region（区）**；Attila 里统一为**每省 3 个**
- 每省有且仅有一个 **省会 / 城（City）**：**有城墙**，被攻时打完整攻城战
- 其余是 **小据点 / 镇（Minor Settlement）**：**无墙**，被攻时只是街巷与一个占领点

**这套两级结构比"每城都是要塞"好在哪**——三条：

**（一）它把"哪里值得设防"变成了地图上的既定事实，而不是玩家逐城决策。**
本项目的 105 郡国目前是**平的**：REVIEW 的【C1 地图冻结】就出在这里——
所有郡都能修城、都能守，于是 `A/D ≥ 2.2` 的攻城门槛处处成立，谁也打不动谁。
**给郡国分"郡治 / 属县"两级，让相当一部分郡国天然是"无墙"的**，
攻方就有了低成本的切入点，地图才会流动起来。

本项目的数据是现成的：`commanderies.json` 有 105 郡国的属县，
`strategic-nodes.json` 有 61 个关隘港口渡口。**天然的两级结构就在数据里，只是没用起来。**

**（二）OE 的攻城规则把这一点讲得更彻底，且给出了破局的杠杆。**
OE 手册（pp.20–21）：无墙据点**视为有四个缺口**（每条道路入口一个），攻方可立即突击；
所以**攻方单位数多于守方、且守方不足四个单位时，据点会被轻松拿下**。
有墙据点则必须先破墙：木栅可被火箭烧毁，土墙砖墙需要抛石机或火炮；
**关键是缺口数量越多，守方越被摊薄**，攻方的正确解法是"多开缺口"而非"堆兵力比"。

**这条直接给 REVIEW 的【C1 地图冻结】一个解法**：
把攻城判据从"兵力比 A/D"改成"**同时突击点数 vs 守军单位数**"，
而同时突击点数由**器械投入**决定，不由兵力决定。见 §10 的落地建议。

**（三）"占满全省才有额外收益"是一个天然的战役目标生成器。**
Rome II 的敕令必须**控制全省所有区**才能颁布（见 §3.3）。
这把地图上的"下一个目标"从 105 选 1 收敛成"补齐哪个州"，
正是本项目 §2.5 想要的动作空间收敛手段。

**适配度：★★★★★（两级据点）/ ★★★★★（缺口数取代兵力比）/ ★★★★（补齐全省的奖励）**

### 3.2 建筑槽位：本项目的反面教材，但有一条要抄

槽位数（据 TWCenter 与 Total War: Warhammer Wiki 社群整理）：

| 作品 | 城 / 省会 | 镇 / 小据点 |
| --- | --- | --- |
| Attila | 6 槽 | 4 槽（部分 3） |
| Warhammer 系列 | 多数省会 8 槽，特殊据点最多 12 | 4 槽，最高只能升到 III 级 |

Attila 的槽位**不是固定的**：每回合城镇产生"成长值"，攒满转成一单位余裕人口，
**花掉余裕人口才开出一个新槽**；且**空槽放太久会变成贫民窟，清除昂贵**。

**为什么它是反面教材（对本项目）：**

槽位 = 生产队列的空间化版本。105 郡 × 4–8 槽 = 420–840 个决策位，
这是 `GAMEPLAY-AI-FRIENDLY.md` §2.3 那条硬规则要杀掉的东西的最纯形态。
**首轮方案 §6.6「不做建筑槽位」的判断是对的，本文完全同意，不需要重议。**

**但有一条必须抄：槽位数是派生量，不是常数。**

Attila 用"成长 → 余裕人口 → 开槽"把**城市规模变成了一个可投资的、可见的进度条**。
首轮方案 §3.8 已经有"郡国分级（派生值）"，但它目前只是一个显示层。
**建议把郡等做成真的门槛量**：郡等决定该郡能承载几支军团、能否作为战区补给基地、
能否作为工程的起点。这样"把哪个郡养大"就成了一个长周期投资决策——
一次决策覆盖很多回合（C3 友好），动作集只有"投或不投"（C4 友好）。

**"空槽变贫民窟"这条也值得抄形状**：**投资开了头不接续，会比不投更糟。**
这是对"什么都点一点"的自然惩罚，逼出取舍。

**适配度：★（建筑槽位本身）/ ★★★★（郡等是派生的可投资进度条）/ ★★★★（半途而废比不做更糟）**

### 3.3 Rome II 的敕令（Edict）：委任槽位是稀缺资源

规则（据 Steam 社群与 TWCenter 多帖交叉确认）：

- 敕令**按省颁布**，一省一条
- **必须控制该省所有区**才能颁
- **可同时生效的敕令总数受「Imperium 等级」限制，上限 5**

**这一条是本文对首轮方案 §6.2 的第二条重点建议。**

首轮方案的战区方针是：一个势力有 1–5 个战区（上限 5），**每个战区各设一条方针，不花战略点**。
也就是说**方针是免费且全覆盖的**。

免费全覆盖的委任 = **没有决策**。模型只需要给每个战区各挑一个当前最优档，
这道题的信息熵接近零，而它却要占掉观测与动作集里不小的篇幅。

**改法（Rome II 式）：**

```
可同时生效的常驻方针数 = f(威望 / 名分 / 行政容量)，开局 2 条，上限 4 条
未被方针覆盖的战区 → 走一个确定性的默认行为（保守：安民 + 不输送）
```

效果：

- **"把注意力放在哪个战区"变成一道真题**（C5 友好：这是可以分出高下的判断）
- 动作集不增反减（方针条目从 5 条固定变成 2–4 条中选，且默认档不必出现在动作集里）
- 与 §1.4 的 Authority、§2.5 的行政容量共享同一个"治理能力"标量，不新增属性

**适配度：★★★★★**

### 3.4 Shogun 2 的 Realm Divide：反滚雪球做砸了的教科书案例

机制：玩家扩张到一定规模（社群普遍说法是 **15 省左右**，
[Steam 讨论](https://steamcommunity.com/app/34330/discussions/0/3823036783907490359/)）后触发
**Realm Divide** 事件，**其余所有势力无条件对你宣战**，无论此前关系如何；
外交与贸易实际上被移出游戏。

社群评价高度一致且负面，代表性表述包括：
"再喜欢你的势力，五回合后也会翻脸"；"世仇的两家会放下血仇联手打你"；
"这是为了平衡 AI 而做的糟糕实现"；主流应对是**装 mod 把它关掉**
（[TWCenter 长贴](https://www.twcenter.net/threads/realm-divide-how-i-hate-thee.501915/)、
[Steam 讨论多帖](https://steamcommunity.com/app/34330/discussions/0/357286663691329394/)）。

**这正是 `GAMEPLAY-AI-FRIENDLY.md` §4.1 区分的两件事里的坏的那一件：结构性退化。**
Realm Divide 让"识别领先者"这个零难度任务主导了全场，
并且**把领先者的最优策略压缩成一条**（社群原话："forces same old strategy"）。

**对本项目的三条教训：**

1. **围殴的触发不能是无条件的、自动的、不可逆的。**
   首轮方案 §7.5（二）的"众怒 −3/季持续衰减 + 明写的降温动作"方向正确，
   Realm Divide 恰恰是没有降温通道的版本。
2. **围殴触发之后必须留下可玩的选项。** Realm Divide 之后外交被删除，玩家只剩打。
   首轮方案 §7.5（五）"与僭越者结盟不被禁止，只是盟友每季威望 −3"这条是对的，**必须保留**。
3. **触发阈值不能是"省数"这种一维量。** 一维阈值等价于给所有模型一条公开的红线，
   最优解退化为"贴着线不过"。首轮方案的众怒是行为加权的（屠城 / 背盟 / 奉诏折扣），
   这比省数好，**但要确保众怒不能靠"不动"归零**——见 §9.6 的 Decadence 讨论。

**适配度：★（不要做）—— 但作为反例，它的价值是 ★★★★★**

### 3.5 Attila 的气候变化：一个全局强制函数

机制（据 [TV Tropes: Total War Attila](https://tvtropes.org/pmwiki/pmwiki.php/VideoGame/TotalWarAttila)
与 Steam 社群整理）：战役推进过程中气候持续变冷，
**最终稳定在全球 −4 肥沃度并永久保持**；
初始肥沃度"average"及以下的省份**全部变成不毛之地**；
北方冬季延长，最北处可达四回合里三回合是冬天，附带减员与产出惩罚。

设计目的明确：**逼迫迁徙势力南下**。手册与开发者访谈的口径是，
迁徙势力若不能及时找到新土地就会被冻死。

**这是本文给 REVIEW 的【C2 苟活占优】找到的最直接的一味药。**

REVIEW 算出来的边际交换率是：袁绍席位上丢地的分数代价是拿地收益的 **7.3 倍**，
曹操席位上是 **26 倍**，因此"修城、劝农、结盟、绝不出兵"是占优策略。
这个结论成立的前提是：**不动的话，你的资产不会贬值。**

气候变化就是在打破这个前提：**世界本身在恶化，静止的资产会自动缩水。**

汉末的对应物完全是史实的，不需要发明【史实】：

- **人口持续流失**：中原户口从桓灵之际到魏晋的锐减是有文献支撑的（本项目 §附录 已用《郡国志》户口做锚）
- **流民与瘟疫**：建安二十二年大疫；黄巾之后流民持续南下与西迁
- **失去中央支持的边郡内缩**：凉州、并州、幽州边郡的实际控制持续退缩

**落地草案（不用引入"气候"这个词）：**

```
每年岁首，按一张公开的、确定性的时间表施加「离乱」：
  - 全图户口基线 −1.2%/年（中原战区 −2.0%，江南 / 巴蜀 −0.4%）
  - 民心 < 40 的郡额外 −1.0%
  - 「屯田」「修渠」「兴学」工程完成的郡免除该年衰减
```

三个性质，逐条对照约束：

- **确定性、公开、可预告**（C5：它是输入随机的极限形式——完全没有随机）
- **零动作集增量**（C4：它不是一个动作，是世界的规则）
- **它把"什么都不做"变成一个持续亏损的选项**（直接打 C2 的病灶）
- 它同时给工程系统（§6.4）一个真实的紧迫性，而不是"闲着就修"

**适配度：★★★★★（本文对 REVIEW【C2】的第一条建议）**

## 四、Nobunaga's Ambition / 战国题材：西方评价与机制对比

### 4.1 西方评价的两个一致判断

《信长之野望·创造》（*Nobunaga's Ambition: Sphere of Influence*，2015 西方发行）
Metacritic **80**，"generally favorable"（[Metacritic](https://www.metacritic.com/game/nobunagas-ambition-sphere-of-influence/)）。

西方评价里反复出现的判断有两条，且方向一致：

**（一）系统是"棋盘游戏式的清晰"，难度来自后果而非规则复杂度。**

评论者 Erik Twice 的表述（[原文](https://eriktwice.com/en/2019/01/25/nobunagas-ambition-sphere-of-influence-%E2%98%85%E2%98%85%E2%98%85%E2%98%85/)）：
这套设计使用的是"比起臃肿的策略电子游戏、更接近桌游的清晰简单机制"；
挑战不来自系统数量，而来自**资源不够、什么都想做就什么都做不成**。

他还特别点名了外交系统：称其为"我见过的电子游戏里最精简的外交系统，也是最好的之一"——
机制是**派遣家臣持续投入时间与金钱，逐步与对方大名建立信任**。

**这条对本项目直接有用**：外交不是一次性掷骰，也不是一个滑条，
而是**一项要持续投入、可被打断、进度公开或半公开的长周期动作**。
这与 CK3 的阴谋（`GAMEPLAY-AI-FRIENDLY.md` §1.2E）是同构的，
但比 CK3 少了随机性——**信任是攒出来的，不是掷出来的**。
首轮方案 §7.3 的"谈判轮"目前是**单季一次性**的，建议加上这条持续投入的通道。

**（二）批评集中在"官员调来调去"和"势力之间差异不足"。**

同一篇评论列出的缺点：**不断地调动武将**（constant shuffling of officers）、
历史事件系统的局限、经济层在中期之后失去重要性；
以及**各家大名同质化——区别主要来自地理位置与手下武将，而非独特的机制**。

**这两条批评几乎是给本项目量身定做的警告：**

- "官员调来调去"= 本项目 §4.2 的岗位系统如果没有任免成本（§2.6）就会变成同一件事
- "势力同质化"= 首轮方案里六个席位的规则完全相同，**唯一的差别是开局盘面**。
  这在竞技场语境下不见得是坏事（见 §8），但要知道自己在做什么选择。

### 4.2 《新生》（Awakening，2023）的委任：Koei 自己给出的答案

这是本文认为**光荣系列里与本项目最相关的一作**，而它不是三国。

官方与评测口径（[Steam 商店页](https://store.steampowered.com/app/1336980/NOBUNAGAS_AMBITION_Awakening/)、
[digitallydownloaded 上手报道](https://www.digitallydownloaded.net/2023/06/ive-played-nobunagas-ambition-awakening-youre-going-to-love-this-game.html)、
[Steam 社群讨论](https://steamcommunity.com/app/1336980/discussions/0/6363075944117015449/)）：

- **家臣按自己的判断行动**，并**主动向玩家提交"提案（submissions / 具申）"**
- 玩家把家臣**任命到郡、国的主官位置**；上任后由他们自行决定当地发展方向
- 对城主可以下达**大方向的指示**，由其自主经营辖下城池
- **国（province）一级的委任更彻底**：可以给予完全自主权，
  包括**在有机会时不经请示直接进攻邻国**
- 「知行（Dominion）」系统：把土地授予家臣，受地者会为家族的发展尽力

**三层结构**：势力 → 国（授予自主权）→ 郡（受国主管辖）。
这与首轮方案 §6.2 的三层委任（国策 → 战区方针 → 郡级自动执行）**结构完全一致**。

**但《新生》比首轮方案多了一样东西，而那一样恰恰是最值钱的：提案通道。**

首轮方案的委任是**单向的**：模型下方针，引擎执行，不回话。
《新生》的家臣会**主动上报**"我认为该打某处 / 该修某处 / 有某人可招"。

**为什么这对 LLM 竞技场特别重要：**

1. **它是天然的动作空间裁剪器。** 与其把 105 个郡的所有合法动作全枚举给模型，
   不如让引擎按确定性规则**预筛出 5–15 条"下属的建议"**，模型在其上做批准/否决/改派。
   这把第一级条目数从 REVIEW §1.1 实测的 **62–195 条**压到十几条，
   直接对上【A1 动作集撑破裁剪线】。
2. **它把"信息呈现"的负担从模型移到引擎。** 这正是 lmgame-Bench 说的 harness
   （`GAMEPLAY-AI-FRIENDLY.md` §5.4 末条）：**没有 harness 时模型都聚在随机水平附近。**
3. **它产生一个新的可测量维度：模型对下属建议的采纳率与采纳质量。**
   引擎知道每条提案的确定性收益期望，因此可以算出"模型否决的提案里有多少是本该采纳的"。
   这是一个比胜率信息量大得多的过程指标。

**但有一个必须避开的陷阱**：如果提案带有引擎算好的收益排序，
模型的最优策略退化为"永远采纳第一条"，那测的就是"会不会读排序"。
**正确做法**：提案只给**事实与前置条件**（"陈留郡守军 3 千，粮可支 4 旬，与濮阳相邻"），
**不给评分、不给排序**，让模型自己权衡。这条与首轮方案 §4.8 已接受的原则一致。

**适配度：★★★★★（提案通道）—— 本文对首轮方案 §6.2 的第三条重点建议**

### 4.3 与光荣《三国志》的横向差异

| | 《信长之野望·新生》 | 《三国志 14》 | 本项目取哪一边 |
| --- | --- | --- | --- |
| 委任层数 | **3 层（势力 / 国 / 郡）** | 2 层（地区委任 / 都市方针） | 3 层 |
| 下属是否主动上报 | **是（具申）** | 否 | **是** |
| 委任者可否自主开战 | **国主可授予此权** | 否 | 谨慎：见下 |
| 据点粒度 | 城 + 郡 | 46 城 / 338 地区 | 105 郡 + 属县（不作可操作层） |
| 任免成本 | 有（知行 / 忠诚） | 弱 | **有**（§2.6） |

"授予下属自主开战权"这一条本项目**不建议直接搬**：
它会让"战争由谁发起"变得不可归因，而本项目要测的恰恰是模型的开战判断。
**但它的一个弱化版本值得做**：授予战区都督**有限的反击权**——
遭到进攻时可以自动就近调兵与反击，不必等到下一次季议。
这解决的是首轮方案 §1.4「无重大变化时不调用模型」与"被偷袭时来不及反应"之间的矛盾。

## 五、更远但有借鉴价值的四款

### 5.1 Old World（Mohawk Games / Soren Johnson，2021）

设计师是 **Civilization IV 的首席设计师 Soren Johnson**；
Epic 2021-07-01，Steam/GOG 2022-05-19；Metacritic **80**；IGN 8/10；
PC Gamer 评为 2021 年最佳策略游戏
（[Wikipedia: Old World](https://en.wikipedia.org/wiki/Old_World_(video_game))）。

这一款与本项目的相关度**最高**，因为它解决的是同一个问题：
**如何在一个有很多单位和很多城市的 4X 里，让玩家一回合只做有限次决策。**

#### 5.1.1 Orders：本项目 SP 的成熟原型

官方手册（[Old World Official User Manual v1.23](https://cdn.akamai.steamstatic.com/steam/apps/597180/manuals/Old_World-Official_User_Manual.pdf)）
第 9–11 页：

- **几乎一切都要花 Order**：移动一个单位要 1 个或更多；派工人修地块要现在花，
  且**每个在建回合再自动扣 1 个**
- 增长途径：探索发现地标（首个发现者 **+2 声望**，其余 **+1**）；
  **每 10 点声望（Legitimacy）= +1 Order**；某些地块改良；某些法条（如奴隶制）
- 每个市民 **+0.1 Order**
- 可以用训练点等资源**临时买 Order**
- 单位另有独立的"疲劳（fatigue）"上限，一般 **3**；强行军花 100 训练点，
  且超出正常上限的每一格**要花 2 个 Order**

**与首轮方案 §2.2 的 `SP = 5 + ⌊√n⌋` 对比：**

| | Old World Orders | 本项目 SP |
| --- | --- | --- |
| 增长来源 | **人口 + 声望 + 建设 + 法条**（四条独立轨） | 郡国数（一条轨） |
| 是否可临时购买 | **可以（花训练点）** | 否 |
| 是否有独立的单位行动上限 | **有（疲劳）** | 无 |
| 花完之后 | 停手 | 停手 |

**三条建议：**

**（一）把 SP 的来源从"郡国数"改成多条轨的和。**
只挂郡国数意味着 SP 与版图完全同向，
**开局大的席位（袁绍 13 郡）永远比小的（曹操 1 郡）有更多动作**——
这正是 REVIEW §1.1 指出的"六个模型这一回合面对的是难度完全不同的题"的一部分成因。
改成 `SP = 基线 + f(威望) + f(郡等和) + 已完成工程加成`，则**小势力可以靠打得漂亮来追平动作预算**，
这才是能把推理质量转成结果的通路（C5）。

**（二）加一条"临时购买"的通道。**
花粮 / 花威望换本季额外 1–2 个 SP，且有递增价格。
这给"关键回合全力一搏"提供了机制，是一个纯粹的判断题（C5 友好），
且动作集只 +1 条（C4 友好）。

**（三）军团要有独立于 SP 的行动上限。**
否则模型可以把全部 SP 都倾泻到一支军团上做多次机动，这是微操的变体（C1 风险）。

#### 5.1.2 Ambitions：动态生成的私有目标

- **完成 10 个 Ambition 即可获胜**，这是与 VP 并列的独立胜利路线
- Ambition 是**半随机的、由所选的世家（vassal families）驱动的、难度递增的**
- 早期很简单（"造六座矿"、"研六项技术"、"有三座相连的城"），后期急剧变难
- **继位者上台会选择新的 Ambition**——目标随人物更替而变

**与首轮方案 §7.5（三）"私有战略目标"的对比**：
首轮方案的私有目标是**开局抽 2–3 个、固定不变**的。
REVIEW 的【C2】指出，12 条目标里至少 4 条是纯守成向的（"三年不失一郡"等），
它们与"苟活占优"直接共谋。

**Old World 的做法解掉了这个问题**，靠两条结构：

1. **目标是逐个解锁的，不是一次给全的**：完成一个才出下一个，且难度递增。
   于是**没有"选一组容易的目标然后龟缩"这条路**——你必须持续解题。
2. **目标由所选世家驱动**：选了不同的家族，目标池就不同。
   这是一个**开局的、公开的、有代价的选择**，而不是随机发牌。

**落地草案：**

```
开局每方从"家世 / 乡里 / 部曲"三类中选 2 组（公开），决定其后的目标池
目标逐个揭示：完成第 k 个才解锁第 k+1 个，难度按 k 递增
终局排名的私有目标项 = 完成的目标个数，不是"达成率"
```

最后一句很重要：**用"完成个数"而不是"达成率"计分，
消掉了"少领目标就容易满分"的漏洞**——这正是 REVIEW【C2】边际交换率算出来的病灶之一。

#### 5.1.3 Laws：成对互斥的法条

- 法条**成对互斥**，例如**奴隶制 vs 自由**、**行会 vs 门阀**
- 每个技术层级提供 **2–3 组**法条选择

**这个形状比首轮方案 §6.5 的"4 系 × 3 级"好在一处：它天然是取舍，不是积累。**
4×3 的结构里，只要资源够，你迟早能点满一整系；
成对互斥的结构里，**选了 A 就永远拿不到 B**，且这个选择是公开的、可被对手利用的。

汉末的对应物极其现成【史实】，且都是真实的政策二选一：

| 一组 | 一边 | 另一边 |
| --- | --- | --- |
| 用人 | **唯才是举**（曹操建安十五年令）：招揽阈值低，但士人清议不利 | **举孝廉循资**：士族向心，但人才流入慢 |
| 土地 | **屯田**：粮产高，民附度低（军事化管理） | **假民公田**：粮产平，民心高 |
| 军制 | **世兵/部曲**：兵源稳定，豪族坐大 | **征发郡兵**：中央可控，民心消耗大 |
| 名分 | **奉诏**：外交折扣，行动受制 | **自署**：行动自由，士人离心 |

**适配度：★★★★★（成对互斥法条）**

#### 5.1.4 人物必死与继承

- **一回合 = 一年**，君主会老死；**没有继承人就直接游戏结束**
- 继位者上台**重选 Ambition**
- 城市的不满（discontent）每一级给控制该城的世家 **−20 好感**；不满到 8 级则 **−40% 产出**
- 缓解手段：接通首都贸易网、驻扎**同族**部队并筑城墙（护城河/箭塔再 −1）、法条、公共建筑、宗教

**这一条直接对上 REVIEW 的【G7 史实卒年 = 脚本化必败】。**

Old World 的做法与 OE（§1.4）一致，且更彻底：
**君主之死不是剧本，是一个每局都会发生、有明确规则、可以提前准备的结构性事件。**
准备的手段是公开的（生子、收养、指定继承人），
惩罚的大小是**你准备程度的函数**（OE：无明确继承人惩罚更大，连一个可继位者都没有时最大）。

**建议（与 REVIEW 的 G7 改法合并）：**

1. 君主**不进史实卒年表**，只按年龄寿命表死或死于局内战事（同 REVIEW）
2. 继位惩罚按**准备程度**分三档，而不是固定值：
   已明确指定且有纽带的继承人 → 轻；有在册武将但无指定 → 中；无人可继 → 势力瓦解
3. **"指定继承人"是一个花 SP / 花威望的显式动作**（对标 CK3 的 150 权势）
4. 继位后**私有目标重抽**（Old World 式），这让君主更替成为一个真正的战略转折点而非纯损失

**适配度：★★★★★（继承作为结构性事件）**

#### 5.1.5 胜利条件：Double Victory

- 200 回合；到点时 VP 最高者胜
- 或提前达到 VP 上限
- 或 **Double Victory：VP 超过所需总量的一半，且是第二名的两倍**
- VP 来源：城按文化等级计（弱 1 / 发展中 2 / 强 3 / 传奇 4，传奇每再升一级 +1）；
  奇观 2；圣地 2；点满一条技术分支末端 1

**Double Victory 这个形状值得抄。**
它是首轮方案 §9.2 的"绝对阈值"与"相对领先"的**合取**，而不是二选一：

- 光有绝对阈值 → Diplomacy 的已知均衡：领先者被全场按住，和局率高（`GAMEPLAY-AI-FRIENDLY.md` §4.2）
- 光有相对领先 → 退化成"永远做第二名"
- **两个条件同时满足才提前结束** → 领先者必须**既做大又拉开差距**，
  而围殴方只要把两个条件里任意一个破掉就能拖到终局

它还有一个对竞技场特别友好的性质：**提前终局的判据是两条可一眼验算的不等式**，
模型可以准确知道自己离胜利还有多远、离被别人一击获胜还有多远（C2/C5 友好）。

**适配度：★★★★★**

### 5.2 Shadow Empire（VR Designs / Vic Davis，Matrix Games）—— 行政压力 = 距离的函数

本作以后勤与行政的深度著称。两条机制值得记：

**（一）Administrative Strain（行政压力）**

社群整理（[Steam 讨论](https://steamcommunity.com/app/1154840/discussions/0/3470604115205909813/)、
[攻略](https://steamcommunity.com/sharedfiles/filedetails/?id=3195937264)）：
任何资产若距离所属 zone 的城市**超过 6 格**就产生行政压力，
**压力随距离与资产等级递增**，并**全面拉低该 zone 的产出**——
资源生产、税收、乃至最大仓储值都受影响。
缓解办法是**建新城、划新 zone**，并可用 Zone Borders 命令调整内部边界让新据点向中心靠拢。

**（二）领袖任职与关系分**

领袖有 40 多种技能，任 zone 总督、council 主任、HQ 指挥官或顾问。
关系分（Relation Score）直接改判定：**25 → 技能判定 −10；75 → +10；100 → +20**
（[Grognerd's Guide to Human Resources](https://steamcommunity.com/sharedfiles/filedetails/?id=2307478602)）。

**对本项目的价值：**

Shadow Empire 把"帝国太大管不过来"从一个抽象数值（EU4 的容量、OE 的 Authority）
下沉成了**一个空间函数**：`压力 = g(距离, 资产等级)`。
这比标量上限更适合本项目，理由有两条：

1. 本项目的 `commanderies.json` 有真实经纬度，`strategic-nodes.json` 有 61 个关隘港口渡口，
   **"距离"是现成的、可预计算的、而且是史实的**
2. 它让**地理成为战略的一部分**：远征拿下的飞地是负担而不是资产，
   而这正是汉末的真实约束【史实】——公孙度据辽东、士燮据交趾，
   中央对这些地方的实际控制力与距离直接相关

**但必须注意 C2**：不能把每郡的压力值都塞进观测。
**做法**：压力按**战区**聚合成一个 3 档标签（宽裕 / 吃紧 / 失控），
每郡的具体值留在引擎里，模型只看聚合值和"是哪几个郡拖累的"。

**适配度：★★★★（距离型行政压力，需按战区聚合）/ ★★★（领袖关系分改判定 —— 与本项目已有的忠诚重叠）**

### 5.3 Field of Glory: Empires（AGEOD / Slitherine，2019）—— Decadence

这是本文找到的**反滚雪球正面案例**，与 §3.4 的 Realm Divide 恰成对照。

机制（据 [Wargamer 评测](https://www.wargamer.com/field-of-glory-empires/review)
与 [Quarter to Three 年度评选文](https://www.quartertothree.com/fp/2020/01/21/6th-best-game-of-2019-field-of-glory-empires/)）：

```
Legacy（胜利分） = Culture（正） − Decadence（负）
```

- **Culture 是分散储存在每个区域里的**，并按该区域的**忠诚度做百分比折算**——
  忠诚波动，你的文化值就跟着波动
- **Decadence 是一个全国性的、缓慢自然衰减的值**，
  由**帝国规模**与**未完全平定的新占领土**产生
- 大量提升区域忠诚的建筑（竞技场、剧场、贵族区等）**本身会随时间产生 Decadence**
- 文明等级 5 级（部落 → 帝国），每级 5 个子级（Young → **Decadent**）
- 胜利：Legacy 领先第二名达到一定量即自动获胜；否则终局时最高者胜
- 区域可合并成"省"以**把政策执行下放给 AI**，降低管理负担

**为什么这比 Realm Divide 好，三条：**

| | Realm Divide（Shogun 2） | Decadence（FoG:E） |
| --- | --- | --- |
| 触发 | 一个阈值，全或无 | **连续的，边扩边涨** |
| 施加者 | 其他玩家（被迫的 AI 行为） | **规则本身** |
| 可否规避 | 不可 | 可：**平定、建设、控制节奏** |
| 玩家的应对 | 只有打 | **"打下来"和"消化掉"是两笔独立的账** |
| 对基准的影响 | 让"识别领先者"主导全场 | **让"扩张节奏"成为一道真题** |

**最后一行是关键。** Decadence 把征服拆成两个阶段：**取得**与**消化**。
一个模型可以打得很快但消化不了，另一个可以打得慢但每一块都吃干净。
**这两种策略的优劣是需要推理才能判断的，因此它是一个合格的区分器（C5）。**

**同时，它是 REVIEW【C2 苟活占优】的第二味药**：
Culture 按区域忠诚折算，所以**不作为的势力也不会自动积累 Culture**；
而 Decadence 随帝国规模持续产生，**大而不治的势力会持续失血**。
两头都堵住之后，"守着不动"不再是安全策略。

**汉末的对应物**【史实】：**"新破之地"与"久附之地"的区别**是真实的军事政治常识——
曹操取徐州后的反复、刘备入蜀后数年的安抚、孙氏对山越的长期经营，
都是"打下来 ≠ 拿到手"的实例。

**落地草案：**

```
国力指数 PI = 治绩 − 虚耗

治绩：Σ over 己方郡国 ( 户口 × 民心系数 × 岁月系数 )
      岁月系数：新附 0.3 → 每季 +0.1 → 归附满 7 季后为 1.0
      民心 < 30 的郡，岁月系数清零重算

虚耗：k1 × (郡国数 − 行政容量)⁺ + k2 × Σ(新附郡数) + k3 × 未平定的叛乱数
      每季自然衰减 −8%
```

这一条同时替掉了首轮方案 §9.1 的"国力指数"里"只数户口与郡数"的写法，
并直接回应 REVIEW 算出来的边际交换率问题：**拿地在头 7 季是亏的，第 8 季起才回本**，
于是"拿多少 / 什么时候拿 / 拿完先不先消化"变成三道相互耦合的真题。

**适配度：★★★★★（Decadence / 治绩-虚耗结构）/ ★★★★（区域合并为省以下放执行）**

### 5.4 Imperiums: Greek Wars（Kube Games，2020）—— 腐败与陪都

官方手册（[Imperiums 手册 PDF](https://cdn.cloudflare.steamstatic.com/steam/apps/1520480/manuals/Manual.pdf)，§2.2 与 §3.1）：

- **腐败是局部现象**，不是全国常数；随地点变化
- 严重程度取决于**国家的规模与实力**，以及**距首都或陪都（Regional Capital）的距离**
- 对策：在边远地区**建陪都**；首都与陪都都能压制其周边的腐败
- 全国只能有一个首都，但**陪都可以有多个（数量取决于帝国规模）**；
  任何达到一定规模的城市都可以升为陪都
- **政体决定四件事**：腐败的最大影响、达到最大影响所需时间、
  **陪都之间的最小间距**、陪都周边城市的忠诚下降幅度

**最后一条是精华。** 它把"政体"从一堆百分比修正，变成了
**一组关于你的行政几何形状的约束**：
不同政体让你能铺多密的陪都网，从而决定你的帝国能长成什么形状。

**汉末的对应物是完全现成的**【史实】：**州治与都督区**。
东汉十三州各有州治，`commanderies.json` 里的 105 郡国天然按州归属；
汉末实际出现的"都督某州诸军事"正是一个跨郡的行政中枢。

**落地草案（与 §3.3 的方针槽位合并成一个系统）：**

```
势力可设 1 个「霸府 / 治所」+ N 个「州治 / 都督府」
N = f(名分, 行政容量)，开局 1，上限 4
每个治所压制其周边若干郡的「离心」（按图距离衰减，用 strategic-nodes 的连通性算，不用直线距离）
两个治所之间必须相隔 ≥ M 跳（M 由「名分路线」决定：奉诏路线 M 大，自署路线 M 小但威望持续损耗）
```

这样，**"我的行政中枢摆在哪"就变成一道纯粹的空间规划题**：
动作集只有 O(郡国数) 且每局只做 2–4 次（C3/C4 极友好），
但它的后果贯穿全局，而且要求模型真正理解地图的连通结构（C5 友好，
且正是 SAGA 论文说的 Scene Blindness 的对症题型，见 `GAMEPLAY-AI-FRIENDLY.md` §3.3）。

**适配度：★★★★★（陪都 / 治所网络）/ ★★★★（政体决定行政几何）**

### 5.5 横向对比：五种"行政上限"的写法

这是本章最有用的一张表。五款作品对同一个问题给了五个不同的答案：

| 写法 | 出处 | 成本口径 | 超限后果 | 规避手段 | 可序列化性 | 适配度 |
| --- | --- | --- | --- | --- | --- | --- |
| **数量上限** | OE Authority | 城镇**个数** | 贵族动乱大涨 → 分裂 | 附庸化 | 极好（两个整数） | ★★★★★ |
| **加权容量** | EU4 Governing Capacity | Σ(发展度 × 治理系数) | 递增数值惩罚 | 降级为领地 / 建法院 | 极好（一个标量） | ★★★★★ |
| **距离函数** | Shadow Empire 行政压力 | g(距城市的格距, 资产等级) | 全 zone 产出下降 | 建新城划新 zone | 中（要聚合） | ★★★★ |
| **距离 + 陪都网** | Imperiums 腐败 | 距首都/陪都的距离 | 局部腐败、忠诚下降 | **建陪都**（有间距约束） | 好（按治所聚合） | ★★★★★ |
| **消化时间** | FoG:E Decadence | 帝国规模 + 未平定的新地 | Legacy（胜利分）净扣 | 平定、控制节奏 | 极好（两个标量） | ★★★★★ |

**本文的建议：三条一起上，且共用同一个标量。**

```
行政容量 = 基线 + f(名分) + f(治所数与布局) + f(国策·文教)
行政成本 = Σ over 郡国 ( 户口权重 × 治理档位系数 × 距离衰减 )
  治理档位：直辖 1.0 / 羁縻 0.4 / 从属 0（不计入，但户口只按折扣计入 PI）
超限后果：豪族离心 +（超出量），离心到阈值则郡国自立（OE 式的贵族叛乱）
```

三个来源各出一半：**成本口径取 EU4，后果取 OE，距离项取 Imperiums**。
Decadence 不并进这个标量，它单独作为 PI 的负项（§5.3）。

## 六、桌游：多人不对称博弈的设计手法

### 6.0 为什么这一章对本项目的信息密度最高

《Diplomacy》在首轮已被判定为骨架五星（`GAMEPLAY-AI-FRIENDLY.md` §1.2A），本章不重复。
但桌游作为一个整体，对本项目的价值高于任何电子游戏，原因有三条：

1. **桌游的规则必须能被人在脑子里跑完。** 这是一个天然的复杂度上限，
   而它恰好与"规则要能塞进系统提示、模型要能心算结算"这条要求同构。
2. **桌游的动作空间天然是可枚举的**，因为它必须能印在一张玩家辅助卡上。
3. **多人不对称博弈的设计经验，绝大部分沉淀在桌游里而不是电子游戏里。**
   电子游戏的多人不对称通常靠数值堆，桌游必须靠结构。

### 6.1 Twilight Struggle（GMT，2005）—— 共享牌堆与 DEFCON

#### 6.1.1 共享牌堆：你手里的牌可能是对手的武器

核心创新：**双方从同一副牌里抽牌**；
如果你打出的牌上印的是**对手的事件**，你可以用它的行动点（Ops），
**但那个事件照样会触发**
（[Clio's Board Games 分析](https://cliosboardgames.wordpress.com/2018/07/22/turning-weakness-into-strength-benefitting-from-opponent-events-in-twilight-struggle/)、
[The Thoughtful Gamer 评测](https://thethoughtfulgamer.com/2017/03/05/twilight-struggle-review/)）。

评论者的共识表述是：这一条规则**把一个来回拉锯的区域控制游戏变成了危机管理练习**——
你每一轮都被迫打出一张帮对手多过帮自己的牌，而且知道对手同样如此。

**这个结构对 LLM 竞技场的价值：**

它制造了一种**极便宜的两难**：动作集不变（还是"打哪张牌、用作事件还是行动点"），
但每个动作都自带一个负面副作用，于是**排序与时机成为唯一的技巧来源**。
没有任何随机性，没有任何隐藏信息（牌库公开、弃牌堆公开），
**纯粹靠"什么时候吃下哪个苦头"分高下**——这是 C5 的理想形态。

**汉末的对应物**：可以做成**「时局牌」**。
每季公开抽出 2–3 张时局（旱、蝗、疫、羌乱、鲜卑寇边、天子诏、士人清议、粮价、流民），
**每张牌都指名一个受益方与一个受损方**，任何一方都可以"引用"该时局来强化自己本季的某个动作，
**但引用之后该时局的既定效果照常发生**。

- 状态成本：牌堆是公开的，弃牌堆是公开的 → **观测里只需要一个牌 ID 列表**（C2 极友好）
- 动作集增量：每季 +2–3 条"引用时局"条目（C4 友好）
- 随机性位置：**抽牌在决策之前且公开** → 输入随机，符合 §5.1 的放置表（C5 友好）

**适配度：★★★★★**

#### 6.1.2 DEFCON：共享的厄运钟 + 归责

规则（[GMT 官方规则 PDF](https://www.gmtgames.com/living_rules/TSRules2nd.pdf)）：

- 在**战场国**发动政变会使 DEFCON **降一级**（更接近核战）
- **DEFCON 降到 1 则核战爆发，游戏立即结束**
- **当时的行动方（phasing player）被认定为责任方，判负**

社群举的经典例子：DEFCON 处于 2，美方打出"奥运会"牌，苏方选择抵制，
DEFCON 降到 1，核战触发——**判负的是作为行动方的美方**。

**这个机制的三个性质，每一条都罕见地契合本项目：**

| 性质 | 说明 | 对应约束 |
| --- | --- | --- |
| **状态是一个整数** | 整个机制的状态就是 DEFCON 的当前档位 | C2：几乎零 token |
| **所有人共享后果，但责任明确归属** | 谁把它推过线谁输 | C5：制造一场高质量的胆小鬼博弈 |
| **它给弱势方一件真正的武器** | 濒临出局的一方可以威胁"一起完蛋" | 反 kingmaker 的正解 |

第三条特别值得展开。首轮方案 §7.5（一）说"没有 kingmaker：末位方无法把胜利送给某人"，
这是对的，但它没有给末位方任何**正面的**筹码——末位方在最后十几季是完全无关紧要的，
这会让那几个席位的模型调用变成纯粹的浪费。
**共享厄运钟给了末位方一件武器**：不是"把胜利送给谁"，而是"让所有人都拿不到"。
这既保住了反 kingmaker，又让末位席位的决策仍然有分量。

**汉末的对应物**【史实】：**天下崩坏度**。
黄巾之后的中原秩序是一个真实在崩的东西，
而屠城、决水、纵兵掠食、大规模征发、驱民为兵，都是真实加速崩坏的行为。

**落地草案：**

```
「离乱」是一个 0–100 的全局公开整数，开局 194 年设为 40
上升：屠城 +8 / 决水灌城 +12 / 掠食姿态每季 +1 / 大规模征发 +2 / 引异族入塞 +15
下降：每年岁首 −3；「屯田」「安民」等工程完成 −2；全境无战事的一季 −1
离乱 ≥ 85 → 本局立即终止，判定为「天下俱丧」：
   最近一季推高离乱最多的那一方直接判负，其余按当时 PI 排名，但全体分数打七折
```

打七折那条是刻意的：**避免"引爆"成为一个纯粹的自杀式否决权**。
所有人都损失，但引爆者损失最大——这就是 DEFCON 的结构。

**适配度：★★★★★（本文第二推荐）**

### 6.2 Root（Leder Games / Cole Wehrle，2018）—— 不对称设计的当代标杆

#### 6.2.1 Reach：把"势力有多强势"做成一个公开的整数

《Law of Root》的建组规则（[Root Database 官方规则站](https://www.therootdatabase.com/law/setup/en/)）：
每个势力有一个 **reach（触及值）**，组局时所选势力的 reach 之和必须达到人数对应的下限。

| 势力 | reach | | 势力 | reach |
| --- | --- | --- | --- | --- |
| Marquise de Cat | **10** | | Riverfolk Company | 5 |
| Lord of the Hundreds | 9 | | Knaves of the Deepwood | 4 |
| Keepers in Iron | 8 | | Twilight Council | 4 |
| Underground Duchy | 8 | | Woodland Alliance | **3** |
| Lilypad Diaspora | 7 | | Corvid Conspiracy | 3 |
| Eyrie Dynasties | 7 | | Lizard Cult | **2** |
| Vagabond（第一/第二个） | 5 / 2 | | | |

| 人数 | 所需 reach 总和 |
| --- | --- |
| 2 人 | ≥ 17 |
| 3 人 | ≥ 18 |
| 4 人 | ≥ 21 |
| 5 人 | ≥ 25 |
| 6 人 | ≥ 28 |

**这是一条工程上极其务实的做法**：设计者不试图让每个势力等强，
而是**给每个势力标一个公开的强度数字，然后约束组合**。

**对本项目的直接用法**（见 §8.6 详述）：
给 194 剧本的每个席位标一个 **开局势能值**（可由 `scenario-194.json` 的郡国数、
户口总和、武将质量、邻接威胁数确定性算出），
**用它来约束"哪几个席位可以同场"以及"多局轮换时如何配对"**，
而不是徒劳地把六个席位调成等强。

#### 6.2.2 Eyrie 的 Decree：自缚式命令

规则（[Law of Root: Eyrie Dynasties](https://www.therootdatabase.com/law/eyrie-dynasties/en/)）：

- Eyrie 受"敕令（Decree）"约束，敕令有四栏：**征募 / 移动 / 战斗 / 建造**
- **每回合必须往敕令里加牌**（Birdsong 阶段加的牌中最多一张是鸟牌），
  然后**为敕令里的每一张牌执行一次对应动作**
- 鸟牌是万用的，可在任意地形执行；其余花色的牌**只能在对应地形执行**
- **只要有一张牌无法执行，政府立刻崩溃（Turmoil）**：
  每张鸟牌（含忠诚重臣）扣 1 分、除忠诚重臣外的敕令牌全弃、
  当前领袖翻面并换一位新领袖

**这是本文见过的最纯粹的"承诺装置（commitment device）"。**

它的博弈结构是：**你过去的命令约束你现在的行动，而且约束会累积**。
Eyrie 的力量来自敕令越长动作越多，风险也来自敕令越长越难全部执行完。

**为什么它对 LLM 竞技场特别有价值：**

`GAMEPLAY-AI-FRIENDLY.md` §6.2 已经把"**计划兑现度**"列为要测的过程指标之一
（模型声明的多回合意图，实际执行了几回合）。
但那是一个**被动观测**的指标——引擎在旁边记账，模型并不为食言付出代价。

**Decree 把它变成主动机制**：食言有明码标价的惩罚。
于是"我要不要把这一条写进长期计划"成为一个真正的决策，
而**长程规划能力**这件本来很难测的东西，被压缩成了一个可以直接读数的量。

**落地草案（给首轮方案的新增动作）：**

```jsonc
// 「军令状」：可选的自缚式承诺，一次季议最多立一条
{
  "action": "pledge",
  "clause": { "kind": "takeCommandery", "target": "濮阳", "byCouncil": 12 },
  "stake": "prestige:10"     // 押上的威望
}
// 达成 → 威望 +20，且该季 SP +2（连续三次达成再 +1）
// 逾期未达成 → 威望 −10（押注额），全军忠诚 −5，全局可见（进 treacheryLog）
```

三个性质：

- **完全可选**：不立军令状也能玩，所以它不强迫任何一种风格（避免 Realm Divide 式的单一化）
- **动作集只 +1 条**，且参数域就是现有的 campaign 目标域（C4 友好）
- **它是最直接的长程规划探针**：一个模型敢不敢立、立多远、达成率多少，
  三个数就能把规划能力的三个侧面读出来

**适配度：★★★★★（本文第三推荐）**

#### 6.2.3 Dominance：中途改判自己的胜利条件

规则（社群与官方规则站一致）：

- 标准胜利是 **30 分**
- 持有 **≥10 分**时可以打出**统治牌（Dominance card）**，
  **把自己的胜利条件从"30 分"换成"控制特定的若干地块"**
- 流浪者（Vagabond）在 4 人及以上局中不能这样用，而是可以用统治牌**与另一方结盟**：
  对象必须是除自己外分数**最低**的一方且未在联盟中；
  结盟后流浪者**不再计分**，若对方获胜则流浪者同胜

**两条独立的价值：**

**（一）"公开地更改自己的胜利条件"是一个绝妙的博弈层。**
它让"这一方到底想要什么"从一个静态事实变成一个**动态的、需要被推断和被应对的事实**，
但因为它是**公开宣告**的，所以它并不增加任何隐藏状态的序列化成本（C2 友好）。

**汉末的对应物**：**改换路线的公开宣示**。

| 路线 | 触发条件 | 改判后的胜利条件 |
| --- | --- | --- |
| **奉天子** | 持有汉室的「奉」筹码 | 天下户口的过半承认（§1.6） |
| **霸府** | PI ≥ 阈值 | 控制指定的 N 个战略节点（洛阳、长安、许、宛、寿春…） |
| **割据** | 被从属或 PI 低于末位阈值 | 存活至终局且保有本州全部郡国 |
| **僭号** | 威望极低但兵力极强 | 纯 PI 最高，但立即众怒拉满（对标袁术） |

宣告后**不可撤回**，且**全局可见**。这一条同时缓解 REVIEW 的
【C3 终局分级在开局就已经锁死】——因为终局判据不再是开局盘面的函数，
而是**每一方自己在局中做的一次不可逆选择**的函数。

**（二）落后方与领先方结盟的合法通道。**
流浪者规则的精妙之处在于**限定只能与最低分者结盟**，
于是它是一个**结构性的追赶机制**，而不是 kingmaker。
首轮方案 §7.5（五）"留一条投靠强者的路"方向对，但没有这条"只能投靠弱者"的约束。
两条都留着更好：**投靠强者要付威望，投靠弱者免费**——这就给了扶弱一个天然的价格优势。

**适配度：★★★★★（公开改判胜利条件）/ ★★★★（限定扶弱的结盟）**

### 6.3 Scythe（Stonemaier，2016）—— 组合式不对称与"禁用组合"

机制：每个玩家拿到一张**势力板（faction mat）**和一张**玩家板（player mat）**；
势力板给独特能力，玩家板给行动位的成本与收益结构；**两者组合**。

平衡手段（[Stonemaier 官方 FAQ](https://stonemaiergames.com/games/scythe/faq-scythe/)
与 BGG 平衡数据帖）：

1. **玩家板上的起始资源按出场顺序错开**，且这个错开量是**依据盲测数据**定的
2. **明确公布禁用组合**：对有经验的玩家，
   **Crimea/Patriotic 与 Rusviet/Industria 两组组合建议禁用**
   （抽到就把玩家板放回去重抽），新手第一局不受此限

**这两条做法都值得抄，而且是本文认为对"可评测性"最实用的两条。**

**（一）"按出场顺序错开起始资源"就是座位偏置的显式补偿。**
`GAMEPLAY-AI-FRIENDLY.md` §5.4 已经列了席位轮换（MINDGAMES 的做法）。
Scythe 的做法是**互补的另一半**：轮换是在多局尺度上抹平偏置，
**起始资源补偿是在单局内减小偏置**。两者同时用，方差更小。

**（二）"公布禁用组合"是承认平衡有极限的成熟做法。**
一个竞技场不必强求所有开局配置等强，但**必须知道哪些配置不等强，并把它们排除或标注**。
这直接引出 §8.6 的落地方案。

**适配度：★★★★★（起始资源按席位错开）/ ★★★★★（显式的禁用/标注组合）**

### 6.4 Here I Stand（GMT / Ed Beach，2006）—— 六条互不相同的记分轨

- **六个大国，各有一条独特的胜利路径**：奥斯曼、哈布斯堡、英格兰、法兰西、教廷、新教
- **所有人共用一副牌**，所以英格兰玩家可能抽到只有教廷或奥斯曼才能打的牌
- 它是**第一款把秘密缔约做成显著特色的牌驱动游戏**，
  设有专门的**回合前外交阶段（Diplomacy Phase）**
- **交易的内容不限于领土与同盟，还包括牌与事件本身**
- **关键：这些约定是非约束性的（non-binding）**

（据 [Shut Up & Sit Down 条目与评测](https://www.shutupandsitdown.com/review-here-i-stand/)、
[There Will Be Games 评测](https://therewillbe.games/articles-boardgame-reviews/2206-here-i-stand-review)、
[Stuart Ellis-Gorman 评测](https://www.stuartellisgorman.com/blog/review-here-i-stand-by-ed-beach)。）

评测中一段判断值得原样记下大意：**约定的非约束性是刻意的**——
它保留了 Diplomacy 式的背叛张力，
但因为背叛的对象通常是"这一回合的牌怎么打"而不是"整盘棋的位置"，
所以它避免了 Diplomacy 里"一次背叛彻底改变某人的整局处境"的副作用。

**三条可迁移的机制思路：**

**（一）非约束外交 + 后果只在中等尺度。**
首轮方案 §7.6 的背信日志（全局可见、永不删除、自动检测）方向正确。
Here I Stand 提示的补充是：**要让背叛的即时收益和即时代价都不要太大**，
否则博弈会两极化（要么没人敢背叛，要么背叛一次就定胜负）。
具体做法：**盟约的条款粒度要细**（一季的借道、一次的共同出兵、一批粮草），
而不是只有"结盟 / 不结盟"这种粗粒度。

**（二）"你手里有别人才能用的资源"制造交易需求。**
共用牌堆是这个思路的一种实现；本项目有一个更史实的实现：**在野人才与俘虏**【史实】。
你俘虏的将领可能对你无用（水土不服、资历不合、忠诚不可能），
但对某一方极有价值（旧主、同乡、姻亲）。
`officers.json` 里的 578 名武将有充足的关系数据可以支撑这个交易市场。
**这给外交通道提供了除"割地"之外的第二种硬通货**，而且它的价值是不对称的、需要推断的。

**（三）六条互不相同的记分轨。**
这一点本项目**不建议直接抄**，理由见 §8.3：
六条不同的记分轨会让"谁在领先"变成一个跨维度比较问题，
而跨维度比较在评测上是灾难——你无法判断"教廷的 12 分"和"奥斯曼的 12 分"哪个更强。
**本项目应当保留单一的公开进度条（PI）+ 私有目标的结构**（首轮方案 §9.1 的判断是对的），
把不对称放在**手段**上而不是**记分口径**上。

**适配度：★★★★★（细粒度非约束条款）/ ★★★★★（俘虏与人才作为不对称硬通货）/ ★★（各自独立的记分轨，不抄）**

### 6.5 COIN 系列（GMT / Volko Ruhnke，2012 起）—— 把动作空间压到 5 条的那把刀

以系列首作《Andean Abyss》为准
（[GMT 官方规则 PDF](https://www.gmtgames.com/andeanabyss/AARules-1c.pdf)，§1.1、§2.2–2.3）：

**结构：**

- 1–4 人，四方（政府 + 三个叛乱方），**各方胜利条件互不相同**
- **不发手牌**。76 张牌从牌堆逐张翻，**并且始终多翻一张公开给所有人看**
- 每张事件牌顶部印着**本张牌上各方获得资格（Eligible）的顺序**
- **每张牌上最多只有两方行动**
- **执行了事件或行动的一方，下一张牌上不具资格**

**第 2 顺位的选项菜单取决于第 1 顺位做了什么**（这张表就是整个游戏的动作空间）：

| 第 1 顺位做了 | 第 2 顺位可以做 |
| --- | --- |
| 只做了行动（Op） | **只能做有限行动（LimOp，仅一个地区、无特别行动）** |
| 行动 + 特别行动 | **可以改为执行事件** |
| 执行了事件 | **可以做行动，且可带特别行动** |

**过（Pass）**：不行动的一方得 **+1 资源**（政府 +3），**并保留下一张牌的资格**；
后面顺位的合资格方递补上来，获得同样的选项。

**另有一条明确写进规则的外交条款**（§1.5.1）：
玩家可以做任何符合规则的相互安排，但只能自愿转移资源或货运；
**所有谈判都是公开的；规则不约束玩家履行任何协议。**

**这套设计对本项目的价值极高，逐条说：**

**（一）每次决策的第一级菜单只有 5 条左右。**
「事件 / 行动 / 行动+特别行动 / 有限行动 / 过」——就这些。
对照 REVIEW §1.1 的实测：本项目六个席位在**开局第一回合**的第一级条目数是
**62 / 138 / 155 / 172 / 186 / 195**，四席已越过 140 条裁剪线。
COIN 证明**深度不必来自第一级的宽度**。

**（二）"行动了就丧失下一次资格"是一个纯结构性的节奏机制。**
它带来的战略深度是巨大的：**你必须判断这张牌值不值得用掉你的资格**，
因为用掉了，下一张牌（你已经看得见）你就只能干看着。

**这一条几乎是为本项目量身定做的**，因为它同时解决三个问题：

| 问题 | COIN 的资格机制如何解 |
| --- | --- |
| 动作集太大（REVIEW A1） | 第一级只有 5 条 |
| 六个席位动作集规模差 3.1 倍（REVIEW A1） | **所有席位的第一级菜单完全相同** |
| 调用成本（C3） | 不具资格的一方**根本不需要被调用**，一张牌只调 2 个模型 |

第三行值得单独强调：**这是一个直接的成本优化**。
首轮方案是每季调用全部 6 个模型；COIN 结构下，一个决策点只调 2 个。

**（三）"始终多翻一张"是一个被设计出来的、有界的前瞻窗口。**
不是全知，也不是全盲，**恰好一步**。
对 LLM 而言这是一个极其友好的规划题面：状态增量只有一张牌的 ID，
但它要求模型做真正的两步推理（"如果我现在用掉资格，下一张牌我就吃不到"）。

**（四）"所有谈判公开、规则不约束履约"与本项目的双通道设计天然契合。**
首轮方案 §7.1 已经把谈判与命令分成两个独立通道，
COIN 的这条规则等于确认了这个方向在多方桌游里是标准做法。

**落地草案（对首轮方案 §1.2「一次季议的六个阶段」的可选改造）：**

```
每季不再全员发言，改为「主议 / 副议」两席制：
  - 每季公布一张「时局牌」（§6.1.1），牌面印本季的行动次序
  - 按次序，第一个有资格的势力选择：全议 / 简议 / 让（Pass）
  - 第二个有资格的势力的菜单，按上表由第一个的选择决定
  - 行动了的势力下一季无资格；让的势力得资源并保留资格
  - 无资格方本季不调用模型，只走 standing 方针
```

**代价必须写清楚**：这会让每方的实际决策频率从"每季一次"降到"约每两季一次"，
在 60 季的局长下每方约 30 次决策点，**比首轮方案的 ~15 次全量决策还多**，
但**每次的 token 量小得多**。这是一个"多次小决策 vs 少次大决策"的取舍，
需要在 M1 切片上实测两种结构的区分度再定。**本文不替这个取舍下结论，但强烈建议做这个实验。**

**适配度：★★★★★（资格轮替）/ ★★★★★（第 2 顺位菜单依赖第 1 顺位）/ ★★★★★（多翻一张的有界前瞻）**

## 七、重点问题一：行政与委任 —— 怎么不让模型"几十个省逐个点"

### 7.1 先把这个问题拆成三个，它们的解法不一样

"几十个省逐个点"听起来是一个问题，实际上是三个，各自打在不同的约束上：

| 编号 | 问题 | 症状 | 打的是 |
| --- | --- | --- | --- |
| **P1 决策数爆炸** | 每个决策点要下的命令条数随郡国数线性增长 | 105 郡 × 若干动作 = 上百条 | **C4**（动作集可枚举）、**C3**（调用成本） |
| **P2 观测爆炸** | 每个郡的状态都得进上下文 | REVIEW【B1】：token 预算低估 1.7–3 倍 | **C2**（≤6000 token） |
| **P3 注意力平摊** | 就算动作集不大，模型也会"每处都关照一点" | 产不出取舍，六个模型的输出趋同 | **C5**（区分度） |

**这三个问题的解法互不通用，这是本章最重要的一句话。**

- 把郡聚合成战区，解 P1 与 P2，**完全不解 P3**（模型改成"每个战区都关照一点"）
- 把命令交给引擎默认执行，解 P1，**可能加重 P3**（模型更没有可下注的地方）
- 只有**总量受限的资源**（Order / 敕令槽 / 行政容量 / 资格）才解 P3，因为它强迫"这一份投入给了甲就给不了乙"

华语三国系列（`GAMEPLAY-RTK-SERIES.md` 已覆盖的 11 代、14 代的委任与都市方针）**主要在解 P1**，
基本不解 P3——这正是 §4.1 里西方评论者对《信长之野望》那条批评的实质：
"官员调来调去"不是操作量的问题，是**每一次调动都不需要放弃什么**的问题。

### 7.2 七个家族的做法

下面七类做法覆盖了本文调研到的全部西方样本。每一条标明它解 P1/P2/P3 中的哪几个。

#### 家族 A：削"每回合能碰几次"——行动预算

代表：**Old World 的 Orders**（已在 §5.1.1 展开）。

- 形状：一个每回合刷新的全局整数，移动一个单位、派一个工人都要花
- 解 **P1 + P3**（这是唯一天然解 P3 的家族：花在这里就不能花在那里）
- 不解 P2（省还在，状态还在）
- 代价：如果预算与版图同向增长，它就退化成"大势力动作多"，反而放大开局差距（§5.1.1 的第一条建议就是针对这个）

#### 家族 B：削"能管多大"——治理容量

代表：**OE 的 Authority**（§1.4）、**EU4 的 Governing Capacity**（§2.5）、**FoG:E 的 Decadence**（§5.3）。

- 形状：一个标量上限，超了就吃惩罚
- 解 **P3**（逼出"哪些地方直辖、哪些羁縻"的取舍），部分解 P1（羁縻的郡不进动作集）
- 不解 P2（除非羁縻的郡在观测里也降级为一行摘要——**这一点必须显式设计，不会自动发生**）
- 这一家族的合成方案见 §9.10

#### 家族 C：改决策粒度——空间聚合

代表：**Rome II / Attila 的省-区两级**（§3.1）、**Shadow Empire 的 zone**（§5.2）、
**FoG:E 把区域合并成省并把执行下放给 AI**（§5.3）、**Stellaris 的星区（Sector）**。

Stellaris 是这一族里做得最彻底的：指定一颗星球为星区首府，
**四个超空间跳跃范围内的星球自动并入该星区**；
星区可以整体设一个"发展方向（focus）"，由 AI 按该方向自动建造；
星区有自己的资源库存，也可以共用国库
（据 [gamepressure 攻略](https://guides.gamepressure.com/stellaris/guide.asp?ID=35462)、
[Gamer Empire](https://gamerempire.net/stellaris-how-to-create-sectors/)、
[Steam 讨论多帖](https://steamcommunity.com/app/281990/discussions/0/1870623560003647974/)）。

- 解 **P1 + P2**
- **不解 P3**，且有一个隐藏成本：聚合的边界是玩家画的，于是"怎么画边界"本身变成了一道新的、
  和战略无关的题（Stellaris 的 Zone Borders、Shadow Empire 的划 zone 都是这个问题）
- **对本项目的直接结论**：战区划分**不要交给模型**。用东汉十三州做固定分组（`commanderies.json` 已有州归属），
  只允许"设几个治所"这种 O(1) 的选择（§5.4）。把边界当成地理事实，不当成决策。

#### 家族 D：委任给一个有自己意志的代理人

代表：**Imperator: Rome 的总督**、**Civ VI 的总督**、**CK3 官僚政体的 Governor**（§2.6）、
**《信长之野望·新生》的国主授权**（§4.2）。

**Imperator: Rome 是这一族里最值得抄的一个，而它此前没被本文覆盖**
（§2.7 只谈了它的中国 mod）。规则要点
（据 [Imperator Wiki: Province](https://imperator.paradoxwikis.com/Province)、
[gamepressure: Governors](https://www.gamepressure.com/imperator-rome/governors/z8c30b)）：

- 每个大区（region）由一位**总督**治理，**总督自己决定该省的施政方针**
- 方针是一张明确的表，每条都是"拿什么换什么"，例如：
  **Bleed Them Dry** 税 +30%、商业 +20%，代价是忠诚 −0.25、粮食 −25%；
  **Harsh Treatment** 忠诚 +0.3，代价是产出 −40%；
  **Local Autonomy** 各阶层满意度 +15%，代价是产出 −40%
- **总督忠诚过低会锁死你改方针的能力**
- **省忠诚跌破 33 → 该省被判定为不忠，拒绝执行中央命令；该省内的领地无法交互**，
  建造与人口迁移全部被阻断；**忠诚归零则直接叛乱**

最后一条是本文在整个第七章里认为最有价值的单条设计：

> **它把"省"从动作集里动态移除了。**

绝大多数策略游戏的动作集是一个常数（省数 × 每省可做的事）。
Imperator 让它成为**局势的函数**：你治得越差，你能下的命令越少；
治得好，动作才回来。

**这对竞技场的意义非常大，逐条对约束：**

| 性质 | 说明 | 约束 |
| --- | --- | --- |
| 动作集随治理质量收缩 | 差的模型面对的动作集**更小**，不是更大 | C4：天然的上界保护 |
| "恢复动作自由"本身成为一个目标 | 模型有动机去修复而不是继续摊大饼 | C5：一个纯推理的中间目标 |
| 判据是一个整数阈值 | 观测里只需要"忠诚 41 / 不忠"一个字段 | C2：近乎零成本 |
| 完全确定性 | 33 是个硬线，不掷骰 | C5：可复盘 |

**Civ VI 的总督则贡献了另一条独立的、同样重要的机制：委任的粘性。**
系统有 7 位总督，各有 6 级晋升，共 42 个"总督头衔"，
头衔主要靠市政树解锁，**因此永远不够把所有总督点满**；
一城同时只能驻一位总督；
**把总督调到另一座城，就任期要从头计算**
（据 [Civilopedia: Governors](https://www.civilopedia.net/en-US/gathering-storm/governors/intro/)、
[Civ6 Wiki: Governors](https://civ6.fandom.com/wiki/Governors)）。

"调动 = 重置就任期"这一条**直接治 §4.1 那条批评**（官员调来调去）。
它把"换人"从一个免费操作变成一个有明确等待成本的投资决策。
与 §2.6 的"任免要花 150 权势"合起来，本项目的任免应当**同时有价格与延迟**：

```
任免一位太守：花威望（CK3 式）+ 到任后 N 旬内该郡加成不生效（Civ VI 式）
```

- 解 **P1 + P3**（委任占用稀缺的委任资源）
- 部分解 P2（下属的施政方针可以只用一个枚举值表示）
- **风险**：见 §7.6

#### 家族 E：例外管理 + 提案上行

代表：**《信长之野望·新生》的"具申"**（§4.2 已详述，本文对首轮方案的第三条重点建议）、
**Distant Worlds: Universe 的顾问建议**。

Distant Worlds 是这一族的极端：舰船设计、科研、殖民、谍报、征兵、殖民地建设、条约管理
**全部可以自动化，理论上可以做到没有一件事需要玩家操作**；
同时顾问会在殖民、防御、外交等方面给出**建议**
（据 [Steam 商店页](https://store.steampowered.com/app/261470/Distant_Worlds_Universe/)、
[SpaceSector 评测](https://www.spacesector.com/blog/2014/08/distant-worlds-universe-review/)、
[PCGamesN 评测](https://www.pcgamesn.com/distant-worlds-universe/distant-worlds-universe-review)）。

- 解 **P1 + P2**（引擎预筛，模型只看被筛出来的 5–15 条）
- **是否解 P3 取决于提案里带不带评分**：带排序就退化成"选第一条"（§4.2 已警告）
- 这是本项目**性价比最高**的一条：它不改任何规则，只改 harness，而 lmgame-Bench 的结论正是
  **harness 决定模型间能不能拉开差距**（`GAMEPLAY-AI-FRIENDLY.md` §5.4）

#### 家族 F：换掉决策对象——不是"省"，是"全国"或"阶层"

这一族在华语三国游戏里几乎没有对应物，值得展开。

**（一）Victoria 3 的中央建设队列。**
建造不是"在某省点某建筑"，而是**一条全国统一的队列**，
由国家预算（政府建设）与投资池（私营建设）两股力量推进，
两者的比例由「经济体制」法条决定
（据 [Vic3 Wiki: Building](https://vic3.paradoxwikis.com/Building)、
[TheGamer 攻略](https://www.thegamer.com/victoria-3-construction-building-types-automatic-expansion/)）。

形式上这削掉了 P1：省只是队列条目的一个参数。
**但社群的反馈提供了一条极重要的反直觉证据**：
Paradox 论坛上有专门的"废除建设队列机制"请愿帖，
核心抱怨是玩家把**绝大部分游戏时间花在管理和排列这条队列上**
（[Paradox 论坛请愿帖](https://forum.paradoxplaza.com/forum/threads/petition-to-end-the-construction-queue-mechanic.1594102/)、
[另一帖：集中化队列正在破坏本地价格与其他系统](https://forum.paradoxplaza.com/forum/threads/centralized-construction-queue-is-sabotaging-local-prices-and-gameplay-systems-in-general.1613537/)）。

> **结论：集中化本身不减负。减负来自"条目数有上限"，不来自"条目放在一个列表里"。**

这条结论直接适用于本项目：把 105 郡的动作收进一个全国队列，
如果队列长度没有硬上限，动作集一点没变小。
**必须配 Rome II 式的槽位上限（§3.3）才有意义。**

**（二）EU4 的阶层（Estates）与王领（Crown Land）。**
这是本文认为对汉末**最贴切、而华语三国游戏普遍没有**的一套结构
（据 [EU4 Wiki: Estates](https://eu4.paradoxwikis.com/Estates)，数值仅用于说明形状）：

- 多数国家有 3 个阶层（**贵族 / 教士 / 市民**），另有按地理与政体解锁的特殊阶层
- 每个阶层有两个 0–100 的值：**忠诚（loyalty）** 与 **影响力（influence）**
  - 忠诚 0–29 不忠（只给惩罚）/ 30–59 中立（给一项加成）/ 60–100 忠诚（给多项）
  - 忠诚均衡点基线 30，**每控制 1% 国土 +0.2**；影响力**每控制 1% 国土 +0.5**（上限 40）
  - **影响力到 100 且忠诚 <50 且不在战争中 → 触发该阶层的政变灾难**
- **王领**是君主直辖的比例，与阶层持有的土地此消彼长；多数国家开局约 30%；
  低于 30% 吃税收与集权惩罚，50% 以上给加成
- **特权（privilege）**：给阶层一项永久特权，换取加成，代价通常是**专制上限 −5%**；
  每个阶层一般最多 6 项；**收回特权要求忠诚高于影响力，且收回时掉 20 忠诚**
- 两个反向的、**各带 5 年冷却**的杠杆：
  - **收地（Seize Land）**：立刻 +5% 王领，**所有阶层 −20 忠诚**，谁掉到 30 以下就反
  - **卖官（Sale of Titles）**：卖出 10% 王领，**所有阶层 +10 忠诚**，换一笔现金

**为什么这个结构对本项目特别值钱，四条：**

1. **它用 3 个实体承载了 100 多个郡的政治状态。** 这是 P2 的终极解法：
   观测里不写"每个郡的豪族态度"，写"士人 / 豪族 / 军吏"三行。
2. **决策对象是阶层，不是郡。** 动作集大小与版图**完全解耦**（P1）。
3. **收地/卖官是一对纯时机题**（对照 §1.5 的 OE 诏令）：
   成本公开、收益公开、冷却公开，唯一的变量是"什么时候按"。
   动作集只 +2 条，却能问出很深的规划判断（C4 + C5 双友好）。
4. **汉末对应物是现成的【史实】**：编户齐民与豪族荫附是一对真实的、此消彼长的量；
   察举与征辟是真实的"特权"；曹操的屯田与租调、袁绍对河北大姓的倚重，都是这条轴上的具体位置。
   本项目可用**三个阶层**：**士人（清议与征辟）/ 豪族（部曲与荫户）/ 军吏（兵源与军功）**。

- 解 **P1 + P2 + P3**（唯一一个三项全解的家族）
- 代价：需要一套新的属性与结算，是本文所有建议里工程量最大的一条

#### 家族 G：削决策频率与资格

代表：**COIN 的资格轮替**（§6.5）、**Rome II 的敕令数受帝国等级封顶**（§3.3）。

- 解 **P1 + P3 + C3**（不具资格的一方根本不调用模型）
- 不解 P2
- 这是唯一能直接压低**调用成本**的家族，因此它同时对上 REVIEW 的【E1 预算差 20 倍】

### 7.3 七个家族的总对照

| 家族 | 代表 | 解 P1 决策数 | 解 P2 观测 | 解 P3 取舍 | 引入的新状态 | 工程量 | 适配度 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **A 行动预算** | Old World Orders | ✅ | ❌ | ✅ | 1 个整数 | 小 | ★★★★★ |
| **B 治理容量** | OE / EU4 / FoG:E | 部分 | 需显式设计 | ✅ | 1–2 个标量 | 小 | ★★★★★ |

| **D 代理人委任** | Imperator / Civ VI / CK3 | ✅ | 部分 | ✅ | 每战区 1 枚举 + 忠诚 | 中 | ★★★★★ |
| **E 提案上行** | 信长·新生 / Distant Worlds | ✅ | ✅ | 看是否带排序 | 无（纯 harness） | **小** | ★★★★★ |
| **F 换决策对象** | Victoria 3 / EU4 阶层 | ✅ | ✅ | ✅ | 3 阶层 × 2 值 + 王领 | 大 | ★★★★★（阶层）/ ★★（中央队列） |

### 7.4 本项目的组合方案：四道闸门

把上面的东西装成一条漏斗，每一道闸门砍掉一个数量级：

```
闸门 1（广度）：行政容量        —— 决定你能直辖几个郡，其余走羁縻/从属（家族 B，§9.10）
                                   效果：进入动作集的郡从 105 降到 ~15–30

闸门 2（粒度）：决策对象换层    —— 模型下的是「战区方针」与「阶层政策」，不是郡级命令
                                   （家族 C 固定分组 + 家族 F 阶层）
                                   效果：第一级条目从 O(郡数) 降到 O(战区数 + 3)

闸门 3（呈现）：提案通道        —— 引擎按确定性规则预筛 5–15 条「具申」，不带评分不带排序
                                   （家族 E）
                                   效果：郡级的事仍然发生，但只以"下属提了什么"的形式出现

闸门 4（频率）：资格轮替        —— 每个决策点只有 2 方具资格，其余走 standing 方针
                                   （家族 G）
                                   效果：单次决策点的模型调用数从 6 降到 2
```

**预算目标（建议写进验收标准）：**

| 量 | 首轮实测 / 估计 | 本文建议的目标 |
| --- | --- | --- |
| 第一级动作条目数 | 62–195（REVIEW §1.1） | **≤ 12，且六席之差 ≤ 1.5 倍** |
| 观测 token | 低估 1.7–3 倍（REVIEW【B1】） | ≤ 6000，其中郡级明细 ≤ 1200 |
| 单个决策点的模型调用数 | 6 | **2** |
| 每方每局全量决策次数 | ~15 | 20–30（次数增、单次变小） |

第一行的后半句"六席之差 ≤ 1.5 倍"是本文新加的：
REVIEW 指出六席开局的第一级条目数差 3.1 倍，
**这意味着六个模型面对的根本不是同一道题**——这是评测口径问题，不只是成本问题。
闸门 1 + 闸门 2 天然压缩这个差距，因为战区数与阶层数不随版图线性增长。

### 7.5 一条容易搞错的分界：聚合决策，不要聚合后果

上面四道闸门全都作用在**决策**上。有一条必须同时守住：

> **郡不再是决策对象，但郡必须仍然是后果对象，而且因果链要短到模型能自己推出来。**

理由有两条，一条是设计的，一条是评测的：

- **设计上**：如果"我把方针从劝农改成征兵"之后，模型看不到任何一个郡发生了可归因的变化，
  那么这个决策对模型来说就是一次盲注，它学不到东西，也没法在后续决策里修正。
- **评测上**：委任链条越长，模型的决策与终局结果之间的**因果距离**越远，
  同一个决定的效果被更多中间过程稀释，**区分度就越低**。
  这与 §8.5 要讲的方差问题是同一件事的两面。

**具体做法**：观测里对每个战区给出**"上一季这条方针实际产生了什么"的三行回执**
（户口变化、民心变化、粮秣变化，以及贡献最大/最小的两个郡的名字）。
这比给出 30 个郡的完整明细便宜两个数量级，但保住了因果可读性。

### 7.6 委任的天花板：这是本章唯一一个必须先做实验才能回答的问题

所有委任设计都有一个共同的、在游戏设计文献里**不会被讨论**的风险，
因为商业游戏的"被委任方"是 AI，而"委任方"是人；本项目两边都是模型。

**风险的形状：**

```
令 S(π) 为某个策略 π 的终局得分。
  S(默认)   = 模型什么都不管，全部走引擎的 standing 方针
  S(弱模型) = 一个能力较弱的模型接管
  S(强模型) = 一个能力较强的模型接管

定义「委任余量」 headroom = S(强模型) − S(默认)

如果 headroom ≈ 0，这个竞技场测不出任何东西。
```

两个已知的失败模式，各有商业实证：

| 失败模式 | 症状 | 实证 |
| --- | --- | --- |
| **默认太笨** | 玩家被迫全部手动接管，微操从后门回来 | **Stellaris**：社群对星区 AI 与星球自动化的评价高度负面且长期稳定——AI "把每一栋建筑都升级一遍"、"每颗星球什么都产一点、毫无协同"，共识是重要星球仍须手动管理（[Steam 讨论：自动化在 3.0 里变好了吗](https://steamcommunity.com/app/281990/discussions/0/5711105714142951051/)、[星区 AI 与星球自动化的讨论帖](https://steamcommunity.com/app/281990/discussions/0/3342162929525647553/)） |
| **默认太强** | 委任方无事可做，决策质量与结果脱钩 | **Distant Worlds**：官方与评测都强调"可以全部自动化到没有一件事需要你做"（同 §7.2 家族 E 的引用）。作为单机体验这是卖点；作为竞技场这是**零区分度** |

**因此本文给出的不是一条设计建议，而是一条工程纪律：**

1. **默认策略必须是写死的、公开的、确定性的、并且故意平庸的。**
   "保守但不犯低级错误"——不抢地、不弃地、不背盟、粮低于阈值就停止征兵。
   理由有三条：可复现（同一局面同一行为）；给模型留出余量；
   **而且模型能预测默认会做什么，这本身是一道可推理的题**（对照 §6.5 COIN 的"多翻一张"）。
2. **每一层委任分别测 headroom。** 战区方针一层、阶层政策一层、提案采纳一层。
   哪一层 headroom 接近零，哪一层就该被删掉或改造——**它只是在烧 token**。
3. **把 headroom 写进 M1 的验收标准**，具体门槛见 §10.4 的实验 E-2。

**这条纪律的一个直接推论，与直觉相反：**
不是委任层越多越好。首轮方案的三层委任（国策 → 战区方针 → 郡级自动执行）
在 P1/P2 上是对的，但**每加一层，headroom 就被稀释一次**。
本文建议的四道闸门里，闸门 3（提案）与闸门 4（资格）**不增加委任深度**——
它们改的是呈现与频率，不是把更多决定权交出去。这是刻意的。

## 八、重点问题二：不对称势力怎么做到既平衡又可评测

### 8.1 先分层：不是所有"不对称"的评测代价都一样

游戏设计学界对不对称有两套常被引用的框架：

- **Fullerton (2018)**《Game Design Workshop》第 4 版：不对称游戏由四类差异构成——
  **能力（abilities）、资源（resources）、规则（rules）、目标（objectives）**
- **Bayrak & Ruhe (2022)**（CHI PLAY '22，[DOI: 10.1145/3505270.3558333](https://doi.org/10.1145/3505270.3558333)）：
  把不对称定义为一种结构特征——"玩家能做的事有多不一样所导致的玩法差异"，
  并归纳出六个机制维度：**操作、位置、时间框架、相互依赖、结果、反馈**
- **Campelo & Roque (2022)**（DiGRA '22，[DOI: 10.46787/digra2022-90](https://doi.org/10.46787/digra2022-90)）：
  把不对称分为**内生（endogenous）与外生（exogenous）**两大类

（这三条经由 [Zhou & Zhou (2025), *Teapot: An Exploration of Asymmetric Design in Board Games*,
乌普萨拉大学游戏设计系硕士论文](https://uu.diva-portal.org/smash/get/diva2:1975321/FULLTEXT01.pdf) 转引与整理，
该论文本身是一个 1v3 不对称卡牌桌游的设计实践报告，其框架部分对本项目有用，其原型本身与本项目无关。）

**但这些框架都是为"玩起来好不好"服务的，不是为"测得准不准"服务的。**
本项目需要的是另一张表——按**评测代价**排序：

| 层级 | 不对称在哪 | 例子 | 六席面对的是不是同一道题 | 抹平方法 | 所需样本量 | 建议 |
| --- | --- | --- | --- | --- | --- | --- |
| **L1 盘面** | 同规则，不同开局 | 全战三国的不同君主；本项目现状 | **是**（规则同，题面不同） | 席位轮换可**完全**抵消 | 基线 | **v1 做** |
| **L2 资源/能力** | 同规则，不同起始数值与特技 | Scythe 的势力板；RTK 各家武将差异 | 基本是 | 轮换 + **起始补偿** | ~1.5× | **v1 做** |
| **L3 规则** | 每方的合法动作集不同 | Root 的猫/鹰/联盟；COIN 四方 | **否** | 只能靠大样本 + 显式标注 | ~3–5× | **v2 再说** |
| **L4 目标** | 每方记分口径不同 | Here I Stand 六条记分轨 | **否，且不可比** | 没有可靠方法 | 不可行 | **不做（§8.3）** |

**这张表是本章的骨架**。它说明一件在游戏设计里不重要、在竞技场里决定成败的事：

> 不对称的代价不是"不好玩"，是**"要跑更多局才能把模型的差别从席位的差别里分出来"**。

而本项目的局长是 15 年 / 60 季，一局的算力成本不低，**样本量就是最硬的预算约束**。

### 8.2 西方的五种平衡手法（工程做法，不是设计理念）

| # | 手法 | 出处 | 形状 | 本项目能不能用 |
| --- | --- | --- | --- | --- |
| 1 | **公开的强度值 + 组合约束** | Root 的 reach（§6.2.1） | 每方一个整数，组局时要求总和达标 | **能，直接用**（§8.6） |
| 2 | **起始资源按顺位错开** | Scythe（§6.3） | 依据盲测数据定的补偿量 | **能** |
| 3 | **公布禁用 / 标注组合** | Scythe（§6.3） | 明说哪两个组合不该同场 | **能** |
| 4 | **竞标执方 / 让先** | Twilight Struggle 锦标赛惯例 | 出价决定谁执哪方，弱方得补偿 | 需改造，见下 |
| 5 | **大样本迭代** | Root 的社群数据 | 靠上千局数据反复调 | **必须做，但要注意 §8.4** |

**第 4 条值得单独说，因为它在竞技场里有一个原版没有的额外收益。**

Twilight Struggle 的锦标赛实践是：双方竞标，赢标者选边，弱势方得到起始影响力补偿；
社群共识大致是给美方 +2 影响力，且很少超过这个量
（这是**锦标赛惯例与社群共识，不是 GMT 官方规则**；
本文在 [GMT 官方第二版规则 PDF](https://www.gmtgames.com/living_rules/TS_Rules_Deluxe.pdf) 中**没有**找到这条，
以下 Steam 讨论串是其社群出处之一：[讨论帖](https://steamcommunity.com/app/406290/discussions/2/364039531224161772)）。

把它搬进 LLM 竞技场，会多出一个副产品：

> **出价本身是模型对"我在这个席位上有多大胜算"的显式估计，
> 因此竞标 = 免费得到一份校准度（calibration）数据。**

具体做法：开局前让每个模型对每个席位给一个 0–100 的自评胜算，用它决定席位分配与补偿量；
终局后拿实际结果去比对，得到每个模型的**校准误差**。
这是一个与胜率完全独立的能力维度，而且几乎不花额外的 token（一次调用，几十个数字）。

**必须写清楚它的两个风险**，否则这条建议会被误用：

1. 自评是**可以被策略性操纵**的（低报以骗补偿）。因此**补偿量不能只由自评决定**，
   必须以 §8.6 的客观势能值为主、自评为辅（或者干脆把自评只用于评测、不用于分配）。
2. 它引入了一个**局外的元决策**，而元决策的能力与局内战略能力不是一回事。
   报告时必须分开列，不能混进主排名。

### 8.3 为什么不抄"各方独立的记分轨"

（本节是 §6.4 与 §6.6 的展开。）

Here I Stand 给六个大国六条互不相同的胜利路径，COIN 给四方各自的胜利条件。
作为桌游这是杰作；**作为评测基准这是灾难**，三条理由：

**（一）跨维度不可比，模型排名失去意义。**
"教廷的 12 分"与"奥斯曼的 12 分"不是同一个量。
一旦记分轨不同，你能得到的只有"谁赢了这一局"这一个 bit，
而 `GAMEPLAY-AI-FRIENDLY.md` §6.2 已经指出：一局一个 bit 的统计功效极低。
**独立记分轨会摧毁所有过程指标的可比性**——而过程指标才是本项目区分度的主要来源。

**（二）观测与理解成本按方数翻倍。**
每个模型都要读懂六套记分规则才能预判对手（不然连"谁在领先"都算不出来）。
这直接顶到 C2，而且更糟的是：**不同模型对"规则文本理解"的差异会混进结果**，
让人分不清输的是战略还是阅读。

**（三）它会让一个零推理的任务主导全场。**
这与 §3.4 的 Realm Divide 是同一个病：
当"搞清楚谁快赢了"变成一道需要跨六套规则做换算的难题时，
最优策略就是把算力花在换算上，而不是花在战略上。

**替代方案（保留不对称、但保住可比性）：**

```
单一公开进度条 PI（首轮 §9.1 的判断是对的，保留）
  ＋ 私有目标（个数计分，§5.1.2）
  ＋ 路线（§6.2.3 的 Dominance 式公开改判）

关键约束：所有路线最终必须折算到同一个 PI 尺度上。
路线改变的是「怎么挣 PI」，不是「PI 怎么算」。
```

这样得到的是**可比的不对称**：六方的手段不同，但尺子只有一把。
而且路线是**局内选的、公开的、不可撤回的**，
所以它属于 Campelo & Roque 意义上的**内生不对称**——
规则手册对所有人相同，差异是打出来的。**这是竞技场里唯一免费的不对称。**

### 8.4 免责：桌游胜率数据的方法边界

（本节是 §0.4 那条声明的展开。以下所有数字都**不用于任何标定**，只用于说明量级。）

**Root 的数据是本文找到的最好的一份，它的口径如下**
（[Synergy in the Woodland: Analysing almost 3000 games of Root](https://compulsiveresearchmtg.blogspot.com/2023/12/synergy-in-woodland-analysing-almost.html)）：

- 样本 **2,957 局**，由三个来源拼接：Root Digital League **2,484** 局、
  锦标赛 **216** 局、HRF Web App **257** 局
- **只统计 4 人局**（作者明说，是为了让"胜率"有一致含义）；4 人局的基线胜率是 25%
- Vagabond 的各个角色被合并为一个势力；**联盟胜利被剔除**
- 报告的胜率（含置信区间）：
  Rats 35.80%（±7.38）、Duchy 30.74%（±2.21）、Eyrie 29.57%（±2.10）、
  Vagabond 25.51%（±1.96）、Alliance 25.14%（±2.41）、Badgers 24.83%（±6.94）；
  文中同时给出更低的几家（Riverfolk、Marquise、Corvid、Lizard），最低一档在 17% 量级
- 作者自陈的局限：三个数据源之间口径不一致，数字被 Digital League 主导；
  Rats 与 Badgers 因样本少，置信区间达 ±7%

**从这份数据能得到的唯一结论，也是本章最重要的一条：**

> **Root 是当代不对称设计的标杆，有官方数字版持续产出数据、有多年迭代，
> 它的势力胜率区间仍然是大约 17%–36%，而基线是 25%。最强与最弱差约 2 倍。**
>
> **因此：不要指望把六个三国席位调平。目标应该是"知道每一席偏多少，并在评分时把它扣掉"。**

**三条必须写下来的核实边界：**

1. 检索过程中我看到过"按玩家经验分层的胜率"这类说法
   （例如新手局猫 28%、高手局降到 18%，联盟反向上升）。
   **我在能核实的一手来源里找不到这个分层分析**——上面那份 2,957 局的研究明确**没有**做技能分层。
   因此**本文不引用任何技能分层胜率**，尽管这恰恰是本项目最想知道的东西（见下）。
2. Twilight Struggle 的 +2 让先是**锦标赛惯例**，我未能在 GMT 官方规则中找到它。
3. 这些数据全部来自**人类对局**。人类的技能分布与模型的技能分布不是一回事，
   **迁移性未经验证**。这一点在 §8.5 会变得很关键。

### 8.5 可评测性的核心：把席位、模型、随机性三个量分开

这是整份文档里技术含量最高的一节，因为有一篇论文正好把这件事量化了。

**来源：** James Goodman, Diego Perez-Liebana, Simon Lucas,
*Seeding for Success: Skill and Stochasticity in Tabletop Games*,
IEEE Transactions on Games, Vol. 17, No. 3, pp. 777–786, 2025
（[arXiv:2503.02686](https://arxiv.org/abs/2503.02686)）。
实验在 [TAG（Tabletop Games Framework）](https://github.com/GAIGResearch/TabletopGames) 上跑，
覆盖 15 款商业桌游，智能体是按各游戏分别调参的 MCTS。

#### 8.5.1 它定义的指标：Span 与 Trimmed Span

```
对每一个随机种子，跑 1000 局，得到"先手胜率"
Span        = 这些胜率里的最大值 − 最小值        （0 = 种子完全不影响，1.0 = 种子完全决定）
Trimmed Span = 去掉最极端的 5% 之后的 Span
另外两个辅助指标：胜率分布的香农熵；落在 99% 二项置信区间外的种子比例
```

实测结果（论文 Table II，200 个种子 × 1000 局）：

| 游戏 | 人数 | Span | T-Span | 熵 | 越界比例 |
| --- | --- | --- | --- | --- | --- |
| Dots and Boxes（确定性对照） | 2 | 0.06 | 0.06 | 1.13 | 0.00 |
| Connect 4（确定性对照） | 2 | 0.08 | 0.06 | 1.21 | 0.02 |
| Diamant | 2 | 0.08 | 0.05 | 1.16 | 0.01 |
| **Puerto Rico** | 3 | **0.10** | **0.08** | 1.32 | 0.05 |
| Dominion | 2 | 0.32 | 0.27 | 2.58 | 0.56 |
| Seven Wonders | 3 | 0.48 | 0.34 | 2.89 | 0.72 |
| Can't Stop | 2 | 0.52 | 0.37 | 2.90 | 0.60 |
| Colt Express | 2 | 0.66 | 0.50 | 3.23 | 0.86 |
| Hearts | 3 | 0.65 | 0.52 | 3.25 | 0.81 |
| Stratego | 2 | 0.66 | 0.63 | 3.02 | 0.94 |
| Sushi Go | 2 | 0.80 | 0.67 | 3.41 | 0.76 |
| Virus | 2 | 0.92 | 0.70 | 3.23 | 0.73 |
| Love Letter | 2 | 0.99 | 0.87 | 3.69 | 0.88 |
| **Poker** | 2 | **1.0** | **0.99** | 3.63 | 0.95 |

**Puerto Rico 的 0.08 是本项目应当瞄准的量级**：一款有随机性的重策游戏，
种子对结果的影响与纯确定性游戏几乎无异。

#### 8.5.2 三条直接冲击本项目假设的发现

**（一）种子的影响随棋力上升而上升，不是下降。**

论文的原话大意是：在所有或大多数游戏里都存在一个清晰的模式——
**随着玩家棋力提高，随机种子的影响会增大**；
解释是更强的智能体更善于把好种子带来的优势兑现，
而弱智能体会把好牌打烂，反而掩盖了种子的影响。

**这一条直接冲击本项目的约束 C5 的常见理解方式。**
"模型越强，运气的影响越小"是错的；反过来才对。
**推论：不能靠"等模型变强"来解决方差问题，必须靠机制与实验设计。**
它也让本项目"把随机性全部前置到决策之前"（`GAMEPLAY-DESIGN.md` §9.4 的放置表）
从一个偏好变成一条硬要求。

**（二）镜像配对的收益远小于直觉，除非游戏本身极随机。**

论文 Table I：把 1000 局按"同种子交换位置各打一次"的镜像对来跑，
相对于 1000 个独立种子的单局：

| 游戏 | 单局方差 | 单局 95% 区间 | 镜像方差 | 镜像 95% 区间 |
| --- | --- | --- | --- | --- |
| Dots + Boxes | 0.247 | 6.2% | 0.247 | 6.2% |
| Dominion | 0.249 | 6.2% | 0.243 | 6.1% |
| Seven Wonders | 0.231 | 5.9% | 0.221 | 5.8% |
| Colt Express | 0.248 | 6.2% | 0.220 | 5.8% |
| Sushi Go | 0.249 | 6.2% | 0.204 | 5.6% |
| Hearts | 0.222 | 5.8% | 0.196 | 5.4% |
| **Poker** | 0.249 | 6.2% | **0.113** | **3.5%** |

（方差是"每局"口径，理论上限 0.250；区间用精确二项检验。）

**多数游戏的置信区间只收窄 0.1–0.4 个百分点。**
只有 Poker 这种"结果在发牌时就基本定了"的游戏，镜像才带来数量级的改善。

**对本项目的含义**：席位轮换（`GAMEPLAY-AI-FRIENDLY.md` §5.4 已列）**是必须做的，但它不够**。
它抵消的是席位偏置的**期望**，抵消不了**局与局之间的方差**。
真正的方差控制必须来自：**减少随机源本身** + **增加剧本数** + **过程指标替代胜负指标**。

**（三）存在"非单调种子"：在某些开局上，中等棋力反而赢得更多。**

论文 Table III 给出各游戏中"先手胜率随算力预算非单调变化"的种子比例：
Dominion **17%**、Poker **16%**、Virus **16%**、Love Letter **13%**、
Sushi Go 9%、Hearts 6%、Can't Stop 6%、Colt Express 3%、Seven Wonders 2%。
（论文指出，若完全没有规律，按其检验方法约有 2% 会被误标，
所以 Seven Wonders 与 Colt Express 实际上不表现这个性质。）
论文把成因类比为极小化极大搜索里的 **k-level trap**：
搜索到某个深度会选出一个局部看起来好、再深一层就是坏棋的走法；
差别在于这里的陷阱是**种子专属的**。

**对本项目的含义，非常直接**：
**单个剧本、单个种子上的胜负，不能用来给模型排序。**
在最坏情况下（Dominion 量级），约六分之一的开局会给出"中等模型打赢强模型"的结果，
而这不是噪声，是那个开局的结构性质。

#### 8.5.3 由此得出的评测协议（建议直接进 M1）

```
第 0 步：先测游戏，再测模型
  用一个固定的确定性 baseline 策略自我对局，跑 200 个剧本种子 × N 局
  计算 Trimmed Span
    T-Span ≤ 0.15  → 可以开始跑模型
    0.15–0.30      → 可跑，但必须加大剧本数，且不得报告单剧本结论
    > 0.30         → 不要跑模型。先改机制。这时测的是剧本，不是模型。

第 1 步：分源定位随机性
  论文 Table IV 的方法：每次固定一个随机源，其余照常，各测一次 T-Span
  本项目需要分别固定的源：
    ① 席位分配   ② 每季天时/灾异   ③ 在野人才刷新   ④ 私有目标抽取
  找出主导源，优先削它。（论文在 Catan 上的结论是初始地图布局比骰子序列更重要，
  在 Colt Express 上是角色发牌主导——两例都说明"开局分配"往往比"过程掷骰"更致命。）

第 2 步：拉丁方轮换
  6 个模型 × 6 个席位，一个拉丁方 = 6 局，保证每个模型在每个席位各执一次
  报告时把席位作为固定效应剥离：只做"同席位内的模型比较"

第 3 步：报告口径
  主排名用 TrueSkill（一局多人、非二元结果，Elo 不适用）
  同时报告过程指标（`GAMEPLAY-AI-FRIENDLY.md` §6.2 的清单）
  单独报告：席位固定效应的大小、每个席位的 baseline 分、以及委任余量（§7.6）
```

第 0 步是本文对首轮方案 §10 的一条新增建议，也是最便宜的一条：
**它不需要调用任何模型**，只要一个确定性策略和一台机器。
`GAMEPLAY-REVIEW.md` 判定数值层有 7 条致命问题，
而 T-Span 恰好是一个能在写完数值之后、跑模型之前就发现问题的**廉价体检项**。

### 8.6 落地：席位势能值与"已知不平衡组合"表

（本节是 §6.2.1 与 §6.3 引出的落地方案。）

**第一步：给 194 剧本的每一席算一个公开的势能值（对标 Root 的 reach）。**

本项目的数据足以确定性地算出它，不需要任何主观打分：

```
seatPotential = w1 · 郡国数
              + w2 · Σ户口（取对数）
              + w3 · 武将质量（officers.json：该势力初始在籍武将的能力分位数之和）
              + w4 · 战略节点控制数（strategic-nodes.json 的 61 个关隘港口渡口）
              − w5 · 邻接敌对势力数
              − w6 · 到最近关键城（洛阳/长安/许/邺/寿春）的最短跳数
```

**权重 w1–w6 完全未标定，本文不提供数字。**
标定方法是 §8.5 第 0 步的副产品：跑 baseline 自我对局，
用各席位的终局 PI 做回归，反解权重。**先有实测，再有权重，不要反过来。**

**第二步：把势能值公开给所有模型。**

这一条容易被忽略但很重要：
势能值是**公共知识**——每个模型都能自己从公开的地图与户口数据里估出来。
把它藏起来不会制造平衡，只会制造**"谁更会估"这个与战略无关的能力差**。
公开它，反而让"我处在什么位置、该采取什么姿态"成为一道干净的战略题。

**第三步：Scythe 式的起始补偿。**

按势能值反向给一次性起始资源（威望 / 粮 / 首年额外 SP），
补偿量同样由实测标定，不由设计者拍。
注意 Scythe 的做法是**依据盲测数据**定的，不是设计师估的——这一点必须照搬。

**第四步：Root 式的组合约束 + Scythe 式的禁用表。**

```
同场约束：一局六席的 seatPotential 总和落在 [下限, 上限] 区间内
          且极差（最高−最低）不超过阈值
标注表：  维护一份「已知不平衡的席位组合」清单，随实测数据更新
          M1 阶段大概率会发现若干组合（例如袁绍 + 曹操同场时的中原绞杀）
          发现之后的正确做法是「标注并排除」，不是「改数值硬凑平」
```

**为什么是"标注并排除"而不是"调平"**：§8.4 的 Root 数据已经给了答案——
一款迭代多年、数据充分的标杆作品都做不到调平。
把有限的工程量花在"知道偏差有多大并把它扣掉"上，回报远高于花在"消灭偏差"上。

### 8.7 建议的分期：v1 只做 L1 + L2，规则不对称留到 v2

**结论：第一版应当是"规则完全对称 + 盘面与资源不对称"。**

理由三条，全部来自前面的实测证据：

1. **样本量。** §8.1 的表：L3 规则不对称把所需局数推高 3–5 倍。
   在 60 季一局的成本下，这可能意味着 M1 根本得不出结论。
2. **可比性。** 规则不对称意味着六席的**合法动作集不同**，
   于是 REVIEW【A1】那条"六席动作集规模差 3.1 倍"的问题会被制度化，而不是被修掉。
3. **它不是必需的。** §8.3 已经给出了替代路径：
   **内生不对称**——所有人规则相同，但通过路线宣告（§6.2.3）、
   阶层特权（§7.2 家族 F）、法条二选一（§5.1.3）**在局内长出差异**。
   这种不对称在评测上几乎免费：规则手册只有一份，动作模板只有一套，
   差异出现在状态里而不是规则里。

**v2 里可以安全引入规则不对称的两个位置**（如果届时数据支持）：

| 位置 | 为什么相对安全 |
| --- | --- |
| **起始阶层结构不同** | 例如袁绍开局士族影响力高、曹操开局王领比例高、孙氏开局有额外的"江东豪族"阶层。规则表仍然是同一张，差的是初始值与可用条目 |
| **路线专属条款** | 走"奉天子"路线解锁的外交条款与走"霸府"路线的不同。但路线是**局内选的**，不是发牌发的 |

两者的共性：**差异是可枚举的、公开的、且落在同一套动作模板的参数域里**，
不需要为某一席写一套单独的规则。

### 9.0 判定口径：我凭什么说"普遍没有"

**"普遍没有"必须有依据，否则就是拍脑袋。** 本章的依据是首轮两份文档的横向覆盖：

- `GAMEPLAY-RTK-SERIES.md`：光荣《三国志》本传 8 / 8 Remake / 9 / 10 / 11 / 13 / 14

### 9.1 可转让、不可撤回的正统筹码

- **出处**：Oriental Empires 的 Recognize Emperor / Son of Heaven（§1.6）
- **形状**：每方手里有**一枚**"承认"筹码，指向某一方；被指向者获得该方的人口计入天子进度；
  **给出后不可收回，只能转授**；承认了别人就断了自己的天子路线
- **华语三国的现状**：名分普遍是**自己的属性值**（威望 / 名声 / 声望），由引擎按规则算。
  我没有找到"由其余每一方各自持有、可转授、不可撤回"的实现
- **为什么对竞技场有价值**：它把一个内政数值变成了**六方之间可交易、可勒索、可交换的一次性棋子**。
  状态成本是每方一个 ID（C2 近乎免费），动作集是 +1 条 ×势力数（C4 友好），
  而它产生的博弈深度是本文见到的最高的
- **落地**：§1.6 已给 JSON 草案
- **适配度：★★★★★（本文第一推荐）**

### 9.2 承诺装置：把自己的手绑起来

- **出处**：Root 的 Eyrie 敕令（Decree，§6.2.2）
- **形状**：过去的命令累积成一份必须逐条兑现的清单，**有一条做不到就整体崩溃**
- **华语三国的现状**：没有。所有作品里，"上回合说要做的事"对这回合没有任何约束力
- **为什么对竞技场有价值**：`GAMEPLAY-AI-FRIENDLY.md` §6.2 把"计划兑现度"列为要测的过程指标，
  但那是**被动观测**——引擎在旁记账，模型食言不付代价。
  Decree 把它变成**主动机制**：食言有明码标价的惩罚。
  于是"长程规划能力"这件很难测的事，被压缩成三个可直接读数的量：
  **敢不敢立、立多远、达成率多少**
- **落地**：§6.2.2 的「军令状」草案（可选、押威望、逾期进背信日志）
- **适配度：★★★★★（本文第三推荐）**

### 9.3 共享的厄运钟 + 明确的归责

- **出处**：Twilight Struggle 的 DEFCON（§6.1.2）
- **形状**：一个所有人共享的整数，越界则全局立即终止，**并且把责任判给当时的行动方**
- **华语三国的现状**：没有同构物。最接近的是率土 / 战略版的**赛季重置**
  （`GAMEPLAY-OTHER-SANGUO.md` §三），但赛季重置是**对所有人一视同仁的定期清零**，
  不是"某一方把它推过线"，因此没有归责，也就没有胆小鬼博弈
- **为什么对竞技场有价值**：三条罕见的性质叠在一起——状态是一个整数（C2 几乎零成本）、
  后果共享而责任明确（C5：制造高质量的胆小鬼博弈）、
  **给末位方一件真正的武器**（不是"把胜利送给谁"，而是"让所有人都拿不到"），
  从而让最后十几季里落后席位的模型调用不再是纯浪费
- **落地**：§6.1.2 的「离乱 0–100」草案，含"引爆者判负、其余打七折"的分配
- **适配度：★★★★★（本文第二推荐）**

### 9.4 公开地、不可逆地改判自己的胜利条件

- **出处**：Root 的统治牌（Dominance，§6.2.3）
- **形状**：达到门槛后可以宣告换一套胜利条件；**公开、不可撤回**
- **华语三国的现状**：多轨胜利条件是有的（RTK 各代的统一/霸业档、率土的分级终局），
  但**轨道是引擎按盘面判定的，不是玩家自己宣告选定的**。差别在于"谁做这个选择"
- **为什么对竞技场有价值**：
  1. 它让"这一方到底想要什么"从静态事实变成**需要被推断、且推断得到的**动态事实，
     而因为宣告是公开的，**不增加任何隐藏状态**（C2 友好）
  2. 它直接缓解 REVIEW【C3 终局分级在开局就锁死】：
     终局判据不再只是开局盘面的函数，而是**每方局内一次不可逆选择**的函数
- **落地**：§6.2.3 的四条路线表（奉天子 / 霸府 / 割据 / 僭号），并按 §8.3 折算到同一把 PI 尺子上
- **适配度：★★★★★**

### 9.5 资格轮替：不是每一方每一回合都能动

- **出处**：COIN 系列（§6.5）
- **形状**：每张牌上只有两方能动；**动过的一方下一张牌没有资格**；
  过（Pass）的一方得资源并保留资格；第 2 顺位的选项菜单由第 1 顺位的选择决定
- **华语三国的现状**：**全部作品都是"每个回合每一方都行动"**。这是整个品类的默认假设
- **为什么对竞技场有价值**（这条同时解三个问题，见 §6.5 的表）：
  第一级菜单只有 5 条（对上 REVIEW【A1】）；**所有席位的第一级菜单完全相同**
  （对上"六席动作集差 3.1 倍"）；不具资格的一方**根本不需要被调用**
  （直接对上 REVIEW【E1 预算差 20 倍】）
- **风险**：它把决策频率从"每季一次"改成"约每两季一次"，是结构性改动，必须实测（§10.4 实验 E-3）
- **适配度：★★★★★（但须先做对照实验）**

### 9.6 不作为也要失血：把"静止"变成亏损

（本节兼答 §3.4 留下的问题：**怎么保证"众怒"不能靠"什么都不做"归零**。）

- **出处**：Field of Glory: Empires 的 Decadence（§5.3）+ Attila 的气候变化（§3.5）
- **形状**：
  - Decadence：`胜利分 = Culture − Decadence`。Culture **分散存在各区域、按忠诚折算**；
    Decadence 由**帝国规模**与**未消化的新占领土**持续产生，缓慢自然衰减
  - Attila：一张公开的、确定性的、逐年恶化的时间表，肥沃度最终永久 −4
- **华语三国的现状**：**在首轮覆盖的作品里，我没有找到把"静止"设为亏损的机制。**
  最接近的是率土 / 战略版的赛季重置，但那是对所有人一视同仁的清零，
  不构成"你不动就贬值、别人动了就相对上升"的压力
- **为什么对竞技场有价值**：这是 REVIEW【C2 苟活占优】的正面解。
  REVIEW 算出的边际交换率（袁绍席位丢地代价是拿地收益的 7.3 倍、曹操席位 26 倍）
  之所以成立，**前提是"不动的话资产不会贬值"**。Decadence 与离乱时间表同时打掉这个前提
- **对 §3.4 那个问题的具体回答**：

  ```
  众怒（或本文建议的「虚耗」项）必须满足两条，缺一不可：
    ① 它随时间自然衰减（否则退化为 Realm Divide 式的不可逆红线）
    ② 但它的衰减速度 < 「治绩」项因不作为而下降的速度
  这样，「什么都不做」能让众怒降下来，却会让 PI 净值继续下滑。
  于是「降温」是一个真实可选、但要付机会成本的动作，而不是一个免费的躲避键。
  ```

  这一条的意义在于：它保住了 §3.4 从 Realm Divide 学到的教训（**必须有降温通道**），
  同时堵住了降温通道被滥用成"苟活"的漏洞。**两个要求可以同时满足，靠的是速率差，不是靠禁止。**
- **落地**：§5.3 的「治绩 − 虚耗」公式 + §3.5 的离乱时间表（两者互补，不重复计分）
- **适配度：★★★★★（本文对 REVIEW【C2】的核心建议）**

### 9.7 阶层，而不是郡，作为决策对象

- **出处**：EU4 的 Estates 与 Crown Land（§7.2 家族 F），旁证是 CK3 的世家庄园（§2.6）
- **形状**：3 个阶层实体，各有忠诚与影响力两个值；王领与阶层土地此消彼长；
  特权是"永久让权换加成"；收地 / 卖官是一对带 5 年冷却的反向杠杆
- **华语三国的现状**：豪族与士人**通常是事件、修正值或武将属性**，
  不是一个**你可以与之交易、给它特权、从它手里收地**的对手方。
  RTK 系列有"名士""在野""登用"，那是**个体**层面的；
  EU4 的阶层是**集体行动者**，这是不同的东西
- **为什么对竞技场有价值**：
  1. **P2 的终极解法**：用 3 行承载 105 个郡的政治状态
  2. **动作集与版图彻底解耦**（P1）
  3. 收地 / 卖官是一对**纯时机题**：成本、收益、冷却全部公开确定，
     动作集只 +2 条却能问出很深的规划判断（对照 §1.5 的 OE 诏令）
  4. **汉末对应物完全是史实的**【史实】：编户齐民与豪族荫附是一对真实此消彼长的量
- **落地**：三个阶层——**士人**（清议、征辟、舆论）/ **豪族**（部曲、荫户、坞堡）/
  **军吏**（兵源、军功、直属武力）；一个"王领比例"对应**编户 / 荫附**之比
- **适配度：★★★★★（但工程量是本章最大的一条）**

### 9.8 成对互斥的法条

- **出处**：Old World 的 Laws（§5.1.3）
- **形状**：法条**成对互斥**（奴隶制 vs 自由、行会 vs 门阀），选了一边就永远拿不到另一边
- **华语三国的现状**：RTK 14 的「政策」与「主义」是最接近的，
  但主流结构仍是**"资源够就能点满一整系"**的积累式科技/政策树
- **为什么对竞技场有价值**：**它天然是取舍，不是积累。**
  积累式结构里，强模型的优势会变成"点得更快"，
  于是开局领先者的复利优势被放大（正是 §1.7 反对的那件事）；
  互斥结构里，优势体现在**选得对**，而且选择是公开的、可被对手针对的
- **落地**：§5.1.3 的四组汉末二选一（唯才是举 vs 举孝廉、屯田 vs 假民公田、
  世兵部曲 vs 征发郡兵、奉诏 vs 自署），全部有史料支撑
- **适配度：★★★★★**

### 9.9 逐个解锁、由开局选择驱动的私有目标

- **出处**：Old World 的 Ambitions（§5.1.2）
- **形状**：完成一个才解锁下一个；难度递增；目标池由开局所选的世家决定；继位者上台重选
- **华语三国的现状**：没有。剧本目标通常是固定的统一/存活条件，或是史实事件驱动的任务
- **为什么对竞技场有价值**：首轮方案的私有目标是**开局抽 2–3 个、固定不变**的，
  REVIEW【C2】指出其中至少 4 条是纯守成向的，与"苟活占优"直接共谋。
  Old World 的两条结构同时堵掉这个漏洞：
  1. **逐个解锁 + 难度递增** → 没有"选一组容易的目标然后龟缩"这条路
  2. **目标池由公开的、有代价的开局选择决定** → 不是随机发牌，因此可归因
  再加一条本文的补充：**用"完成个数"而不是"达成率"计分**，
  消掉"少领目标就容易满分"的漏洞
- **落地**：§5.1.2 的草案（家世 / 乡里 / 部曲三选二，公开；目标逐个揭示）
- **适配度：★★★★★**

### 9.10 行政容量：把三种写法合成一个标量

（本节是 §1.4、§2.5、§5.5 一路指向的落地方案，也是本文对首轮方案的第一条重点建议。）

**华语三国的现状**：普遍**没有版图规模上限**。城越多越强，是单调的。
"管不过来"这件事在光荣系列里基本靠**武将数量不够**间接体现，不是一条显式约束。

**五种西方写法已在 §5.5 对比过，本节给合成方案。** 取法原则是：
**成本口径取 EU4（可心算），后果取 OE（有戏剧性且与豪族耦合），距离项取 Imperiums（用现成的地理数据）。**

```jsonc
// ① 容量（供给侧）：一个标量，四个来源
adminCapacity = base                      // 基线，与席位无关
              + f(名分)                    // 奉诏 > 自署；对应 §3.5 的路线值
              + f(治所网络)                // 霸府 1 个 + 州治/都督府 N 个，N = f(名分, 容量)
              + f(国策·文教)               // 唯一与"发展"挂钩的一项，权重要小

// ② 成本（需求侧）：Σ over 己方郡国
adminCost = Σ ( 户口权重(郡) × 治理档位系数 × 距离衰减(郡, 最近治所) )

  治理档位（每郡三选一，这是一个可枚举的二元/三元动作，C4 友好）：
    直辖 1.0   —— 全部产出，全额占用容量
    羁縻 0.4   —— 产出打折，兵员不可直接征发，容量占用小
    从属 0.0   —— 不占容量；户口按折扣计入 PI（OE 式：附庸人口计入宗主）

  距离衰减：用 strategic-nodes.json 的 61 个节点算「跳数」，不用直线距离
            （理由见 §5.4：图距离才是史实上的控制成本）

// ③ 超限后果（OE 式，不是 EU4 式的产出打折）
overflow = max(0, adminCost − adminCapacity)
每季：受影响郡的「豪族离心」+= g(overflow)
      离心越阈值 → 该郡自立，析出为新势力，与你自动开战
      （并按 §1.3：豪族出身的部队可能倒戈；豪族私兵压不住豪族）
```

**为什么后果要取 OE 的"分裂"而不是 EU4 的"产出 −x%"：**

产出打折是一个**连续、可预测、可承受**的惩罚，模型的最优解是"算一下划不划算，然后超限"。
分裂是一个**离散、有阈值、且会把一块地送给敌人**的惩罚，
它逼出的是真正的取舍：**"这个郡我到底要不要直辖"**。
而且分裂出的新势力会重新变成一个可争取的对象，让地图重新流动——
这与 REVIEW【C1 地图冻结】是同向的。

**为什么成本要按户口加权而不是按郡数：**

按郡数（OE 原版）意味着南阳（东汉户口最多的郡之一）与一个边地小郡等价，
这既不史实，也让"拿哪个郡"这道题失去内容。
本项目的 `commanderies.json` 有现成的户口数，**加权几乎不增加任何工程量**。

**观测成本控制（必须显式设计，不会自动发生）：**

```
观测里不写每个郡的 adminCost 明细，只写：
  - 容量 / 成本 两个数，以及超限量
  - 每个战区一个三档标签（宽裕 / 吃紧 / 失控）        ← Shadow Empire 式聚合（§5.2）
  - 拖累最大的两个郡的名字                            ← 保住因果可读性（§7.5）
```

**适配度：★★★★★**

### 9.11 任免有价、有延迟，且免官不等于削弱

- **出处**：CK3 官僚政体的 150 权势任免与"世家庄园独立于官职"（§2.6）；
  Civ VI 的"调动总督重置就任期"（§7.2 家族 D）
- **形状**：任免要花一种专属货币；到任有一段不生效的时间；
  被免者的家族经济基础**不随官位消失**
- **华语三国的现状**：任免基本是**零成本、即时生效**的。
  这正是西方评论者对《信长之野望》那条批评的根源（§4.1："官员调来调去"）
- **为什么对竞技场有价值**：
  - 有价格 → "谁来当这个郡的太守"成为一道真正的资源分配题（P3）
  - 有延迟 → 消灭"每季重排一遍岗位"这种零信息量的高频动作（P1 + P3）
  - **根基独立于官职** → 免官不等于削弱对方，只是把对方从体制内推到体制外。
    这在汉末是精确的【史实】：袁氏的力量来自门生故吏与汝南南阳的乡里根基，不来自某个具体官位
- **落地**：§2.6 的 `appoint` 草案，加一条 Civ VI 式的到任延迟
- **适配度：★★★★★**

### 9.12 治理失败会让你的动作集变小

- **出处**：Imperator: Rome 的省忠诚 < 33 → 拒绝执行中央命令（§7.2 家族 D）
- **形状**：一个整数阈值，跌破之后该省**退出可交互范围**，建造与人口迁移全部阻断；归零则叛乱
- **华语三国的现状**：没有。混乱的城通常只是产出下降或叛乱概率上升，
  **仍然可以正常下令**
- **为什么对竞技场有价值**：绝大多数游戏的动作集是常数；
  这条让它成为**局势的函数**——治得差，能下的命令更少；治得好，动作才回来。
  对上 C4（天然的上界保护）、C5（"恢复动作自由"是一个纯推理的中间目标）、
  C2（观测里只多一个整数）
- **一个必须注意的副作用**：它会让落后方的动作集进一步萎缩，
  可能加速滚雪球。**必须与 §9.3 的共享厄运钟配对**——
  末位方的动作虽少，但手里那件"一起完蛋"的武器不受此限
- **适配度：★★★★★（须与 §9.3 配对使用）**

### 9.13 有界的前瞻窗口，与"用了就帮对手"的共享牌堆

这两条放在一起，因为它们都在改造**信息与时机**，而不是改造动作。

**（一）始终多翻一张（COIN，§6.5）**
- 形状：不是全知，也不是全盲，**恰好一步**
- 华语三国的现状：事件是黑箱，抽到才知道
- 价值：状态增量只有一张牌的 ID，却要求真正的两步推理
  （"如果我现在用掉资格，下一张牌我就吃不到"）。**这是本文见过性价比最高的规划题面**

**（二）共享牌堆：打出去的牌照样触发对手的事件（Twilight Struggle，§6.1.1）**
- 形状：动作集不变，但每个动作自带一个负面副作用，于是排序与时机成为唯一的技巧来源
- 华语三国的现状：事件通常是单方受益或单方受损的，不存在"用它就帮对手"的结构
- 价值：**零随机、零隐藏信息，纯靠"什么时候吃下哪个苦头"分高下**——C5 的理想形态
- 落地：§6.1.1 的「时局牌」草案（旱、蝗、疫、羌乱、鲜卑寇边、天子诏、士人清议、粮价、流民），
  每季公开抽 2–3 张，任何一方可"引用"来强化自己本季的某个动作，但该时局的既定效果照常发生
- **适配度：两条均 ★★★★★**

### 9.14 汇总：这 13 条的三个共性

**这 13 条能全部拿五星，不是因为它们各自多精妙，而是因为它们共享三条性质。
这三条性质本身，比任何单条机制都更值得记住：**

**（一）状态极小，后果极大。**
DEFCON 是一个整数，正统筹码是一个 ID，资格是一个 bool。
它们对 C2（≤6000 token）几乎零成本，却能改变整局的博弈结构。
**对照组**：建筑槽位、贸易路线、地块布局——状态巨大，后果琐碎。
**这条差异，比"东方 / 西方"这个分类更能解释本文的评级分布。**

**（二）公开且确定，随机性全部落在决策之前。**
时局牌先翻后决策，行政容量可心算，离乱时间表提前公布，攻城靠缺口数不靠掷骰。
这与 `GAMEPLAY-DESIGN.md` §9.4 的放置表完全同向，
而 §8.5.2 的第一条发现（**种子的影响随棋力上升而上升**）把这条从偏好升级成了硬要求。

**（三）制造的是取舍，不是积累。**
互斥法条、承认了别人就断自己的天子路、动了就丧失下次资格、
收地就掉忠诚、直辖就吃容量——**每一条都在问"你放弃什么"。**
而华语三国系列（乃至大多数商业 4X）的主体结构是**积累**：
攒钱、攒兵、攒科技、攒武将。积累式结构对单人游戏是正确的（它提供成长感），
**对竞技场是有害的**：它让开局领先转化为复利，而复利会淹没决策质量的差异（C5）。

### 10.2 攻城：缺口数取代兵力比的具体形状，以及它没解决的那一半

（本节是 §1.8 与 §3.1 指向的落地建议。）

**机制来源**：Oriental Empires 手册 pp.20–21（§3.1 已引）——
无墙据点视为**有四个缺口**，攻方可立即突击；有墙据点必须先破墙；
**缺口越多，守方越被摊薄**，攻方的正确解法是"多开缺口"而非"堆兵力比"。

**落地草案（替换 `GAMEPLAY-DESIGN.md` §5.5 的 `A/D` 门槛，不替换其余部分）：**

```
breaches = 基础缺口数(据点等级) + 器械投入产生的缺口

  基础缺口数：
    属县 / 无墙据点        4      ← 立刻可突击，不需要器械
    郡治（有墙）           0
    关隘（strategic-node） 0，且器械效率减半

  器械投入：一个 O(1) 的档位选择，进动作集，占 SP
    不投      +0
    冲车/临车 +1，需 N 旬准备
    土山/地道 +2，需 2N 旬准备，且需该郡地形允许
    火攻      +1，仅对木栅，且受时局牌"旱"影响（§6.1.1）

judgement（每旬，确定性）：
  守方能有效防守的缺口数 = ⌊守军单位数 / k⌋
  若 breaches > 守方可防守缺口数 → 破城
  否则 → 双方按现有折损公式交换，守方每旬修复至多 1 个缺口
```

**四条性质，逐条对约束：**

| 性质 | 说明 | 约束 |
| --- | --- | --- |
| 攻方的核心决策从"凑多少兵"变成"投多少器械、等几旬" | 这是一个**时间与资源的取舍**，不是一个乘法 | C1（不是微操）、C5（可分高下） |
| 动作集只 +1 条（器械档位） | 参数域 3–4 档 | C4 |
| 完全确定性，且缺口数是公开的 | 攻守双方都能算出还需要几旬 | C5（可复盘） |
| 小据点天然可破 | 属县基础 4 缺口，守军少的地方守不住 | 直接解冻地图 |

**但必须写清楚它没解决什么，否则这条建议会被误用：**

> **REVIEW【C1】有两个成因，缺口数只解了第二个。**
>
> 成因一：**一支军团的规模上限 = 单个郡的戍兵**，
> 袁绍能一次投入的兵力只占自己国力的 **12%**（REVIEW §3.1 实算）。
> 成因二：`A/D ≥ 2.2` 的破城门槛。
>
> **缺口数机制把成因二拆掉了，但成因一原封不动。**
> 如果不给出"从多个郡抽调兵员编成一支军团"的动作，
> 换成缺口数之后仍然会出现"攻方器械备齐了、但派不出足够守住新占地的兵"的僵局。

本文对成因一没有找到现成的西方对照物可抄——
本文调研的西方作品普遍**不把部队的规模绑定在出发地的驻军上**：
部队是地图上独立存在的单位，集结的成本是**行军时间与行动预算**（Old World 的 Order），
而不是"你只能带走出发那个郡养得起的兵"。**本项目的绑定是它自己的设计选择，因此也只能由它自己解。**
**因此这一条要么由首轮方案自己改（增加 `muster` 类动作），要么承认它是 M1 的已知缺陷。
本文明说：这里我给不出答案。**

### 10.4 必须先做的三个实验

这三个实验的共同点：**都在 M1 的模型对局之前或之中做，且前两个不需要调用任何模型。**

#### E-1：剧本随机度体检（T-Span）

```
输入：一个固定的确定性 baseline 策略（六席同策略），200 个剧本种子，每种子 N 局
输出：Trimmed Span（§8.5.1 的定义）
判据：
  ≤ 0.15  → 通过，可以开始跑模型
  0.15–0.30 → 有条件通过：必须加大剧本数，且报告中不得出现单剧本结论
  > 0.30  → 不通过。先改机制，不要跑模型
附加：按 §8.5.3 第 1 步分源测量（席位分配 / 天时 / 人才刷新 / 私有目标），找出主导随机源
成本：零模型调用
```

**这个实验回答的问题是**："这个游戏到底测的是模型，还是测的是开局。"
Goodman et al. 2025 给出的参照系：Puerto Rico 的 T-Span 是 0.08，Poker 是 0.99。
本项目应当瞄准 Puerto Rico 那一端。

#### E-2：委任余量（delegation headroom）

```
输入：三种策略各跑 M 局
  S0 = 全默认（模型只回"全部采纳"，不做任何选择）
  S1 = 一个已知较弱的模型
  S2 = 一个已知较强的模型
分层测：战区方针层、阶层政策层（若已实现）、提案采纳层，各自单独打开/关闭
输出：headroom = score(S2) − score(S0)，以及 score(S1) − score(S0)
判据：
  某一层的 headroom 在统计上不显著 → 该层要么删掉、要么改造
  score(S2) ≈ score(S1) → 该层区分不出模型强弱，同上
成本：零模型调用（S0）+ 2 × M 局模型对局
```

**这个实验回答的问题是**："我们的委任设计，到底有没有把模型的作用一起委任掉。"
两个已知的反面参照：Stellaris（默认太笨）与 Distant Worlds（默认太强），见 §7.6。

#### E-3：资格轮替 vs 全员季议

```
输入：同一份规则的两个变体
  V-A：每季六方全部下令（首轮方案）
  V-B：COIN 式资格轮替，每个决策点只有 2 方具资格（§6.5 / §9.5）
输出：三个量的对比
  ① 区分度：强弱模型的分差 / 分数标准差
  ② 成本：单局总 token 与总调用次数
  ③ 每方每局的实际决策次数与单次 token
判据：V-B 若在 ① 上不劣于 V-A，而在 ② 上显著更省，则采纳
成本：2 × M 局模型对局
```

**§6.5 已经说过本文不替这个取舍下结论。**
它是一个"多次小决策 vs 少次大决策"的结构选择，
两边都有合理的先验，只能实测。但它直接压着 REVIEW【E1】，所以不能不做。

### 10.5 明确建议不要做的，以及理由

| 不要做 | 出处 | 理由 |
| --- | --- | --- |
| **无条件触发的全场围殴** | Shogun 2 的 Realm Divide（§3.4） | 让"识别领先者"这个零难度任务主导全场，且把领先者的最优策略压成一条。围殴必须**可降温、行为加权、且降温要付机会成本**（§9.6） |
| **建筑槽位** | Attila / Warhammer（§3.2） | 105 郡 × 4–8 槽 = 420–840 个决策位。首轮方案 §6.6 的判断正确，不需重议 |
| **任务树** | Imperator / Terra Indomita（§2.7） | 公开的固定剧本 → 数据污染；且给每方一条被规划好的路，与"测自主规划"相反 |

| **贸易建筑链** | Oriental Empires（§1.8） | 状态量大、收益薄 |
| **玩家自划战区 / zone 边界** | Stellaris / Shadow Empire（§7.2 家族 C） | 会新增一道与战略无关的题。用东汉十三州做固定分组 |
| **无上限的全国统一队列** | Victoria 3（§7.2 家族 F） | 集中化不减负；减负来自条目数上限。**没有上限就等于没做** |

### 10.6 本文没能解决的问题

写在最后，是为了不让读者以为这份文档比它实际的更完整。

**（一）一手资料没拿到的：**

- **CK3 的三国 mod 特性表**（§2.3）。Steam 创意工坊页面在本次调研中反复限流，
  省份数、人物数、自定义机制一律查不到。**这个方向本轮没有可用产出**，不是我略过了它。
- **ModDB 与 BoardGameGeek 均返回 403**（前者影响 §2.2 的 CK2 mod 数据，
  后者使我无法读到一篇标题为"关于 Root 的数据与设计"的设计师访谈，
  那篇很可能正好回答 §8 的核心问题）。
- **Fandom 系维基全部返回 HTTP 402**（§0.4 已声明）。

**（二）证据链弱、只能标为"量级参考"的：**

- 桌游胜率数据的方法未经同行评审（§8.4 已详列口径与局限）。
- Twilight Struggle 的 +2 让先是社群惯例，我在 GMT 官方规则里找不到它。
- 我在检索中见到过按玩家经验分层的 Root 胜率，**但一手来源里没有该分析**，因此全部未采用。

**（三）文献里根本没有答案的：**

- **委任天花板问题（§7.6）在游戏设计文献里没有现成答案**，
  因为商业游戏里"被委任方"是 AI、"委任方"是人，两边能力差距是设计前提；
  本项目两边都是模型，这个前提不成立。**E-2 实验是本文能给出的最好办法，不是标准答案。**
- **人类技能分布 → 模型技能分布的迁移性未知。**
  §8.4 的 Root 数据、§8.5 的 MCTS 实验，被测的都不是语言模型。
  Goodman et al. 2025 的核心发现（**种子影响随棋力上升而上升**）是在 MCTS 智能体上得到的，
  它在语言模型上是否成立**没有人验证过**。本文按"成立"来给建议，
  因为按它不成立来设计的风险更大——但这是一个假设，不是一个已知事实。

**（四）本文提出但完全未标定的：**

- 席位势能值的六个权重（§8.6）
- 行政容量的容量与成本系数（§9.10）
- 缺口数机制里的 `k`、器械准备旬数、各档缺口数（§10.2）
- 离乱钟的各项增减量与 85 的终止阈值（§6.1.2）

**这些数字一个都不要从本文抄。** 本文给的是形状与量级，标定必须靠仿真
（`GAMEPLAY-DESIGN.md` §13.1 已经列了必须靠仿真标定的清单，本文只是往里又加了四项）。
